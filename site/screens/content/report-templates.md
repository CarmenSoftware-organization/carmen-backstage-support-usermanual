# เทมเพลตรายงาน

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **เนื้อหา** > **เทมเพลตรายงาน**

**เทมเพลตรายงาน** (Report Template — แม่แบบของรายงานหรือเอกสารที่โรงแรมเปิดดูหรือพิมพ์จาก Carmen Blue) มี 2 ประเภท:

- **ฟอร์ม:** หน้าตาของเอกสารที่พิมพ์ออกมา เช่น ใบขอซื้อ (PR) หรือใบสั่งซื้อ (PO) แต่ละเอกสารมีได้หลายแบบ และมีแบบเริ่มต้นหนึ่งแบบ ดู [กลุ่มฟอร์ม](/screens/content/form-groups)
- **รายการ:** รายงานที่ผู้ใช้ของโรงแรมเลือกเปิดจากรายการรายงาน

หน้านี้ใช้เพิ่มหรือแก้เทมเพลต เปิดหรือปิดการใช้งาน กำหนดว่าโรงแรมไหนเห็นรายงานใด สำรองเทมเพลตเป็นไฟล์ และกู้เนื้อหาเวอร์ชันเก่ากลับมา

ตัวเทมเพลตเก็บเป็นข้อความแบบ XML (รูปแบบไฟล์ที่ใช้บรรยายหน้าตารายงาน) หน้าจอแสดงข้อความนี้ให้เห็น โดยปกติทีมเทคนิคเป็นผู้เขียนเนื้อหา XML ส่วนผู้ดูแลระบบทั่วไปใช้หน้านี้เพื่อตั้งค่า สำรอง และกู้คืน <!-- plain-ok -->

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ**

- **ค้นหา** ด้วยชื่อ ดู [ค้นหา](/getting-started/common-actions#search)
- **กรอง** ตามสถานะ **ประเภทเทมเพลต** **ประเภทแหล่งข้อมูล** และ **วิธีคำนวณต้นทุน** ดู [ตัวกรอง](/getting-started/common-actions#filters)
- **ส่งออก** รายการเป็นไฟล์ CSV ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **เพิ่มเทมเพลต:** ปุ่ม **เพิ่มเทมเพลต**
- **สำรองทั้งหมด:** ปุ่ม **Backup ทั้งหมด** ดาวน์โหลดทุกเทมเพลตรวมเป็นไฟล์เดียว
- **สำรองบางรายการ:** ติ๊กแถวที่ต้องการ แล้วกด **ดาวน์โหลด backup (N)** ในแถบที่ขึ้นมา ดู [เลือกหลายรายการพร้อมกัน](/getting-started/common-actions#bulk-select)
- **นำเข้า:** ปุ่ม **นำเข้า** นำเทมเพลตจากไฟล์ backup กลับเข้าระบบ
- **อ่านตาราง:** **ประเภทเทมเพลต** **กลุ่มรายงาน** (ป้าย **ค่าเริ่มต้น** = แบบเริ่มต้นของเอกสารนั้น) **วิธีคำนวณต้นทุน** ป้าย **มาตรฐาน** หรือ **กำหนดเอง** และ **สถานะ**
- **เมนูของแถว** (ปุ่ม `⋯`): **แก้ไข**, **ประวัติการเปลี่ยนแปลง**, **ดาวน์โหลด backup** และ **ลบ** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)

**หน้าของเทมเพลต**

- **ส่วนหัว:** ชื่อ เลขเวอร์ชัน (เช่น **v15**) และเส้นทางของข้อมูล เช่น "Dialog · 3 ช่อง → View ... → ..." (ส่วนนี้สำหรับทีมเทคนิค) ปุ่ม **ประวัติการเปลี่ยนแปลง**, **เวอร์ชัน XML**, **ดาวน์โหลด backup** และ **แก้ไข** ดู [โหมดดูและโหมดแก้ไข](/getting-started/common-actions#view-edit) <!-- plain-ok -->
- **ด้านซ้าย:** ข้อมูลเทมเพลต ขอบเขตหน่วยธุรกิจ วิธีคำนวณต้นทุน และแหล่งข้อมูล
- **ด้านขวา:** แท็บตัวแก้ไข 3 แท็บ และแท็บตัวอย่าง ตัวเลขข้างชื่อแท็บคือจำนวนบรรทัด
  - **Dialog XML:** หน้าต่างตัวกรองที่ผู้ใช้กรอกก่อนเปิดรายงาน เช่น ช่วงวันที่ หรือผู้ขาย <!-- plain-ok -->
  - **Content XML:** หน้าตาของตัวรายงานหรือเอกสาร <!-- plain-ok -->
  - **Export XML:** รูปแบบข้อมูลเมื่อผู้ใช้กดส่งออกข้อมูล <!-- plain-ok -->
  - **ตัวอย่าง:** ภาพจำลองของหน้าต่างตัวกรองจาก Dialog XML ช่องในภาพกดไม่ได้และไม่มีข้อมูลจริง ใช้ดูว่าหน้าต่างจะหน้าตาอย่างไร <!-- plain-ok -->
- **แถบเครื่องมือของตัวแก้ไข:** ในโหมดแก้ไขมี **อัปโหลด** (ใส่ไฟล์จากเครื่อง) **จัดรูปแบบ** (จัดย่อหน้าให้อ่านง่าย) **คัดลอก** **ดาวน์โหลด** และ **ล้าง** ในโหมดดูมีเฉพาะ **คัดลอก** และ **ดาวน์โหลด** ใต้ตัวแก้ไขบอกว่า **XML ถูกต้อง** หรือบอกบรรทัดที่ผิด <!-- plain-ok -->

## อธิบายช่องข้อมูล

**ข้อมูลเทมเพลต**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ประเภทเทมเพลต** (จำเป็น) | ฟอร์มหรือรายการ | **ฟอร์ม** หรือ **รายการ** ช่องด้านล่างเปลี่ยนตามประเภท |
| **ชื่อ (EN)** (จำเป็น) | ชื่อภาษาอังกฤษ | ระบบใช้ชื่อนี้จับคู่เทมเพลตตอนนำเข้า |
| **ชื่อ (TH)** | ชื่อภาษาไทย | ไม่บังคับ |
| **คำอธิบาย (EN)**, **คำอธิบาย (TH)** | อธิบายว่ารายงานแสดงอะไร | ไม่บังคับ |
| **กลุ่มรายงาน** (จำเป็น) | หมวดของเทมเพลต | ประเภทฟอร์ม: เลือกรหัสเอกสาร เช่น `PR`, `PO`, `GRN` ประเภทรายการ: พิมพ์ชื่อกลุ่ม เช่น `inventory` |
| **มาตรฐาน** | ป้ายของเทมเพลต | เฉพาะประเภทรายการ ติ๊ก = ป้าย **มาตรฐาน** ไม่ติ๊ก = ป้าย **กำหนดเอง** |
| **เป็นค่าเริ่มต้นของกลุ่มรายงานนี้** | แบบเริ่มต้นของเอกสารนี้ | เฉพาะประเภทฟอร์ม แต่ละกลุ่มมีค่าเริ่มต้นได้อันเดียว ถ้ามีอันอื่นเป็นอยู่แล้ว การบันทึกจะไม่สำเร็จ ให้เปลี่ยนที่หน้า [กลุ่มฟอร์ม](/screens/content/form-groups) แทน |
| **ใช้งาน** | เปิดหรือปิดเทมเพลต | ปิดแล้วผู้ใช้ของโรงแรมจะไม่เห็น |
| **เรียกดูรายงาน** | แสดงปุ่มเปิดรายงานในรายการรายงาน | เฉพาะประเภทรายการ |
| **ส่งออกข้อมูล** | แสดงปุ่มส่งออกข้อมูล | เฉพาะประเภทรายการ ต้องมี Export XML ด้วย ถ้าปิดทั้งสองช่อง รายงานจะไม่แสดงในรายการรายงานเลย <!-- plain-ok --> |

**ขอบเขตหน่วยธุรกิจ และวิธีคำนวณต้นทุน** (เฉพาะประเภทรายการ ประเภทฟอร์มใช้ได้ทุกหน่วยธุรกิจเสมอ)

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **อนุญาต** | หน่วยธุรกิจที่เห็นรายงานนี้ | พิมพ์รหัสหน่วยธุรกิจแล้วกด Enter ทีละรหัส เว้นว่าง = ทุกหน่วยธุรกิจ |
| **ไม่อนุญาต** | หน่วยธุรกิจที่ไม่เห็นรายงานนี้ | พิมพ์รหัสแล้วกด Enter เว้นว่าง = ไม่มี |
| **วิธีคำนวณต้นทุน** | วิธีคิดต้นทุนที่รายงานนี้รองรับ | **FIFO**, **เฉลี่ย**, **เฉลี่ยแยกตาม Location** ไม่ติ๊กเลย = ใช้ได้ทุกวิธี หน่วยธุรกิจที่ใช้วิธีที่ไม่ได้ติ๊กจะไม่เห็นและเปิดรายงานนี้ไม่ได้ |

**แหล่งข้อมูล** (สำหรับทีมเทคนิค)

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ประเภทแหล่งข้อมูล**, **ชื่อแหล่งข้อมูล**, **ดูจาก BU**, **พารามิเตอร์ของแหล่งข้อมูล**, **Builder Key** | บอกว่ารายงานดึงข้อมูลจากที่ใดในฐานข้อมูลของโรงแรม | ประเภทมี View, Function, Procedure ปล่อยให้ทีมเทคนิคตั้งค่า <!-- plain-ok --> |

## งานที่ทำบ่อย

**แก้ข้อความหรือการตั้งค่าของเทมเพลต**

1. ที่หน้ารายการ กดชื่อเทมเพลต
2. กดปุ่ม **แก้ไข**
3. แก้ช่องด้านซ้าย หรือแก้ข้อความในแท็บตัวแก้ไข หรือกด **อัปโหลด** เพื่อใช้ไฟล์จากเครื่องแทนข้อความเดิมในแท็บนั้น
4. กดแท็บ **ตัวอย่าง** เพื่อดูหน้าต่างตัวกรองที่ผู้ใช้จะเห็น
5. กดปุ่ม **บันทึกการแก้ไข** ทุกครั้งที่บันทึก ระบบสร้างเวอร์ชันใหม่ให้

**ดูและกู้คืนเวอร์ชันเก่า**

1. เปิดหน้าของเทมเพลต ถ้ากำลังแก้ไขอยู่ ให้บันทึกหรือยกเลิกก่อน
2. กดปุ่ม **เวอร์ชัน XML** แผง **ประวัติเวอร์ชัน** จะเปิดขึ้น แต่ละเวอร์ชันบอกว่าเกิดจาก **สร้าง**, **แก้ไข**, **นำเข้า** หรือ **กู้จาก v...** <!-- plain-ok -->
3. กางเวอร์ชันที่ต้องการ เพื่อดู **ฟิลด์ที่ต่างจากปัจจุบัน** และเนื้อหาของเวอร์ชันนั้น
4. กด **ดาวน์โหลดเวอร์ชันนี้** ถ้าต้องการเก็บเป็นไฟล์
5. กด **กู้คืนเวอร์ชันนี้** แล้วยืนยันในกล่อง **กู้คืน v...?**

การกู้คืนไม่ลบเวอร์ชันใด ระบบสร้างเวอร์ชันใหม่จากเนื้อหาของเวอร์ชันที่เลือก (เช่น กู้ v12 ได้ v16) และไม่เปลี่ยนว่าเทมเพลตเป็นค่าเริ่มต้นของกลุ่มหรือไม่

**สำรองเทมเพลตเป็นไฟล์**

1. กด **Backup ทั้งหมด** หรือติ๊กแถวแล้วกด **ดาวน์โหลด backup (N)** หรือกด `⋯` > **ดาวน์โหลด backup** ที่แถวเดียว
2. ปุ่มจะแสดงความคืบหน้า เช่น **กำลัง backup 12/40**
3. เมื่อเสร็จ เบราว์เซอร์จะดาวน์โหลดไฟล์ .json หนึ่งไฟล์ <!-- plain-ok -->

การสำรองทำงานในเบราว์เซอร์ของคุณ ถ้าปิดหน้าหรือปิดเบราว์เซอร์ระหว่างนั้น จะไม่ได้ไฟล์ ให้รอจนข้อความ **Backup แล้ว ... รายการ** ขึ้น

**นำเข้าจากไฟล์ backup**

1. กดปุ่ม **นำเข้า** กล่อง **นำเข้าเทมเพลตรายงาน** จะเปิดขึ้น
2. กด **เลือกไฟล์** แล้วเลือกไฟล์ backup (ไม่เกิน 10 MB)
3. ตารางในกล่องจะแสดงแต่ละเทมเพลตพร้อมสถานะ **ใหม่**, **ชื่อซ้ำ** (มีชื่อ EN นี้ในระบบแล้ว) หรือ **ไม่ผ่านตรวจ**
4. เลือกการทำงานของแต่ละแถว: **สร้าง**, **เขียนทับ** หรือ **ข้าม** หรือกด **เขียนทับทั้งหมด**
5. กดปุ่ม **นำเข้า N รายการ** แล้วรอจนเห็นสรุป เช่น "สร้าง 2 · เขียนทับ 1 · ข้าม 0 · ล้มเหลว 0"

ระหว่างนำเข้า กล่องจะปิดไม่ได้ การนำเข้าทำในเบราว์เซอร์ทีละรายการ ถ้าปิดเบราว์เซอร์กลางทาง รายการที่ทำไปแล้วยังอยู่ ส่วนที่เหลือจะไม่ถูกนำเข้า เทมเพลตที่สร้างจากการนำเข้าจะไม่ถูกตั้งเป็นค่าเริ่มต้นของกลุ่ม

## ข้อควรระวัง

::: warning การลบเทมเพลตย้อนกลับไม่ได้
กล่อง **ลบเทมเพลตรายงาน** บอกว่า **การกระทำนี้ย้อนกลับไม่ได้** หน้าจอนี้ไม่มีปุ่มกู้คืน และประวัติเวอร์ชันของเทมเพลตนั้นก็เปิดจากหน้านี้ไม่ได้อีก ให้กด **ดาวน์โหลด backup** ก่อนลบเสมอ ถ้าต้องการกลับมา ให้ **นำเข้า** จากไฟล์นั้น
:::

::: warning เขียนทับตอนนำเข้า
**เขียนทับ** แทนที่เทมเพลตในระบบที่มีชื่อ (EN) เดียวกัน ผู้ใช้ของโรงแรมจะเห็นแบบใหม่ทันที ถ้าเขียนทับผิด ให้กู้เวอร์ชันก่อนหน้าจาก **เวอร์ชัน XML** <!-- plain-ok -->
:::

- ปุ่ม **ล้าง** ในตัวแก้ไขลบข้อความทั้งหมดในแท็บนั้น กด Ctrl+Z (หรือ ⌘+Z) เพื่อย้อนได้ก่อนบันทึก
- การปิด **ใช้งาน** หรือแก้ **อนุญาต** / **ไม่อนุญาต** มีผลกับผู้ใช้ของโรงแรมหลังบันทึก
