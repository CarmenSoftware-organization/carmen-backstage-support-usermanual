# Clusters

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **องค์กร** > **Clusters**

**Cluster** (กลุ่มโรงแรมหรือกลุ่มบริษัทของลูกค้าหนึ่งราย) คือที่รวม **หน่วยธุรกิจ** (Business Unit — โรงแรมหรือสาขาหนึ่งแห่ง) ของลูกค้ารายเดียวกันไว้ด้วยกัน หน้านี้ใช้สร้าง Cluster ให้ลูกค้าใหม่ ดูว่าแต่ละ Cluster ใช้โควตาไปเท่าไร แก้ชื่อหรือโลโก้ และจัดการว่าใครอยู่ใน Cluster บ้าง

ทุก Cluster มี 2 เพดาน

- **โควตาหน่วยธุรกิจ:** สร้างหน่วยธุรกิจได้กี่แห่ง มาจากใบโควตา BU ที่ลูกค้าซื้อ
- **ที่นั่ง:** มีผู้ใช้ได้กี่คน มาจากใบไลเซนส์ที่นั่งของแต่ละโรงแรม

ดูวิธีเพิ่มทั้งสองอย่างที่ [จัดการ License](/guides/manage-license)

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ (จัดการ Cluster)**

- **ดูความจุรวมทั้งระบบ:** กล่องด้านบนรวมทุก Cluster: หน่วยธุรกิจที่ใช้ไปเทียบกับที่ซื้อ ผู้ใช้ที่ใช้ไปเทียบกับที่นั่งที่ซื้อ จำนวน Cluster ที่ **ใช้งาน** จำนวนที่ **ใกล้เต็ม** และจำนวนที่ **โควตาใกล้หมดอายุ**
- **ค้นหา** Cluster ด้วยรหัสหรือชื่อ ดู [ค้นหา](/getting-started/common-actions#search)
- **กรอง** ตามสถานะ **ใช้งาน** / **ไม่ใช้งาน** หรือติ๊ก **แสดง Cluster ที่ถูกลบแบบ soft delete** เพื่อดู Cluster ที่ลบไปแล้ว ดู [ตัวกรอง](/getting-started/common-actions#filters) <!-- plain-ok -->
- **ส่งออก** รายการเป็นไฟล์ CSV ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **อ่านตาราง:** คอลัมน์ **หน่วยธุรกิจ** และ **ผู้ใช้งาน** แสดงจำนวนที่ใช้ไป / เพดาน เช่น `1 / 10` แถบสีแดงหมายถึงใช้ครบหรือเกินแล้ว ส่วน `∞` หมายถึงยังไม่มีเพดาน คอลัมน์ **โควตาหมดอายุ** บอกวันที่โควตาหมดอายุ
- **สร้าง Cluster:** ปุ่ม **เพิ่ม Cluster**
- **เปิด Cluster:** กดชื่อ Cluster
- **เมนูของแถว** (ปุ่ม `⋯`): **แก้ไข**, **ประวัติการเปลี่ยนแปลง** และ **ลบ** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)

**หน้าของ Cluster**

- **ส่วนหัว:** ชื่อ ป้ายสถานะ **รหัส** **ชื่อแฝง** โลโก้ และรูปประจำตัว ด้านขวาเป็นเกจ **หน่วยธุรกิจ** และ **ที่นั่ง** บอกว่าใช้ไปเท่าไรและเหลือว่างเท่าไร
- **แท็บไลเซนส์:** กล่อง **สัญญา** (Subscription — สัญญาการใช้งาน ซึ่งบอกว่าโรงแรมใช้ฟีเจอร์ใดได้) แสดงสัญญาล่าสุดของ Cluster นี้ เรียงตามวันหมดอายุใหม่สุดก่อน แต่ละแถวบอกเลขที่สัญญา วันหมดอายุ จำนวนฟีเจอร์ และที่นั่งที่ใช้ กดปุ่ม **จัดการ** ที่แถวเพื่อเปิดสัญญานั้น หรือกด **จัดการไลเซนส์** เพื่อเปิดหน้าไลเซนส์ของ Cluster ถ้ายังไม่มีสัญญา จะขึ้นว่า **ยังไม่มีสัญญา** พร้อมปุ่ม **สร้างสัญญา**
- **แท็บหน่วยธุรกิจ:** รายชื่อโรงแรมใน Cluster นี้ ค้นหาได้ และกดเพื่อเปิดหน้าของโรงแรมนั้น ถ้ามีโรงแรมเกินโควตา แถวที่เกินจะมีป้าย **เกินขีดจำกัด** และแก้ไขไม่ได้จนกว่าจะซื้อโควตาเพิ่ม
- **แท็บผู้ใช้งาน:** รายชื่อคนที่อยู่ใน Cluster พร้อม **บทบาท** เพิ่มผู้ใช้ เปลี่ยนบทบาท และนำผู้ใช้ออกได้
- **ประวัติการเปลี่ยนแปลง:** ปุ่มมุมขวาบน ดู [ประวัติการเปลี่ยนแปลง](/getting-started/common-actions#activity-trail)

## อธิบายช่องข้อมูล

**ฟอร์มสร้าง Cluster**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **รหัส** (จำเป็น) | รหัสสั้นของลูกค้า ใช้อ้างถึง Cluster นี้ | `GHG` ใช้ตัวอักษรภาษาอังกฤษ ตัวเลข `-` หรือ `_` ยาว 2–20 ตัว ห้ามมีช่องว่าง |
| **ชื่อแฝง** | ชื่อสั้นมากสำหรับที่แคบ | ไม่บังคับ ตัวอักษรหรือตัวเลขไม่เกิน 3 ตัว เช่น `GHG` |
| **ชื่อ** (จำเป็น) | ชื่อเต็มของลูกค้าหรือกลุ่มโรงแรม | "Grand Hotel Group" |
| **หน่วยธุรกิจ** (จำเป็น) | อยู่ในกล่อง **ใบโควตาใบแรก** จำนวนโรงแรมที่ลูกค้าซื้อ ถ้าไม่มีใบโควตาเลย จะสร้างหน่วยธุรกิจใน Cluster นี้ไม่ได้ | `2` |
| **วันหมดอายุ** (จำเป็น) | วันที่ใบโควตาใบแรกหมดอายุ | เลือกวันที่ หรือติ๊ก **ไม่มีวันหมดอายุ** แทน |
| **ไม่มีวันหมดอายุ** | ติ๊กเมื่อโควตาใช้ได้ตลอด | เมื่อติ๊กแล้วไม่ต้องเลือกวันหมดอายุ |

การ์ดด้านขวาของฟอร์มแสดงตัวอย่างของ Cluster ที่กำลังสร้าง ไม่มีอะไรให้กรอก

**หน้าของ Cluster (แก้ไขได้ที่ส่วนหัว)**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ชื่อ** | ชื่อของ Cluster | กดที่ชื่อเพื่อแก้ |
| **รหัส** | รหัสของ Cluster | กดที่รหัสเพื่อแก้ กฎเดียวกับตอนสร้าง |
| **ชื่อแฝง** | ชื่อสั้นไม่เกิน 3 ตัว | ถ้ายังไม่มีจะขึ้นว่า **ยังไม่ได้ตั้ง** |
| ป้ายสถานะ | **ใช้งาน** หรือ **ไม่ใช้งาน** | กดป้ายเพื่อสลับ |
| **โลโก้** และ **รูปประจำตัว** | ภาพที่แสดงคู่กับชื่อ Cluster | กดกรอบภาพเพื่อเลือกไฟล์ |

**กล่องเพิ่มผู้ใช้เข้า Cluster (แท็บผู้ใช้งาน)**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| ค้นหาผู้ใช้ (จำเป็น) | บัญชีที่จะเพิ่ม | พิมพ์ชื่อผู้ใช้หรืออีเมล แล้วกดเลือก บัญชีต้องสร้างไว้ก่อนที่หน้า [ผู้ใช้งาน](/screens/organization/users) |
| **บทบาทใน Cluster** (จำเป็น) | สิ่งที่คนนี้ทำได้ใน Cluster | **ผู้ใช้** ใช้งานได้อย่างเดียว **ผู้ดูแล** จัดการผู้ใช้คนอื่นใน Cluster ได้ ใต้ช่องบอกว่าใช้ที่นั่งไปเท่าไร |

## งานที่ทำบ่อย

**สร้าง Cluster ให้ลูกค้าใหม่**

1. กดปุ่ม **เพิ่ม Cluster**
2. กรอก **รหัส** และ **ชื่อ** (และ **ชื่อแฝง** ถ้าต้องการ)
3. ในกล่อง **ใบโควตาใบแรก** กรอกจำนวน **หน่วยธุรกิจ** แล้วเลือก **วันหมดอายุ** หรือติ๊ก **ไม่มีวันหมดอายุ**
4. กดปุ่ม **สร้าง Cluster** ระบบจะแสดงข้อความ **สร้าง Cluster สำเร็จ** และเปิดหน้าของ Cluster ใหม่

ขั้นตอนเต็มตั้งแต่สร้าง Cluster จนพนักงานเข้าใช้งานได้ อยู่ที่ [ตั้งค่าโรงแรมใหม่](/guides/setup-hotel)

**แก้ชื่อ ชื่อแฝง สถานะ หรือโลโก้**

1. เปิดหน้าของ Cluster
2. กดที่ค่าที่ต้องการแก้ในส่วนหัว แล้วพิมพ์ค่าใหม่ หรือกดป้ายสถานะเพื่อสลับ
3. แถบ **มีการแก้ไขที่ยังไม่บันทึก** จะขึ้นที่ด้านล่าง
4. กดปุ่ม **บันทึกการแก้ไข** หรือกด **ยกเลิก** เพื่อทิ้งสิ่งที่แก้ ดู [เตือนเมื่อยังไม่ได้บันทึก](/getting-started/common-actions#unsaved-changes)

**เพิ่มผู้ใช้เข้า Cluster**

1. เปิดหน้าของ Cluster แล้วกดแท็บ **ผู้ใช้งาน**
2. กดปุ่ม **เพิ่มผู้ใช้** กล่อง **เพิ่มผู้ใช้เข้า Cluster** จะเปิดขึ้น
3. พิมพ์ชื่อหรืออีเมล แล้วกดเลือกชื่อที่ขึ้นมา
4. เลือก **บทบาทใน Cluster**
5. กดปุ่ม **เพิ่มผู้ใช้** ระบบจะแสดงข้อความ **เพิ่มผู้ใช้เข้า cluster แล้ว**

ถ้ากล่องขึ้นว่า **ถึงเพดานไลเซนส์ของ Cluster แล้ว** แปลว่าที่นั่งเต็ม ให้เพิ่มที่นั่งตาม [จัดการ License](/guides/manage-license#seats) ก่อน

**เปลี่ยนบทบาทของผู้ใช้ใน Cluster**

1. ที่แท็บ **ผู้ใช้งาน** หาแถวของผู้ใช้
2. เปลี่ยนค่าในคอลัมน์ **บทบาท** เป็น **ผู้ดูแล** หรือ **ผู้ใช้**

**นำผู้ใช้ออกจาก Cluster**

1. ที่แท็บ **ผู้ใช้งาน** กดปุ่มนำออกที่แถวของผู้ใช้ หรือติ๊กหลายแถวแล้วกด **นำผู้ใช้ที่เลือกออก** ดู [เลือกหลายรายการพร้อมกัน](/getting-started/common-actions#bulk-select)
2. ระบบจะถามยืนยัน เช่น **นำ "ชื่อผู้ใช้" ออกจาก Cluster นี้หรือไม่**
3. กดยืนยัน บัญชีของผู้ใช้ยังอยู่ แต่จะไม่อยู่ใน Cluster นี้อีก

**ลบ Cluster**

1. ที่หน้ารายการ กดปุ่ม `⋯` ที่แถวของ Cluster แล้วเลือก **ลบ**
2. ถ้า Cluster ยังมีหน่วยธุรกิจอยู่ ระบบจะไม่ให้ลบ และแจ้งว่า **ยังมีหน่วยธุรกิจอยู่ ... หน่วย ต้องลบหรือย้ายไป Cluster อื่นก่อน**
3. ถ้าไม่มีหน่วยธุรกิจแล้ว กล่อง **ลบ Cluster** จะถามยืนยัน กด **ลบ**

## ข้อควรระวัง

::: warning การลบ Cluster ย้อนกลับไม่ได้
กล่องยืนยันบอกว่าการลบ **ย้อนกลับไม่ได้** หน้าจอนี้ไม่มีปุ่มกู้คืน Cluster ที่ลบแล้วยังดูได้ด้วยตัวกรองรายการที่ลบแล้ว แต่ใช้งานต่อไม่ได้ ตรวจชื่อและรหัสให้แน่ใจก่อนกดลบ
:::

::: warning การนำผู้ใช้ออกจาก Cluster
ผู้ใช้ที่ถูกนำออกจะเข้าโรงแรมใน Cluster นี้ไม่ได้ทันที ถ้านำออกผิดคน ต้องเพิ่มกลับและตั้งบทบาทใหม่เอง
:::

- การเปลี่ยน **รหัส** ของ Cluster ที่ใช้งานอยู่ อาจทำให้คนที่จำรหัสเดิมสับสน ควรแจ้งทีมก่อนเปลี่ยน
- การสลับสถานะเป็น **ไม่ใช้งาน** ใช้กับทั้ง Cluster และเมื่อกด **บันทึกการแก้ไข** แล้ว หน้าจอไม่ถามยืนยันอีก ตรวจให้แน่ใจว่าเป็น Cluster ที่ถูกต้อง ถ้าไม่แน่ใจผลที่จะเกิดกับโรงแรมใน Cluster ให้ถามทีมเทคนิคก่อน
