# หน่วยธุรกิจ

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **องค์กร** > **หน่วยธุรกิจ**

**หน่วยธุรกิจ** (Business Unit หรือ BU — โรงแรมหรือสาขาหนึ่งแห่ง) อยู่ภายใต้ **Cluster** (กลุ่มโรงแรมของลูกค้าหนึ่งราย) เพียงหนึ่งเดียว หน้านี้ใช้สร้างโรงแรมใหม่ใน Cluster แก้ข้อมูลของโรงแรม เช่น ที่อยู่ ข้อมูลภาษี รูปแบบวันที่ และจัดการว่าใครเข้าโรงแรมนี้ได้บ้าง

แต่ละหน่วยธุรกิจมีฐานข้อมูลของตัวเอง แยกจากโรงแรมอื่น การสร้างหน่วยธุรกิจใช้โควตาของ Cluster 1 แห่ง

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ (จัดการหน่วยธุรกิจ)**

- **ดูภาพรวม:** จำนวนหน่วยธุรกิจทั้งหมด ครอบคลุมกี่ Cluster และจำนวนที่ **ใช้งาน** **ไม่ใช้งาน** และ **เก็บถาวรแล้ว** (ลบไปแล้ว)
- **ค้นหา** ด้วยรหัสหรือชื่อ ดู [ค้นหา](/getting-started/common-actions#search)
- **กรอง** ตามสถานะ หรือติ๊ก **แสดงหน่วยธุรกิจที่ถูกลบชั่วคราว** ดู [ตัวกรอง](/getting-started/common-actions#filters)
- **ส่งออก** เป็นไฟล์ CSV ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **สร้างหน่วยธุรกิจ:** ปุ่ม **เพิ่มหน่วยธุรกิจ**
- **เปิดหน่วยธุรกิจ:** กดรหัสหรือชื่อ
- **เมนูของแถว** (ปุ่ม `⋯`): **แก้ไข**, **ประวัติการเปลี่ยนแปลง** และ **ลบ** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)

**หน้าของหน่วยธุรกิจ**

หน้านี้แบ่งเป็นแท็บ ตอนสร้างใหม่มี 4 แท็บแรก หลังสร้างแล้วจะมีแท็บ **ผู้ใช้งาน** และ **ไลเซนส์** เพิ่มขึ้น

- **ส่วนหัว:** ชื่อโรงแรม (กดเพื่อแก้) ป้ายสถานะ **ใช้งาน** / **ไม่ใช้งาน** และป้าย **HQ** (หน่วยธุรกิจที่เป็นสำนักงานใหญ่ของ Cluster) กดป้ายเพื่อสลับ
- **ทั่วไป:** รายละเอียด ตั้งค่าการคำนวณ และแบรนด์ (โลโก้และรูปประจำตัว)
- **ที่ตั้ง:** ที่อยู่ของโรงแรม ข้อมูลบริษัทที่ออกใบแจ้งหนี้ และข้อมูลภาษี
- **รูปแบบ:** รูปแบบการแสดงวันที่ เวลา และตัวเลข
- **เทคนิค:** ไฟล์แนบใน comment การตั้งค่าเพิ่มเติม การเชื่อมต่อฐานข้อมูล และกล่องตรวจสถานะฐานข้อมูลของโรงแรม ส่วนนี้สำหรับทีมเทคนิค
- **ผู้ใช้งาน:** ใครเข้าโรงแรมนี้ได้ พร้อม **บทบาท BU** และ **สถานะ BU** เพิ่ม แก้ และนำผู้ใช้ออกได้
- **ไลเซนส์:** **ไลเซนส์ผู้ใช้** (ที่นั่ง — จำนวนผู้ใช้ที่โรงแรมนี้มีได้) สัญญาของโรงแรม และ **ใบสิทธิ์ interface** (สิทธิ์เชื่อมต่อกับระบบอื่น) ที่นั่งจัดการได้ที่หน้า [ไลเซนส์](/screens/license/licenses) ปุ่ม **จัดการไลเซนส์** และ **สร้างสัญญาใหม่** พาไปที่นั่น

## งานที่ทำบ่อย

**สร้างหน่วยธุรกิจ**

1. กดปุ่ม **เพิ่มหน่วยธุรกิจ** แถบด้านล่างจะบอกว่ายังต้องกรอกอะไร เช่น **ยังต้องกรอก: ชื่อ, Cluster**
2. กดที่หัวข้อ **(หน่วยธุรกิจที่ยังไม่มีชื่อ)** แล้วพิมพ์ชื่อโรงแรม
3. ที่แถว **Cluster** กด **ตั้งค่า cluster...** แล้วเลือก Cluster
4. เลือก **วิธีคำนวณ** และกรอกแท็บ **ที่ตั้ง** และ **รูปแบบ** ถ้ามีข้อมูลพร้อม
5. ไม่ต้องแตะแท็บ **เทคนิค**
6. กดปุ่ม **สร้างหน่วยธุรกิจ** ระบบจะแสดงข้อความ **สร้าง หน่วยธุรกิจ สำเร็จ**

ถ้าระบบแจ้งว่า **ไม่สามารถสร้างหน่วยธุรกิจได้: cluster มีไลเซนส์ครบโควตาแล้ว** ให้เพิ่มใบโควตา BU ตาม [จัดการ License](/guides/manage-license#bu-quota) ก่อน

**แก้ข้อมูลของโรงแรม**

1. เปิดหน้าของหน่วยธุรกิจ แล้วกดแท็บที่ต้องการ
2. กดที่ค่าที่จะแก้ แล้วพิมพ์ค่าใหม่
3. แถบ **มีการแก้ไขที่ยังไม่บันทึก** จะขึ้นที่ด้านล่าง
4. กดปุ่ม **บันทึกการแก้ไข** หรือกด **ยกเลิก** ดู [เตือนเมื่อยังไม่ได้บันทึก](/getting-started/common-actions#unsaved-changes)

**เพิ่มผู้ใช้เข้าโรงแรม**

1. กดแท็บ **ผู้ใช้งาน**
2. กดปุ่ม **เพิ่มผู้ใช้** กล่อง **เพิ่มผู้ใช้เข้าหน่วยธุรกิจ** จะเปิดขึ้น
3. พิมพ์ชื่อหรืออีเมล แล้วกดเลือก ถ้าไม่เจอชื่อ ให้เพิ่มคนนั้นเข้า Cluster ก่อนที่หน้า [Clusters](/screens/organization/clusters)
4. เลือก **บทบาท BU**
5. กดปุ่ม **เพิ่มผู้ใช้** ระบบจะแสดงข้อความ **เพิ่มผู้ใช้เข้าหน่วยธุรกิจแล้ว**

**เปลี่ยนบทบาทหรือปิดการเข้าโรงแรมของผู้ใช้**

1. ที่แท็บ **ผู้ใช้งาน** กดปุ่มแก้ไขที่แถวของผู้ใช้ กล่อง **แก้ไขผู้ใช้ในหน่วยธุรกิจ** จะเปิดขึ้น
2. เปลี่ยน **บทบาท BU** หรือ **สถานะ BU**
3. กดปุ่ม **บันทึก**

ผู้ใช้ที่มีป้าย **ใช้ร่วมกัน** ยังใช้งานอยู่ในโรงแรมอื่นใน Cluster เดียวกัน การปิดที่นี่จึงไม่คืนที่นั่ง

**นำผู้ใช้ออกจากโรงแรม**

1. ที่แท็บ **ผู้ใช้งาน** กดปุ่มนำออกที่แถวของผู้ใช้
2. กล่อง **นำผู้ใช้ออก** จะถามยืนยัน กดยืนยัน บัญชีของผู้ใช้ยังอยู่ แต่จะเข้าโรงแรมนี้ไม่ได้อีก

**ลบหน่วยธุรกิจ**

1. ที่หน้ารายการ กดปุ่ม `⋯` ที่แถว แล้วเลือก **ลบ**
2. กล่อง **ลบหน่วยธุรกิจ** จะถามยืนยัน กด **ลบ**

## ข้อควรระวัง

::: warning อย่าเปลี่ยนการเชื่อมต่อฐานข้อมูลเอง
กล่อง **การเชื่อมต่อฐานข้อมูล** ในแท็บ **เทคนิค** บอกว่าโรงแรมนี้เก็บข้อมูลไว้ที่ไหน ถ้าเปลี่ยนค่าในกล่องนี้ ระบบจะถามว่า **ย้ายจุดเชื่อมต่อของหน่วยธุรกิจนี้หรือไม่** ถ้ากด **ย้ายจุดเชื่อมต่อ** โรงแรมจะไปอ่านและเขียนข้อมูลที่ใหม่ ข้อมูลเดิมยังอยู่ที่เดิม แต่จะเปิดจากหน้านี้ไม่ได้อีก ผู้ใช้ของโรงแรมอาจเห็นข้อมูลหายไปทั้งหมด ให้ปล่อยกล่องนี้ไว้ให้ทีมเทคนิคเสมอ
:::

::: warning ปุ่มในกล่อง Tenant Migrations และ Tenant Seed Data ของแท็บเทคนิค
สองกล่องนี้ตรวจและอัปเดตฐานข้อมูลของโรงแรมนี้แห่งเดียว เหมือนหน้า [Tenant Migrations](/screens/organization/tenant-migrations) และ [Tenant Seed Data](/screens/organization/tenant-seeds) การกด **ตรวจสอบสถานะ** ปลอดภัย แต่ปุ่ม **ใช้งาน Migration** เปลี่ยนโครงสร้างฐานข้อมูลของโรงแรมและย้อนกลับไม่ได้ และปุ่ม **สร้างข้อมูล** เพิ่มข้อมูลตั้งต้นที่ลบออกจากหน้านี้ไม่ได้ ให้ทีมเทคนิคเป็นผู้กด
:::

::: warning การลบหน่วยธุรกิจย้อนกลับไม่ได้
กล่องยืนยันบอกว่า **การกระทำนี้ย้อนกลับไม่ได้** หน้าจอนี้ไม่มีปุ่มกู้คืน ผู้ใช้ของโรงแรมจะเข้าโรงแรมนี้ไม่ได้อีก
:::

- **วิธีคำนวณ** มีผลกับการคิดต้นทุนสินค้าคงคลังของโรงแรม ถามฝ่ายบัญชีของโรงแรมก่อนเลือกหรือเปลี่ยน
- ถ้ามีหน่วยธุรกิจเกินโควตาของ Cluster หน่วยที่เกินจะแก้ไขไม่ได้จนกว่าจะซื้อโควตาเพิ่ม
