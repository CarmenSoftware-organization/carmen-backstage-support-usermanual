# ตั้งค่าอีเมล

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **Platform** > **ตั้งค่าอีเมล**

หน้านี้กำหนดว่าระบบส่งอีเมลออกในนามใคร และผ่านเซิร์ฟเวอร์ส่งอีเมลตัวไหน มีสองส่วน:

- **การจับคู่อีเมล:** อีเมลแต่ละประเภทของระบบส่งด้วยโปรไฟล์ผู้ส่งตัวใด
- **โปรไฟล์ผู้ส่ง:** ชุดข้อมูลผู้ส่งหนึ่งชุด เช่น "No-reply" ประกอบด้วยชื่อและอีเมลผู้ส่ง และข้อมูลเซิร์ฟเวอร์ส่งอีเมล (SMTP — เซิร์ฟเวอร์ที่รับอีเมลจากระบบแล้วส่งต่อถึงผู้รับ) ที่ผู้ให้บริการอีเมลของคุณให้มา

อีเมลของระบบมี 5 ประเภท ชื่อบนหน้าจอเป็นภาษาอังกฤษ:

| ประเภท | ใช้กับ |
| --- | --- |
| **Register** | ลิงก์ยืนยันอีเมลก่อนสร้างบัญชี และอีเมลแจ้งว่ามีบัญชีอยู่แล้ว |
| **Verify email** | ลิงก์ยืนยันอีเมลของบัญชีแบบเดิม และบัญชีที่ผู้ดูแลสร้างให้ |
| **Invitation** | คำเชิญเข้าคลัสเตอร์ และอีเมลแจ้งเมื่อบัญชีถูกสร้างจากคำเชิญ |
| **Forgot password** | ลิงก์ตั้งรหัสผ่านใหม่ |
| **Notification** | อีเมลแจ้งเตือนภายใน เช่น รายงานและการแจ้งเตือนของหน่วยธุรกิจ |

## สิ่งที่ทำได้ในหน้านี้

**การจับคู่อีเมล**

- **อ่านว่าอีเมลประเภทไหนออกจากโปรไฟล์ใด:** แต่ละแถวคือโปรไฟล์หนึ่งตัว พร้อมป้ายประเภทอีเมลที่ส่งผ่านโปรไฟล์นั้น โปรไฟล์ที่มีป้าย **ค่าเริ่มต้น** รับอีเมลทุกประเภทที่ไม่ได้เลือกโปรไฟล์ไว้ โปรไฟล์ที่ไม่มีอีเมลใดส่งผ่านจะขึ้น **ไม่มีเส้นทางใดส่งผ่านโปรไฟล์นี้**
- **แก้การจับคู่:** กดปุ่ม **แก้ไขการจับคู่** แล้วกดที่ป้ายประเภทอีเมลเพื่อย้ายไปโปรไฟล์อื่น หรือกด **ตั้งเป็นค่าเริ่มต้น** ที่โปรไฟล์ เสร็จแล้วกด **บันทึกการแก้ไข**

**โปรไฟล์ผู้ส่ง**

- **อ่านข้อมูลโปรไฟล์:** ชื่อ อีเมลผู้ส่ง เซิร์ฟเวอร์ ประเภทอีเมลที่ **รับสาย** (ส่งผ่านโปรไฟล์นี้) **SMTP username** และ **หมายเหตุ** รหัสผ่านไม่แสดงบนหน้าจอเลย แสดงเพียง **ตั้งรหัสผ่านไว้แล้ว** หรือ **ไม่ได้ตั้งรหัสผ่าน**
- **เพิ่มโปรไฟล์:** ปุ่ม **เพิ่มโปรไฟล์**
- **แก้ไข:** ปุ่ม **แก้ไข** ในการ์ด แล้วกด **บันทึก** หรือ **ยกเลิก** ท้ายการ์ด แก้ได้ทีละการ์ด ถ้าเปิดแก้การ์ดอื่นทั้งที่การ์ดเดิมยังไม่ได้บันทึก ระบบจะถาม **ทิ้งการแก้ไขที่ยังไม่บันทึก?**
- **ส่งเมลทดสอบ:** ปุ่ม **ส่งเมลทดสอบ** ส่งอีเมลทดสอบผ่านโปรไฟล์ที่บันทึกไว้ เพื่อยืนยันว่าข้อมูลเซิร์ฟเวอร์ใช้ได้จริง
- **ยกเลิกการตั้งค่า:** ปุ่มสีแดง **ยกเลิกการตั้งค่า** ลบโปรไฟล์นี้ออก มีกล่องยืนยัน

## อธิบายช่องข้อมูล

**การ์ดโปรไฟล์ผู้ส่ง (เพิ่มหรือแก้ไข)**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ชื่อโปรไฟล์** (จำเป็น) | ชื่อเรียกโปรไฟล์ในหน้านี้ | เช่น "No-reply", "Support" |
| **อีเมลผู้ส่ง** (จำเป็น) | อีเมลที่ผู้รับเห็นว่าเป็นผู้ส่ง | เช่น `no-reply@yourhotel.com` |
| **ชื่อผู้ส่ง** | ชื่อที่ผู้รับเห็นคู่กับอีเมลผู้ส่ง | เช่น "Carmen" |
| **SMTP host** (จำเป็น) | ที่อยู่เซิร์ฟเวอร์ส่งอีเมล ได้จากผู้ให้บริการอีเมล | เช่น `smtp.gmail.com` |
| **SMTP port** | หมายเลขช่องทางเชื่อมต่อของเซิร์ฟเวอร์ ได้จากผู้ให้บริการอีเมล | 1–65535 ส่วนใหญ่เป็น 587 หรือ 465 |
| **SMTP username** | ชื่อผู้ใช้สำหรับเข้าเซิร์ฟเวอร์ส่งอีเมล | มักเป็นอีเมลของบัญชีผู้ส่ง |
| **รหัสผ่าน SMTP** | รหัสผ่านของบัญชีผู้ส่ง | หน้าจอไม่แสดงรหัสผ่านที่บันทึกไว้ กด **เปลี่ยนรหัสผ่าน** (หรือ **ตั้งรหัสผ่าน**) เพื่อพิมพ์ใหม่ ตอนแก้ไข ถ้าปล่อยว่าง = ใช้รหัสผ่านเดิม หน้านี้ลบรหัสผ่านออกจากโปรไฟล์ที่มีอยู่ไม่ได้ |
| **Implicit TLS** | วิธีเข้ารหัสการเชื่อมต่อ ตั้งตามที่ผู้ให้บริการอีเมลบอก | ติ๊กเมื่อใช้พอร์ต 465 ถ้าใช้พอร์ต 587 ปกติให้เอาติ๊กออก |
| **ใช้งาน** | เปิดหรือปิดโปรไฟล์ | ถ้าปิดโปรไฟล์ที่ยังมีอีเมลส่งผ่านอยู่ ระบบจะเตือนว่ากี่ประเภทจะส่งไม่ได้ ให้ย้ายการจับคู่ไปโปรไฟล์อื่นก่อน |
| **หมายเหตุ** | บันทึกสำหรับผู้ดูแล | เช่น ใครเป็นเจ้าของกล่องอีเมลนี้ ใช้ผู้ให้บริการรายใด |

**กล่องส่งเมลทดสอบ**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ผู้รับ** | อีเมลที่จะรับอีเมลทดสอบ | เว้นว่าง = ส่งไปที่อีเมลของคุณ |

## งานที่ทำบ่อย

**ทดสอบว่าโปรไฟล์ส่งอีเมลได้จริง**

1. ที่การ์ดของโปรไฟล์ กดปุ่ม **ส่งเมลทดสอบ**
2. ในกล่อง **ส่งเมลทดสอบ** พิมพ์อีเมลที่ **ผู้รับ** หรือเว้นว่างเพื่อส่งถึงตัวเอง
3. กดปุ่ม **ส่งเมลทดสอบ**
4. ระบบแสดงข้อความ "ส่งไปที่ ... แล้ว — ตรวจกล่องขาเข้าและ spam" ตรวจกล่องอีเมลของผู้รับ
5. ถ้าส่งไม่สำเร็จ ข้อความจะบอกสาเหตุ เช่น **เชื่อมต่อ SMTP ไม่สำเร็จ — ตรวจ host, port, TLS และรหัสผ่าน** ให้ตรวจข้อมูลในการ์ดกับผู้ให้บริการอีเมล

อีเมลทดสอบส่งออกทันทีที่กดปุ่ม

**เปลี่ยนรหัสผ่านเซิร์ฟเวอร์ส่งอีเมล**

1. ที่การ์ดของโปรไฟล์ กดปุ่ม **แก้ไข**
2. ที่ **รหัสผ่าน SMTP** กดปุ่ม **เปลี่ยนรหัสผ่าน**
3. พิมพ์รหัสผ่านใหม่
4. กดปุ่ม **บันทึก**
5. ส่งเมลทดสอบเพื่อยืนยันว่ารหัสใหม่ใช้ได้

**ให้อีเมลแจ้งเตือนส่งจากโปรไฟล์อื่น**

1. กดปุ่ม **แก้ไขการจับคู่**
2. กดป้าย **Notification** แล้วเลือกโปรไฟล์ที่ต้องการ
3. กดปุ่ม **บันทึกการแก้ไข** ระบบแสดงข้อความ **บันทึกการจับคู่อีเมลแล้ว**

## ข้อควรระวัง

::: warning ยกเลิกการตั้งค่าโปรไฟล์
**ยกเลิกการตั้งค่า** ลบโปรไฟล์นี้ออก หลังจากนั้นอีเมลที่เคยส่งผ่านโปรไฟล์นี้จะกลับไปใช้ค่าตั้งของเซิร์ฟเวอร์ที่ทีมระบบตั้งไว้ ถ้าไม่ได้ตั้งไว้ อีเมลประเภทนั้นจะหยุดส่ง ถ้าจะสร้างโปรไฟล์นี้ใหม่ ต้องกรอกข้อมูลรวมทั้งรหัสผ่านใหม่ทั้งหมด
:::

- อย่าส่งรหัสผ่าน SMTP ทางแชตหรืออีเมล ให้พิมพ์ลงในหน้านี้โดยตรง
- ถ้ายังไม่ได้เลือกโปรไฟล์เริ่มต้น หน้าจอจะเตือนว่ามีอีเมลบางประเภทยังไม่มีผู้ส่ง อีเมลประเภทนั้นจะส่งไม่ได้จนกว่าจะเลือก
- การเปลี่ยนการจับคู่หรือข้อมูลโปรไฟล์มีผลกับอีเมลถัดไปที่ระบบส่ง อีเมลที่ส่งไปแล้วไม่เปลี่ยน
