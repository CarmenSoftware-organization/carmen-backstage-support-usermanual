# สวิตช์ฟีเจอร์

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **Platform** > **สวิตช์ฟีเจอร์**

::: tip ใครเห็นหน้านี้
เมนูนี้แสดงเฉพาะผู้ดูแลระบบสูงสุด (Super Admin) และผู้ที่บทบาทได้รับสิทธิ์จัดการสวิตช์ฟีเจอร์ ในค่าตั้งต้นของระบบ สิทธิ์นี้มีเฉพาะบทบาท Platform Admin ผู้ใช้อื่นไม่เห็นเมนูนี้ ถ้าเปิดลิงก์ตรง จะเจอหน้า [ไม่มีสิทธิ์เข้าถึง](/getting-started/common-actions#access-denied)
:::

**สวิตช์ฟีเจอร์** (Feature Flags — ตัวกำหนดว่าแต่ละเมนูจะแสดงอย่างไร) ใช้ซ่อนหรือปิดเมนูที่ยังไม่พร้อมใช้งาน การตั้งค่านี้มีผลกับ **ทุกคน** ที่ใช้ระบบหลังบ้านนี้ รวมถึงผู้ดูแลระบบสูงสุดและตัวคุณเอง ไม่ใช่เฉพาะบทบาทใดบทบาทหนึ่ง

แต่ละเมนูมีสามสถานะ:

| สถานะ | ผลที่ผู้ใช้เห็น |
| --- | --- |
| **ใช้งาน** | ทำงานตามปกติ |
| **เร็ว ๆ นี้** | เห็นเมนูเป็นสีจางพร้อมป้าย **เร็ว ๆ นี้** แต่กดไม่ได้ ถ้าเปิดลิงก์ตรงจะเจอหน้า [กำลังพัฒนา](/getting-started/common-actions#coming-soon) |
| **ซ่อน** | ไม่เห็นเมนูเลย ถ้าเปิดลิงก์ตรงจะเจอหน้า [ไม่พบหน้านี้](/getting-started/common-actions#not-found) |

สวิตช์นี้เปลี่ยนเฉพาะสิ่งที่แสดงบนหน้าจอผู้ดูแลนี้ ไม่ได้ปิดการทำงานของระบบเบื้องหลัง และไม่กระทบเว็บ Carmen Blue ที่โรงแรมใช้

## สิ่งที่ทำได้ในหน้านี้

- **อ่านสถานะ:** เมนูจัดกลุ่มเรียงตามเมนูด้านซ้าย (**องค์กร**, **จัดการใบอนุญาต**, **เนื้อหา** และอื่น ๆ) รวมถึงกลุ่ม **การดูแลคลัสเตอร์** ซึ่งเป็นเมนูของผู้ดูแล Cluster ใต้ชื่อเมนูมีรหัสภาษาอังกฤษของเมนูนั้น
- **เปลี่ยนสถานะ:** กดปุ่ม **ใช้งาน**, **เร็ว ๆ นี้** หรือ **ซ่อน** ในแถวของเมนู
- **บันทึก:** กดปุ่ม **บันทึกการแก้ไข** มุมขวาบน การเปลี่ยนจะยังไม่มีผลจนกว่าจะกดบันทึก ถ้าออกจากหน้าก่อนบันทึก ระบบจะเตือน ดู [เตือนเมื่อยังไม่ได้บันทึก](/getting-started/common-actions#unsaved-changes)
- **ลบคีย์ที่ไม่รู้จัก:** ถ้ามีการ์ด **คีย์ที่ไม่รู้จัก** (ค่าที่บันทึกไว้ของเมนูที่โปรแกรมรุ่นนี้ไม่มีแล้ว) กด **ลบ** แล้วยืนยัน จากนั้นกด **บันทึกการแก้ไข** การลบเกิดจริงตอนบันทึก

บางหน้าไม่มีสวิตช์โดยตั้งใจ เพื่อไม่ให้ระบบล็อกตัวเอง ได้แก่ **Dashboard**, หน้านี้เอง (**สวิตช์ฟีเจอร์**), โปรไฟล์ และหน้าเข้าสู่ระบบ คุณจึงกลับมาที่หน้านี้เพื่อเปิดเมนูคืนได้เสมอ

## อธิบายช่องข้อมูล

หน้านี้ไม่มีฟอร์มให้กรอก แต่ละแถวมีปุ่มเลือกสถานะสามปุ่มตามตารางด้านบน

## งานที่ทำบ่อย

**ซ่อนเมนูที่ยังไม่พร้อมให้ใช้**

1. หาแถวของเมนูนั้นในกลุ่มที่ตรงกับเมนูด้านซ้าย
2. กดปุ่ม **เร็ว ๆ นี้** (ถ้าอยากให้ผู้ใช้รู้ว่ากำลังจะมา) หรือ **ซ่อน** (ถ้าไม่อยากให้เห็นเลย)
3. กดปุ่ม **บันทึกการแก้ไข**
4. ระบบแสดงข้อความ **บันทึกสถานะฟีเจอร์แล้ว** เมนูด้านซ้ายของคุณเปลี่ยนทันที

**เปิดเมนูคืน**

1. หาแถวของเมนูนั้น
2. กดปุ่ม **ใช้งาน**
3. กดปุ่ม **บันทึกการแก้ไข**

ผู้ใช้คนอื่นที่เปิดระบบค้างไว้อาจยังเห็นเมนูแบบเดิม จนกว่าจะโหลดหน้าใหม่

## ข้อควรระวัง

::: warning ซ่อนแล้วไม่มีใครเข้าหน้านั้นได้
**ซ่อน** เอาเมนูออกจากเมนูด้านซ้ายของทุกคน และทำให้ลิงก์ตรงไปยังหน้านั้นขึ้น **ไม่พบหน้านี้** ทั้งสำหรับผู้ดูแลระบบสูงสุดและตัวคุณเอง ลิงก์ที่บันทึกไว้หรือส่งต่อกันจะใช้ไม่ได้ทันที ก่อนซ่อนเมนูที่มีคนใช้อยู่ เช่น **ไลเซนส์** หรือ **ผู้ใช้งาน** ให้แจ้งทีมก่อน ถ้าซ่อนผิด กลับมาที่หน้านี้แล้วเลือก **ใช้งาน** ได้เสมอ
:::

- **เร็ว ๆ นี้** และ **ซ่อน** ไม่ได้ปิดการทำงานเบื้องหลัง งานตามเวลาหรือโปรแกรมอื่นที่ใช้ข้อมูลของเมนูนั้นยังทำงานตามปกติ
- การเปลี่ยนในหน้านี้ไม่ได้เปลี่ยนสิทธิ์ของใคร ถ้าต้องการให้บางคนไม่เห็นเมนู ให้ปรับที่ [บทบาท](/screens/platform/platform-roles) แทน
