# ไลเซนส์

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **จัดการใบอนุญาต** > **ไลเซนส์**

**ไลเซนส์** (License — สิ่งที่ลูกค้าซื้อไว้) ของลูกค้าแต่ละรายมีหลายแบบ หน้านี้รวมทุกแบบไว้ที่เดียว:

- **สัญญา** (Subscription — สัญญาการใช้งานของหน่วยธุรกิจหนึ่งแห่ง มีวันเริ่ม วันสิ้นสุด และชุดฟีเจอร์ที่ซื้อ)
- **ไลเซนส์ที่นั่ง** (จำนวนผู้ใช้ที่หน่วยธุรกิจหนึ่งมีได้)
- **โควตา BU** (จำนวนหน่วยธุรกิจ หรือโรงแรม ที่ **Cluster** หนึ่งสร้างได้ — Cluster คือกลุ่มโรงแรมของลูกค้าหนึ่งราย)
- **ใบสิทธิ์ interface** (สิทธิ์ให้หน่วยธุรกิจเชื่อมต่อกับระบบภายนอก เช่น ระบบบัญชี)

ใช้หน้านี้เพื่อดูภาพรวมของทั้งระบบ เปิดดูไลเซนส์ของ Cluster ใด Cluster หนึ่ง และเพิ่มหรือแก้ไลเซนส์ ขั้นตอนเพิ่มไลเซนส์แต่ละแบบอธิบายไว้ใน [จัดการ License](/guides/manage-license) หน้านี้จึงอธิบายเฉพาะว่าหน้าจอมีอะไร และลิงก์ไปที่ส่วนนั้นของคู่มือ

## สิ่งที่ทำได้ในหน้านี้

**หน้าแรก (ไลเซนส์)**

- **ดูความจุรวมทั้งระบบ:** กล่องด้านบนแสดงจำนวนหน่วยธุรกิจและผู้ใช้ที่ใช้อยู่เทียบกับที่ซื้อไว้ จำนวน Cluster ที่ **ใช้งาน** จำนวนที่ **ใกล้เต็ม** และจำนวน **โควตา BU ใกล้หมดอายุ** กดตัวเลข **โควตา BU ใกล้หมดอายุ** เพื่อให้ตารางแท็บ **ตามคลัสเตอร์** แสดงเฉพาะ Cluster เหล่านั้น
- **สลับมุมมอง** ด้วยแท็บ 5 แท็บ คือข้อมูลชุดเดียวกันที่จัดคนละแบบ:
  - **ตามคลัสเตอร์:** หนึ่งแถวต่อหนึ่ง Cluster แสดงโควตา BU ที่นั่ง วันที่โควตาหมดอายุ และสถานะ
  - **ตามสัญญา:** สัญญาทั้งหมดของทุก Cluster มีปุ่ม **เพิ่มสัญญา**
  - **ตามไลเซนส์ที่นั่ง**, **ตามโควตา BU**, **ตามใบสิทธิ์ interface:** ใบแต่ละแบบของทุก Cluster ด้านบนมีแถบสรุปจำนวนตามสถานะ
- **ค้นหา** Cluster ด้วยชื่อหรือรหัส หรือค้นหาใบด้วยเลขที่ไลเซนส์หรือเลขที่อ้างอิง ดู [ค้นหา](/getting-started/common-actions#search)
- **กรอง** ในแท็บ **ตามคลัสเตอร์** กรองตามสถานะ และ **สถานะไลเซนส์** (**ไม่มีไลเซนส์**, **เกินโควตา BU**, **ที่นั่งเต็ม**) หรือเปิด **โควตาใกล้หมดอายุ** ถ้าเลือกหลายตัว Cluster ต้องตรงทุกตัว ดู [ตัวกรอง](/getting-started/common-actions#filters)
- **ส่งออก** รายการเป็นไฟล์ CSV ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **เปิดหน้าไลเซนส์ของ Cluster:** กดรหัสของ Cluster (ตัวอักษรสีน้ำเงิน)
- **ดูใบที่ลบแล้ว** (เฉพาะผู้ดูแลระบบสูงสุด): ในแท็บอื่นที่ไม่ใช่ **ตามคลัสเตอร์** กดการ์ด **ลบแล้ว** ในแถบสรุป รายการจะเปลี่ยนเป็นใบที่ลบแล้ว และแต่ละแถวมีปุ่ม **กู้คืน** และ **ลบถาวร** กด **กลับรายการปกติ** เพื่อออก

**หน้าไลเซนส์ของ Cluster**

- **แถบสรุป:** จำนวนหน่วยธุรกิจเทียบกับโควตา จำนวนที่นั่ง และจำนวนสัญญา ด้านขวาบอกเรื่องที่ต้องจัดการ เช่น เกินโควตา หรือสัญญาใกล้หมดอายุ ถ้าไม่มีจะขึ้นว่า **ไม่มีเรื่องต้องจัดการ**
- **แท็บโควตา BU:** กล่อง **ไลเซนส์โควตา BU** แสดงโควตาที่มีผลอยู่และใบทั้งหมด ปุ่ม **เพิ่มไลเซนส์โควตา BU** และในแต่ละแถวมี **แก้ไข**, **ยกเลิกใบ**, **นำออก** ด้านล่างมีกล่อง **หน่วยธุรกิจ** เรียงลำดับแบบเดียวกับที่ระบบใช้ตัดสินว่าโรงแรมไหนอยู่ในโควตา คือหน่วยธุรกิจที่เป็นสำนักงานใหญ่ (HQ) ก่อน แล้วตามด้วยหน่วยที่สร้างไว้นานที่สุด หน่วยที่อันดับเกินโควตาจะมีป้าย **เกินโควตา** และอ่านได้อย่างเดียวจนกว่าจะซื้อโควตาเพิ่ม
- **แท็บที่นั่ง:** หนึ่งแถบต่อหนึ่งหน่วยธุรกิจ พร้อมปุ่ม **เพิ่มไลเซนส์ที่นั่ง** และใบที่นั่งแต่ละใบมี **แก้ไข** และ **นำออก**
- **แท็บสัญญา:** สัญญาของหน่วยธุรกิจใน Cluster นี้ พร้อมปุ่ม **เพิ่มสัญญา** กด **แก้ไข** ที่แถวเพื่อเปิดหน้าของสัญญา (ในแท็บ **ตามสัญญา** ของหน้าแรก กดเลขที่สัญญาได้เลย)

**หน้าของสัญญาหรือหน้าของใบ**

- **สัญญา:** แก้ช่วงวันที่และสถานะในกล่อง **แก้ไขสัญญา** เลือกชุดฟีเจอร์ในกล่อง **กลุ่มสิทธิ์ที่ซื้อ** และปุ่ม **ลบ** ท้ายหน้า
- **ใบที่นั่ง / ใบโควตา BU / ใบสิทธิ์ interface:** แก้จำนวน ช่วงคุ้มครอง และเลขที่อ้างอิงในกล่อง **แก้ไขใบนี้** ใบโควตา BU มีปุ่ม **ยกเลิกใบ** ท้ายหน้า ใบสิทธิ์ interface มีปุ่ม **ลบ** ท้ายหน้า

## อธิบายช่องข้อมูล

ช่องที่มี `*` บนหน้าจอจำเป็นต้องกรอก เลขที่ของสัญญาและของใบ ระบบออกให้เองเมื่อบันทึก

**ฟอร์มเพิ่มสัญญา**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **Cluster** (จำเป็น) | Cluster ของลูกค้า | ถ้าเปิดจากหน้าไลเซนส์ของ Cluster ระบบเลือกไว้ให้แล้ว |
| **หน่วยธุรกิจ** (จำเป็น) | โรงแรมที่ได้สัญญานี้ | สัญญาหนึ่งใบผูกกับหน่วยธุรกิจเดียว และย้ายไปหน่วยอื่นทีหลังไม่ได้ |
| **วันที่เริ่ม**, **วันที่สิ้นสุด** (จำเป็น) | ช่วงสัญญา | นับรวมทั้งวันเริ่มและวันสิ้นสุด เช่น เริ่ม 1 ม.ค. ครบหนึ่งปีคือสิ้นสุด 31 ธ.ค. กดปุ่มเดือนใต้ **ระยะที่ใช้บ่อย** เพื่อเลือกวันสิ้นเดือนนั้นได้เร็วขึ้น |

**หน้าของสัญญา (หลังสร้างแล้ว)**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **วันที่เริ่ม**, **วันที่สิ้นสุด** | ช่วงสัญญา | แก้ได้ในกล่อง **แก้ไขสัญญา** |
| **สถานะ** | สถานะของสัญญา | **ใช้งาน**, **ไม่ใช้งาน** หรือ **หมดอายุ** |
| **กลุ่มสิทธิ์ที่ซื้อ** | ชุดฟีเจอร์ที่ลูกค้าซื้อ | ติ๊กได้หลายชุด ตัวเลขข้างชื่อคือจำนวนฟีเจอร์ในชุด ดู [กลุ่มสิทธิ์ license](/screens/license/license-feature-groups) |

**ฟอร์มไลเซนส์ที่นั่ง โควตา BU และใบสิทธิ์ interface**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **หน่วยธุรกิจ** หรือ **Cluster** | เจ้าของใบ | ระบบใส่ให้จากหน้าที่คุณกดมา แก้ไม่ได้ ในฟอร์มโควตา BU ช่อง **Cluster** แสดงรหัสภายในของ Cluster |
| **เลขที่ไลเซนส์** | เลขที่ของใบ | ระบบออกให้เองเมื่อบันทึก |
| **ที่นั่ง** (จำเป็น, ใบที่นั่ง) | จำนวนผู้ใช้ที่ซื้อในใบนี้ | เช่น `10` ใบที่ใช้งานอยู่หลายใบของโรงแรมเดียวกันนับรวมกัน |
| **โควตา BU** (จำเป็น, ใบโควตา BU) | จำนวนหน่วยธุรกิจทั้งหมดที่ Cluster มีได้ | เช่น `3` ระบบไม่นับรวมหลายใบ แต่ใช้ใบเดียว ดูข้อควรระวัง |
| **กลุ่มสิทธิ์** (จำเป็น, ใบสิทธิ์ interface) | ระบบภายนอกที่จะเชื่อมต่อ | เลือกได้เฉพาะกลุ่มชนิด Interface ที่ **ขายอยู่** |
| **เลขที่อ้างอิง** | เลขจากเอกสารการซื้อ | ไม่บังคับ เช่น เลขที่ใบสั่งซื้อ |
| **มีวันหมดอายุ** / **ไม่มีวันหมดอายุ** | ใบนี้มีวันสิ้นสุดหรือไม่ | มีในใบโควตา BU และใบสิทธิ์ interface ใบที่นั่งต้องมีวันสิ้นสุดเสมอ |
| **วันที่เริ่ม** (จำเป็น), **วันที่สิ้นสุด** | ช่วงคุ้มครอง | **วันที่สิ้นสุด** จำเป็นเมื่อเลือก **มีวันหมดอายุ** |
| **หมายเหตุ** | ข้อความเพิ่มเติม | ไม่บังคับ มีในใบโควตา BU และใบสิทธิ์ interface |

หลังสร้างใบแล้ว แก้ได้เฉพาะจำนวน (หรือกลุ่มสิทธิ์) ช่วงคุ้มครอง และเลขที่อ้างอิง เจ้าของใบและเลขที่ใบแก้ไม่ได้ ใบที่ถูกยกเลิกแล้วแก้ไม่ได้อีก ถ้าต้องการเปลี่ยนให้ออกใบใหม่

## งานที่ทำบ่อย

**ดูว่าลูกค้ารายหนึ่งซื้ออะไรไว้บ้าง**

1. ที่แท็บ **ตามคลัสเตอร์** พิมพ์ชื่อหรือรหัสของ Cluster ในช่องค้นหา
2. กดรหัสของ Cluster
3. อ่านแถบสรุปด้านบน แล้วกดแท็บ **โควตา BU**, **ที่นั่ง** และ **สัญญา** เพื่อดูรายละเอียด

ดูภาพประกอบได้ที่ [จัดการ License ส่วนที่ 1](/guides/manage-license#open)

**เพิ่มไลเซนส์**

- สัญญาและชุดฟีเจอร์: [จัดการ License ส่วนที่ 2](/guides/manage-license#subscription)
- ที่นั่ง: [จัดการ License ส่วนที่ 3](/guides/manage-license#seats)
- โควตา BU: [จัดการ License ส่วนที่ 4](/guides/manage-license#bu-quota)
- ใบสิทธิ์ interface (เพิ่มจากแท็บ **ไลเซนส์** ของหน่วยธุรกิจ): [จัดการ License ส่วนที่ 5](/guides/manage-license#interface)

**แก้ใบที่มีอยู่**

1. ที่หน้าไลเซนส์ของ Cluster กด **แก้ไข** ที่แถวของใบ หรือกดเลขที่ของใบในแท็บ **ตามไลเซนส์ที่นั่ง**, **ตามโควตา BU** หรือ **ตามใบสิทธิ์ interface**
2. แก้ค่าในกล่อง **แก้ไขใบนี้** แถบ **มีการแก้ไขที่ยังไม่บันทึก** จะขึ้นที่ด้านล่าง
3. กดปุ่ม **บันทึกการแก้ไข**

**กู้คืนใบที่ลบไปแล้ว** (เฉพาะผู้ดูแลระบบสูงสุด)

1. ที่หน้าแรกของไลเซนส์ กดแท็บของใบแบบนั้น เช่น **ตามไลเซนส์ที่นั่ง**
2. กดการ์ด **ลบแล้ว** ในแถบสรุป ข้อความ **กำลังดูใบที่ลบแล้ว** จะขึ้น
3. ที่แถวของใบ กด **กู้คืน** แล้วยืนยัน ใบจะกลับมาใช้งานได้อีกครั้ง

## ข้อควรระวัง

::: warning ยกเลิกใบโควตา BU ย้อนกลับไม่ได้
ปุ่ม **ยกเลิกใบ** มีเฉพาะใบโควตา BU ใบที่ยกเลิกยังอยู่ในรายการเพื่อตรวจย้อนหลังได้ แต่ไม่ให้โควตาอีกต่อไป และเปิดกลับไม่ได้ ถ้าใบนั้นเป็นใบที่ให้โควตาอยู่ กล่องยืนยันจะบอกว่าโควตาของ Cluster จะเปลี่ยนจากเท่าไรเป็นเท่าไรทันที
:::

::: warning ลบถาวรย้อนกลับไม่ได้
ผู้ดูแลระบบสูงสุดลบใบถาวรได้จากรายการใบที่ลบแล้ว และลบใบโควตา BU ที่ยกเลิกแล้วได้จากแท็บ **ตามโควตา BU** (ปุ่มถังขยะท้ายแถว) ต้องพิมพ์เลขที่ใบเพื่อยืนยัน ข้อมูลจะหายจริง และเลขที่ใบนั้นจะไม่ถูกออกซ้ำอีก
:::

- **นำออก** (ใบที่นั่งและใบโควตา BU) และ **ลบ** (สัญญาและใบสิทธิ์ interface) จะซ่อนใบจากรายการ ผู้ดูแลระบบสูงสุดกู้คืนได้ แต่มีผลทันที: ถ้านำใบที่นั่งที่ใช้อยู่ออก ที่นั่งเหล่านั้นจะหายจากโรงแรมทันที ถ้านำใบโควตา BU ที่ใช้อยู่ออก Cluster จะสร้างหน่วยธุรกิจใหม่ไม่ได้จนกว่าจะมีใบอื่นมาแทน
- ใบที่นั่งหลายใบที่ใช้งานพร้อมกันนับรวมกัน แต่ใบโควตา BU ไม่นับรวม ระบบใช้ใบเดียว คือใบที่เริ่มล่าสุด ใบอื่นจะขึ้นสถานะ **ถูกแทนที่** ดูรายละเอียดใน [จัดการ License ส่วนที่ 4](/guides/manage-license#bu-quota)
- ใบสิทธิ์ interface ใช้ได้เฉพาะเมื่อสัญญาหลักของโรงแรมยังใช้งานอยู่ ถ้าสัญญาหลักหมดอายุ การเชื่อมต่อจะปิด แม้วันที่ของใบยังไม่หมด
- สัญญาย้ายไปหน่วยธุรกิจอื่นไม่ได้ ถ้าสร้างผิดแห่ง ให้สร้างสัญญาใหม่ให้หน่วยธุรกิจที่ถูกต้อง

- [ตั้งค่าโรงแรมใหม่](/guides/setup-hotel) ส่วนที่ 3 เพิ่มที่นั่ง และส่วนที่ 4 สร้างสัญญาให้โรงแรมใหม่
- [หน่วยธุรกิจ](/screens/organization/business-units) แท็บ **ไลเซนส์** ของโรงแรม
