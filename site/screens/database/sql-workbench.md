# SQL Workbench

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **ฐานข้อมูล** > **SQL Workbench**

หน้านี้ใช้สั่งงาน **ฐานข้อมูลของโรงแรมแห่งหนึ่งโดยตรง** โดยพิมพ์คำสั่งภาษา **SQL** (ภาษาที่ใช้ขอดูหรือแก้ข้อมูลในฐานข้อมูล) บนหน้าจอเรียกฐานข้อมูลของโรงแรมว่า **tenant** (ฐานข้อมูลของโรงแรมแต่ละแห่ง) แต่ละ **หน่วยธุรกิจ** (Business Unit — โรงแรมหรือสาขาหนึ่งแห่ง) มีฐานข้อมูลของตัวเอง คุณทำงานกับได้ครั้งละหนึ่งแห่ง

คำสั่ง SQL แบ่งได้เป็นสองแบบ

- **คำสั่งขอดูข้อมูล** ขึ้นต้นด้วย `SELECT` (หรือ `WITH`) แค่อ่านข้อมูลมาแสดง ไม่เปลี่ยนอะไรในฐานข้อมูล <!-- plain-ok -->
- **คำสั่งเปลี่ยนข้อมูล** เช่น `INSERT` (เพิ่ม), `UPDATE` (แก้), `DELETE` (ลบแถว), `TRUNCATE` (ล้างทั้งตาราง), `CREATE` / `ALTER` / `DROP` (สร้าง แก้ หรือลบโครงสร้าง) คำสั่งเหล่านี้เปลี่ยนข้อมูลจริงของโรงแรมทันที <!-- plain-ok -->

**ใครใช้หน้านี้และเมื่อไร:** เป็นเครื่องมือของทีมเทคนิค ใช้ตรวจหาสาเหตุเมื่อโรงแรมแจ้งว่าข้อมูลผิดปกติ หรือเมื่อทีมเทคนิคต้องสร้างรายงานพิเศษ งานประจำวัน เช่น แก้ข้อมูลผู้ใช้หรือหน่วยธุรกิจ ให้ทำที่หน้าของงานนั้น อย่าใช้หน้านี้แทน เพราะหน้าปกติตรวจความถูกต้องให้ แต่หน้านี้ไม่ตรวจ

## สิ่งที่ทำได้ในหน้านี้

- **เลือกหน่วยธุรกิจ:** กด **เลือก BU** (หรือ **เปลี่ยน** เมื่อเลือกไว้แล้ว) หรือกด Ctrl+B (Mac: ⌘B) แล้วค้นหาด้วยรหัส ชื่อ หรือ Cluster แถบบนจะแสดงรหัสและชื่อของโรงแรมที่กำลังทำงานด้วย ตรวจแถบนี้ทุกครั้งก่อนรันคำสั่ง
- **ดูป้ายสิทธิ์ในแถบบน:**
  - **อ่าน / เขียน** (สีส้ม): คุณรันคำสั่ง บันทึก และลบได้
  - **อ่านอย่างเดียว:** บทบาทของคุณให้ดูได้อย่างเดียว ปุ่ม **รัน**, **บันทึก** และ **ลบ** จะไม่แสดง แม้แต่คำสั่งขอดูข้อมูลก็รันไม่ได้ คุณดูรายการและเปิดดูคำสั่งที่บันทึกไว้ได้เท่านั้น
- **ดูรายการ Database Objects:** รายการสิ่งที่อยู่ในฐานข้อมูลของโรงแรม แบ่งเป็นสามกลุ่ม ค้นหาได้จากช่องด้านบน
  - **Table** คือตารางที่เก็บข้อมูลจริง กดชื่อตาราง ระบบจะใส่คำสั่งขอดูข้อมูล 100 แถวแรกของตารางนั้นลงในช่องพิมพ์ให้ แต่ยังไม่รัน
  - **View** คือคำสั่งขอดูข้อมูลที่บันทึกไว้ เรียกดูได้เหมือนตาราง
  - **Procedure / Function** คือชุดคำสั่งที่บันทึกไว้ในฐานข้อมูลเพื่อเรียกใช้ซ้ำ
  - กดชื่อ View, Procedure หรือ Function ระบบจะเปิดคำสั่งของรายการนั้นในช่องพิมพ์ และแสดงว่า **กำลังแก้ไข:** ตามด้วยชื่อ
- **พิมพ์และจัดการคำสั่ง:** แถบเหนือช่องพิมพ์มีปุ่ม **รัน** (Ctrl+Enter หรือ ⌘+Enter), **จัดรูปแบบ** (จัดย่อหน้าให้อ่านง่าย), **ค้นหา** (Ctrl+F หรือ ⌘+F) และ **ล้าง** (ล้างช่องพิมพ์) ด้านขวาบอกจำนวนบรรทัดและจำนวนคำสั่ง
- **รัน:** ถ้าคุณเลือกข้อความไว้ ระบบจะรันเฉพาะข้อความที่เลือก ถ้าไม่ได้เลือก ระบบจะรันเฉพาะคำสั่งที่เคอร์เซอร์อยู่ (คำสั่งแต่ละคำสั่งคั่นด้วย `;`)
- **อ่านผลลัพธ์:** แผง **ผลลัพธ์** แสดงจำนวนแถว จำนวนคอลัมน์ และเวลาที่ใช้ ถ้ารันหลายคำสั่งพร้อมกัน จะเห็นผลของคำสั่งสุดท้ายเท่านั้น ถ้าคำสั่งผิด แผงจะขึ้น **ผิดพลาด** พร้อมข้อความจากฐานข้อมูล
- **ส่งออกผลลัพธ์เป็นไฟล์ CSV:** ปุ่ม **CSV** ในแผงผลลัพธ์ ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **ปรับขนาด:** ลากเส้นแบ่งระหว่างช่องพิมพ์กับแผงผลลัพธ์ ดับเบิลคลิกเพื่อคืนค่าเดิม เบราว์เซอร์จะจำขนาดไว้
- **บันทึก:** บันทึกคำสั่งในช่องพิมพ์เป็น View, Stored Procedure หรือ Function ในฐานข้อมูลของโรงแรม ดูช่องข้อมูลด้านล่าง
- **ลบ:** ลบ View, Procedure หรือ Function ที่เปิดอยู่ออกจากฐานข้อมูลของโรงแรม ปุ่มนี้แสดงเฉพาะเมื่อเปิดรายการจาก **Database Objects**
- เมื่อเปลี่ยนหน่วยธุรกิจ ช่องพิมพ์และผลลัพธ์จะถูกล้างทั้งหมด ถ้าต้องการเก็บคำสั่งไว้ ให้คัดลอกไปเก็บก่อน

## อธิบายช่องข้อมูล

ช่องเหล่านี้อยู่ในแถบเหนือช่องพิมพ์ ใช้เฉพาะตอนกด **บันทึก** การรันคำสั่งธรรมดาไม่ต้องกรอก

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ชื่อวัตถุ** | ชื่อของ View, Stored Procedure หรือ Function ที่จะบันทึก | เช่น `v_pr_summary` จำเป็นเมื่อบันทึก **View** ที่พิมพ์แค่คำสั่งขอดูข้อมูล ถ้าเว้นว่างจะขึ้น **กรุณากรอกชื่อของ view** |
| **ประเภท** (รายการเลือกข้างช่องชื่อ) | บันทึกเป็น **View**, **Stored Procedure** หรือ **Function** | ค่าเริ่มต้นคือ **View** Stored Procedure และ Function ต้องพิมพ์คำสั่งสร้างแบบเต็ม (ขึ้นต้นด้วย `CREATE OR REPLACE`) <!-- plain-ok --> |
| ช่องพิมพ์คำสั่ง (จำเป็น) | คำสั่ง SQL ที่จะรันหรือบันทึก | ถ้าว่างแล้วกด **บันทึก** จะขึ้น **กรุณากรอก SQL** |

## งานที่ทำบ่อย

**ขอดูข้อมูลในตาราง (ไม่เปลี่ยนข้อมูล)**

1. กด **เลือก BU** แล้วเลือกโรงแรม
2. ตรวจรหัสโรงแรมในแถบบนให้ถูกต้อง
3. ในรายการ **Table** กดชื่อตารางที่ต้องการ ระบบจะใส่คำสั่งขอดู 100 แถวแรกให้
4. กด **รัน**
5. อ่านผลในแผง **ผลลัพธ์** ถ้าต้องการเก็บไว้ กด **CSV**

ตัวอย่างคำสั่งขอดูข้อมูลที่ปลอดภัย

```sql
SELECT * FROM tb_activity LIMIT 100;
```

**รันคำสั่งที่เปลี่ยนข้อมูล (เมื่อทีมเทคนิคให้คำสั่งมา)**

1. เลือกโรงแรม แล้วตรวจรหัสในแถบบนอีกครั้ง
2. วางคำสั่งที่ได้รับลงในช่องพิมพ์ อย่าแก้ไขเอง
3. เลือกข้อความคำสั่งทั้งหมดที่จะรัน แล้วกด **รัน**
4. ถ้าคำสั่งขึ้นต้นด้วย `DROP`, `TRUNCATE`, `DELETE`, `UPDATE`, `ALTER`, `GRANT` หรือ `REVOKE` ระบบจะถามว่า **รัน SQL ที่ทำลายข้อมูลหรือไม่** และบอกว่าจะรันกับฐานข้อมูลของโรงแรมใด อ่านให้ดี แล้วกด **ยืนยันรัน** <!-- plain-ok -->
5. ดูผลในแผง **ผลลัพธ์** ว่าสำเร็จหรือขึ้น **ผิดพลาด**

**บันทึก View ใหม่ (เมื่อได้รับมอบหมาย)**

1. พิมพ์คำสั่งขอดูข้อมูลในช่องพิมพ์ แล้วกด **รัน** เพื่อตรวจว่าผลถูกต้อง
2. กรอก **ชื่อวัตถุ**
3. เลือกประเภท **View**
4. กด **บันทึก** ระบบจะขึ้นว่าบันทึกแล้ว และรายการใหม่จะขึ้นใน **Database Objects**

**ลบ View, Procedure หรือ Function (เมื่อได้รับมอบหมาย)**

1. กดชื่อรายการใน **Database Objects** เพื่อเปิด
2. ตรวจว่าแถบเหนือช่องพิมพ์ขึ้น **กำลังแก้ไข:** ตามด้วยชื่อที่ถูกต้อง
3. กด **ลบ**
4. กล่องยืนยันจะบอกชื่อรายการและโรงแรม กด **ลบ**

## ข้อควรระวัง

::: warning คำสั่งเปลี่ยนข้อมูลมีผลทันทีและย้อนกลับไม่ได้
เมื่อกด **รัน** คำสั่งเปลี่ยนข้อมูลจะเปลี่ยนข้อมูลจริงของโรงแรมทันที ไม่มีปุ่มย้อนกลับ และหน้านี้ไม่ตรวจว่าข้อมูลที่แก้ถูกต้องตามหลักของระบบหรือไม่ ผู้ใช้ของโรงแรมจะเห็นผลทันที รันเฉพาะคำสั่งที่ทีมเทคนิคให้มา และตรวจรหัสโรงแรมในแถบบนทุกครั้ง
:::

::: warning ระบบไม่ได้ถามยืนยันทุกคำสั่ง
ระบบถามยืนยันเฉพาะคำสั่งที่ขึ้นต้นด้วย `DROP`, `TRUNCATE`, `DELETE`, `UPDATE`, `ALTER`, `GRANT` หรือ `REVOKE` คำสั่งที่เปลี่ยนข้อมูลแบบอื่น เช่น `INSERT` (เพิ่มข้อมูล) หรือ `CREATE` (สร้าง) จะรันทันทีโดยไม่ถาม <!-- plain-ok -->
:::

::: warning คำสั่ง DELETE หรือ UPDATE ที่ไม่มี WHERE มีผลกับทุกแถว
`WHERE` คือส่วนที่บอกว่าจะแก้หรือลบแถวไหน ถ้าไม่มี คำสั่งจะแก้หรือลบ **ทุกแถว** ในตาราง กล่องยืนยันจะเตือนว่า **คำสั่ง DELETE/UPDATE ไม่มี WHERE clause จะมีผลกับข้อมูลทุกแถว** ถ้าเห็นข้อความนี้ ให้กดยกเลิก แล้วตรวจคำสั่งกับทีมเทคนิค <!-- plain-ok -->
:::

::: warning บันทึก ทับของเดิมโดยไม่ถาม
ถ้ามี View, Procedure หรือ Function ชื่อเดียวกันอยู่แล้ว ปุ่ม **บันทึก** จะเขียนทับของเดิมทันทีโดยไม่ถามยืนยัน รายงานหรือหน้าจอที่ใช้ของเดิมจะเปลี่ยนตาม
:::

::: warning ลบ แล้วกู้คืนไม่ได้
ปุ่ม **ลบ** ลบ View, Procedure หรือ Function ออกจากฐานข้อมูลของโรงแรมอย่างถาวร กล่องยืนยันบอกว่า **ย้อนกลับไม่ได้** ถ้ารายงานหรือหน้าจอใดใช้รายการนั้นอยู่ จะใช้งานไม่ได้
:::

- **รันหลายคำสั่งพร้อมกัน:** ถ้าคำสั่งใดในชุดผิดพลาด ระบบจะยกเลิกทั้งชุด ไม่มีคำสั่งใดในชุดนั้นมีผล
- **คำสั่งที่ใช้เวลานาน:** แต่ละคำสั่งรันได้ไม่เกินประมาณ 30 วินาที ถ้าเกิน ระบบจะหยุดคำสั่งนั้นและแสดงข้อผิดพลาด
- **ปิดหน้าระหว่างรัน:** คำสั่งยังรันต่อในฐานข้อมูลของโรงแรมจนเสร็จหรือจนครบเวลา แต่คุณจะไม่เห็นผล อย่ากดรันซ้ำเพื่อดูผล ให้ใช้คำสั่งขอดูข้อมูลตรวจว่าข้อมูลเปลี่ยนแล้วหรือยัง
- ถ้าบนหน้าจอขึ้นคำว่า **schema** เช่นในข้อความหลังบันทึก หมายถึงส่วนของฐานข้อมูลที่เป็นของโรงแรมนี้ <!-- plain-ok -->

## คู่มือที่เกี่ยวข้อง

ยังไม่มีคู่มือแบบทีละขั้นสำหรับหน้านี้ เพราะเป็นงานของทีมเทคนิค หน้าที่เกี่ยวข้อง:

- [หน่วยธุรกิจ](/screens/organization/business-units) รหัสและชื่อของโรงแรมที่เลือกในหน้านี้
- [Tenant Migrations](/screens/organization/tenant-migrations) อัปเดตโครงสร้างฐานข้อมูลของโรงแรมด้วยวิธีที่ปลอดภัยกว่า
- [Database Pools](/screens/database/database-pools) ฐานข้อมูลของโรงแรมแต่ละแห่งเก็บอยู่ที่ไหน
