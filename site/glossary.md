# อภิธานศัพท์

หน้านี้รวมคำที่ใช้ในระบบและในคู่มือ พร้อมความหมายแบบสั้น ๆ คอลัมน์ **ป้ายภาษาไทย** และ **ป้ายภาษาอังกฤษ** คือคำที่เห็นบนหน้าจอเมื่อเลือกภาษานั้น

::: tip หน้าจอภาษาไทยใช้คำไม่ตรงกันในบางที่
บางคำบนหน้าจอภาษาไทยมีหลายแบบ เช่น เมนู **ไลเซนส์** อยู่ใต้กลุ่ม **จัดการใบอนุญาต** และบางที่เขียนว่า **license** ทั้งสามคำหมายถึงสิ่งเดียวกัน คู่มือนี้ใช้คำตามที่เห็นบนหน้าจอ และรวมทุกแบบไว้ในตารางด้านล่าง
:::

## องค์กรและผู้ใช้

| ป้ายภาษาไทย | ป้ายภาษาอังกฤษ | ความหมาย |
| --- | --- | --- |
| **Cluster**, คลัสเตอร์ | Cluster, Clusters | กลุ่มโรงแรมหรือกลุ่มบริษัทของลูกค้าหนึ่งราย รวมหน่วยธุรกิจหลายแห่งไว้ด้วยกัน ดู [Clusters](/screens/organization/clusters) |
| **หน่วยธุรกิจ**, BU | Business Unit, BU | โรงแรมหรือสาขาหนึ่งแห่ง อยู่ภายใต้ Cluster เดียว ดู [หน่วยธุรกิจ](/screens/organization/business-units) |
| **HQ** | HQ | หน่วยธุรกิจที่เป็นสำนักงานใหญ่ของ Cluster |
| **Tenant** | Tenant | ฐานข้อมูลของโรงแรมแต่ละแห่ง หน่วยธุรกิจแต่ละแห่งมีฐานข้อมูลของตัวเอง แยกจากแห่งอื่น |
| **Migration**, Tenant Migrations | Migration, Tenant Migrations | การอัปเดตโครงสร้างฐานข้อมูลของแต่ละโรงแรมให้ตรงกับระบบรุ่นล่าสุด ดู [Tenant Migrations](/screens/organization/tenant-migrations) |
| **Tenant Seed Data**, ข้อมูลตั้งต้นของ tenant | Tenant Seed Data | ข้อมูลตั้งต้นที่ฐานข้อมูลของทุกโรงแรมต้องมีก่อนเริ่มใช้งาน ดู [Tenant Seed Data](/screens/organization/tenant-seeds) |
| **นำเข้าข้อมูล** | Data Import | การโหลดข้อมูลหลักของโรงแรมจากไฟล์ Excel ที่เตรียมไว้ เข้าไปในฐานข้อมูลของหน่วยธุรกิจ ดู [นำเข้าข้อมูล](/screens/organization/data-import) |
| **ผู้ใช้งาน** | Users | บัญชีของทุกคนที่ใช้ Carmen เช่น พนักงานโรงแรม แต่ละบัญชีผูกกับ Cluster และหน่วยธุรกิจที่เข้าได้ ดู [ผู้ใช้งาน](/screens/organization/users) |
| **ผู้ดูแล** / **ผู้ใช้** (บทบาทใน Cluster หรือหน่วยธุรกิจ) | Admin / User | ระดับของผู้ใช้ภายใน Cluster หรือหน่วยธุรกิจหนึ่ง ผู้ดูแลจัดการผู้ใช้คนอื่นในที่นั้นได้ ผู้ใช้ทั่วไปใช้งานได้อย่างเดียว |
| **มุมมองผู้ดูแล Cluster** | Cluster Admin view | หน้าจอแบบย่อสำหรับคนที่ดูแลเฉพาะ Cluster ของตัวเอง เปิดได้จากเมนูผู้ใช้ที่มุมขวาบน |

## ใบอนุญาต (ไลเซนส์)

| ป้ายภาษาไทย | ป้ายภาษาอังกฤษ | ความหมาย |
| --- | --- | --- |
| **ไลเซนส์**, **ใบอนุญาต**, license | License, Licenses, License Management | สิ่งที่ลูกค้าซื้อไว้ เช่น จำนวนโรงแรม จำนวนผู้ใช้ ฟีเจอร์ที่ใช้ได้ และการเชื่อมต่อกับระบบภายนอก ดู [ไลเซนส์](/screens/license/licenses) |
| **สัญญา** | Subscription | สัญญาการใช้งานของหน่วยธุรกิจ มีวันเริ่มและวันสิ้นสุด และบอกว่าหน่วยธุรกิจนั้นใช้กลุ่มฟีเจอร์ใดได้ |
| **ที่นั่ง**, ไลเซนส์ที่นั่ง | Seats, Seat license | จำนวนผู้ใช้ที่หน่วยธุรกิจหนึ่งมีได้ |
| **โควตา BU** | BU Quota | จำนวนหน่วยธุรกิจที่ Cluster หนึ่งสร้างได้ |
| **ใบสิทธิ์ interface** | Interface license | สิทธิ์ให้หน่วยธุรกิจเชื่อมต่อกับระบบภายนอก เช่น ระบบขายหน้าร้าน ระบบจัดการโรงแรม หรือระบบบัญชี |
| **กลุ่มสิทธิ์ license** | License Feature Groups | ชุดฟีเจอร์ที่จัดไว้ล่วงหน้า ใช้เลือกตอนขายสัญญาหรือใบสิทธิ์ interface ดู [กลุ่มสิทธิ์ license](/screens/license/license-feature-groups) |
| **ทั่วไป** / **Interface** (ชนิดของกลุ่มสิทธิ์) | Standard / Interface | กลุ่มชนิดทั่วไปใช้กับสัญญา กลุ่มชนิด Interface ใช้กับใบสิทธิ์ interface |
| **ฟีเจอร์ที่ขายได้**, feature | License Features | ความสามารถแต่ละอย่างของ Carmen ที่ขายให้ลูกค้าได้ ระบบสร้างรายการให้เอง คุณเลือกได้เพียงว่าขายได้หรือยัง ดู [ฟีเจอร์ที่ขายได้](/screens/license/license-features) |
| **ความจุรวมทั้งระบบ**, fleet | Fleet capacity | ภาพรวมของทุก Cluster รวมกัน ว่าใช้ไปเท่าไรจากที่ซื้อไว้ |
| **ใกล้เต็ม** | Near limit | ใช้ไปเกือบครบจำนวนที่ซื้อไว้แล้ว |
| **ใกล้หมดอายุ**, **หมดอายุ** | Expiring soon, Expired | สัญญาหรือใบอนุญาตที่ใกล้ถึงวันสิ้นสุด หรือเลยวันสิ้นสุดแล้ว |

## เนื้อหาที่ส่งถึงผู้ใช้

| ป้ายภาษาไทย | ป้ายภาษาอังกฤษ | ความหมาย |
| --- | --- | --- |
| **เทมเพลตรายงาน** | Report Templates | แม่แบบของรายงานที่โรงแรมเปิดดูหรือพิมพ์จาก Carmen ดู [เทมเพลตรายงาน](/screens/content/report-templates) |
| **กลุ่มฟอร์ม** | Form Groups | ชุดแบบฟอร์มสำหรับพิมพ์เอกสารแต่ละประเภท และแบบที่ใช้เป็นค่าเริ่มต้นของแต่ละกลุ่ม ดู [กลุ่มฟอร์ม](/screens/content/form-groups) |
| **แม่แบบแดชบอร์ด** | Dashboard Templates | กล่องข้อมูลบนหน้าแดชบอร์ดของแต่ละหน่วยธุรกิจ และแดชบอร์ดเริ่มต้นที่ติดตั้งให้หน่วยธุรกิจ ดู [แม่แบบแดชบอร์ด](/screens/content/dashboard-templates) |
| **ข่าวสาร** | News | บทความหรือข่าวที่ผู้ใช้เปิดอ่านเองได้ มี 3 สถานะ คือ ร่าง เผยแพร่ และเก็บถาวร ดู [ข่าวสาร](/screens/content/news) |
| **ประกาศ** | Broadcasts | ข้อความแจ้งเตือนที่ส่งตรงถึงผู้ใช้ทุกคน รายชื่อที่เลือก หรือทุกคนในหน่วยธุรกิจหนึ่ง และมีวันหมดอายุเสมอ ดู [ประกาศ](/screens/content/broadcasts) |

## Platform: ตั้งค่าระบบและสิทธิ์

| ป้ายภาษาไทย | ป้ายภาษาอังกฤษ | ความหมาย |
| --- | --- | --- |
| **ตั้งค่า**, ตั้งค่า Platform | Platform Config | ค่าตั้งที่มีผลกับทั้งระบบ เช่น การเชิญผู้ใช้ การตั้งรหัสผ่านใหม่ และการเตือนก่อนหมดอายุ เปลี่ยนแล้วมีผลโดยไม่ต้องรอติดตั้งระบบใหม่ ดู [ตั้งค่า](/screens/platform/platform-config) |
| **ตั้งค่าอีเมล** | Email Settings | ข้อมูลผู้ส่งที่ระบบใช้ส่งอีเมลออก และอีเมลแต่ละประเภทใช้ผู้ส่งรายใด ดู [ตั้งค่าอีเมล](/screens/platform/email-settings) |
| **แอปพลิเคชัน** | Applications | โปรแกรมที่ได้รับอนุญาตให้เชื่อมต่อกับ Carmen เช่น เว็บหรือแอปบนมือถือ ดู [แอปพลิเคชัน](/screens/platform/applications) |
| **App ID** | App ID | รหัสประจำแอปพลิเคชันแต่ละตัว ระบบใช้รหัสนี้เพื่อรู้ว่าการเชื่อมต่อมาจากโปรแกรมใด |
| **บทบาท** | Platform Roles | ชุดสิทธิ์ที่กำหนดว่าผู้ที่ได้รับบทบาทนี้ทำอะไรในระบบหลังบ้านได้บ้าง ดู [บทบาท](/screens/platform/platform-roles) |
| **สิทธิ์** | Permission | การอนุญาตให้ทำสิ่งหนึ่งในหน้าจอหนึ่ง เช่น ดู สร้าง แก้ไข หรือลบ บทบาทหนึ่งรวมสิทธิ์หลายอย่างไว้ |
| **ผู้ใช้**, ผู้ใช้ Platform | Platform Users | ผู้ใช้ที่ได้รับบทบาทแล้ว จึงเข้าใช้ระบบหลังบ้านนี้ได้ ดู [ผู้ใช้](/screens/platform/platform-users) |
| **ผู้ดูแลระบบสูงสุด** | Super Admins | ผู้ที่ทำได้ทุกอย่างในระบบ โดยไม่ต้องตรวจสิทธิ์ใด ๆ ดู [ผู้ดูแลระบบสูงสุด](/screens/platform/super-admins) |
| **สวิตช์ฟีเจอร์** | Feature Flags | ตัวกำหนดว่าแต่ละเมนูจะแสดงอย่างไร: **ใช้งาน** (ใช้ได้ปกติ) **เร็ว ๆ นี้** (เห็นเมนูแต่กดไม่ได้) หรือ **ซ่อน** (ไม่เห็นเลย) ดู [สวิตช์ฟีเจอร์](/screens/platform/feature-flags) |

## สถานะและคำสั่งที่พบบ่อย

| ป้ายภาษาไทย | ป้ายภาษาอังกฤษ | ความหมาย |
| --- | --- | --- |
| **ใช้งาน** / **ไม่ใช้งาน** | Active / Inactive | เปิดใช้อยู่ / ปิดไว้ชั่วคราว ข้อมูลยังอยู่ครบ เปิดกลับได้ |
| **ลบ**, ลบแล้ว, ลบชั่วคราว, ถูกลบชั่วคราว | Delete, Deleted, soft-deleted | รายการถูกซ่อนจากตาราง แต่ยังดูได้ด้วยตัวกรอง **ลบแล้ว** บางหน้าจอกู้คืนได้ <!-- plain-ok --> |
| **ลบถาวร** | Delete permanently, Hard Delete | ลบออกจากระบบทั้งหมด กู้คืนไม่ได้ <!-- plain-ok --> |
| **กู้คืน** | Restore | นำรายการที่ลบไว้กลับมาใช้อีกครั้ง |
| **เก็บถาวร**, เก็บถาวรแล้ว | Archive, Archived | เก็บรายการที่ไม่ใช้แล้วออกจากรายการหลัก โดยไม่ลบทิ้ง ข้อยกเว้น: ในกล่องสรุปของหน้า **ผู้ใช้งาน** ตัวเลข **เก็บถาวรแล้ว** คือจำนวนผู้ใช้ที่ถูกลบ |
| **เร็ว ๆ นี้**, กำลังพัฒนา | Coming soon | เมนูหรือหน้าที่ยังไม่เปิดให้ใช้ |
| **ไม่มีสิทธิ์เข้าถึง** | Access Denied | บทบาทของคุณไม่อนุญาตให้เปิดหน้านี้ |
| **ส่งออก**, ส่งออก CSV | Export, Export CSV | ดาวน์โหลดรายการเป็นไฟล์ที่เปิดด้วย Excel ได้ |
