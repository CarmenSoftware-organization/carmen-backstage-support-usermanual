# รู้จักหน้าจอหลัก

หลังเข้าสู่ระบบ คุณจะเห็นหน้าจอหลักแบบนี้ทุกครั้ง หน้าจอแบ่งเป็น 4 ส่วน คือ เมนูด้านซ้าย แถบด้านบน พื้นที่ทำงานตรงกลาง และแถบด้านล่าง

![หน้าจอหลักหลังเข้าสู่ระบบ](/screenshots/th/main-screen.png)

## เมนูด้านซ้าย

| กลุ่ม | ใช้ทำอะไร | เมนูในกลุ่ม |
| --- | --- | --- |
| (ไม่มีหัวข้อ) | หน้าแรกหลังเข้าสู่ระบบ สรุปสิ่งที่เพิ่งเปลี่ยนแปลง | [Dashboard](/screens/dashboard) |
| **องค์กร** | ดูแลกลุ่มโรงแรม โรงแรมแต่ละแห่ง ฐานข้อมูลของแต่ละโรงแรม และผู้ใช้งาน | [Clusters](/screens/organization/clusters), [หน่วยธุรกิจ](/screens/organization/business-units), [Tenant Migrations](/screens/organization/tenant-migrations) (อัปเดตโครงสร้างฐานข้อมูลของแต่ละโรงแรม), [Tenant Seed Data](/screens/organization/tenant-seeds) (ข้อมูลตั้งต้นของฐานข้อมูลแต่ละโรงแรม), [นำเข้าข้อมูล](/screens/organization/data-import), [ผู้ใช้งาน](/screens/organization/users) |

คุณจะเห็นเฉพาะเมนูที่บทบาทของคุณอนุญาต เมนู **ผู้ดูแลระบบสูงสุด** และ **Migration แพลตฟอร์ม** แสดงเฉพาะผู้ดูแลระบบสูงสุด (Super Admin — ผู้ที่ทำได้ทุกอย่างในระบบ) เท่านั้น ส่วนเมนูที่ถูกปิดด้วย [สวิตช์ฟีเจอร์](/screens/platform/feature-flags) (Feature Flags — ตัวกำหนดว่าแต่ละเมนูจะแสดงหรือไม่) จะไม่แสดงเลย หรือแสดงเป็นสีจางพร้อมป้าย **เร็ว ๆ นี้** และกดไม่ได้
:::

### ย่อและขยายเมนู

ถ้าต้องการพื้นที่ทำงานกว้างขึ้น ให้ย่อเมนูด้านซ้ายให้เหลือแต่ไอคอน

1. กด **ย่อเมนู** ที่ด้านล่างสุดของเมนูซ้าย
2. เมนูจะเหลือแต่ไอคอน ชี้เมาส์ที่ไอคอนเพื่อดูชื่อเมนู
3. กดปุ่มเดิมที่ด้านล่างสุดอีกครั้งเพื่อขยายเมนูกลับ

![เมนูด้านซ้ายแบบย่อ](/screenshots/th/sidebar-collapsed.png)

ระบบจำไว้ว่าคุณย่อหรือขยายเมนู ครั้งหน้าที่เปิดจะเป็นแบบเดิม

บนจอขนาดเล็ก เช่น โทรศัพท์ เมนูซ้ายจะซ่อนอยู่ ให้กดปุ่มเมนูที่มุมซ้ายบนเพื่อเปิด

## แถบด้านบน

แถบด้านบนมีส่วนต่าง ๆ จากซ้ายไปขวา ดังนี้

- **เส้นทางนำทาง**: บอกว่าตอนนี้คุณอยู่หน้าไหน เช่น **ผู้ใช้งาน > แก้ไข** กดชื่อหน้าก่อนหน้าเพื่อย้อนกลับ
- **ปุ่มสลับภาษา** (ไอคอนตัวอักษร): สลับหน้าจอระหว่างภาษาไทยและภาษาอังกฤษ
- **ปุ่มเปลี่ยนธีม** (ไอคอนดวงอาทิตย์หรือดวงจันทร์): เลือกได้ 3 แบบ
  - **สว่าง**: พื้นหลังสีอ่อน
  - **มืด**: พื้นหลังสีเข้ม สบายตาเวลากลางคืน
  - **ตามระบบ**: ใช้ตามการตั้งค่าของเครื่องคุณ
- **เมนูผู้ใช้** (ชื่อของคุณ): ดูหัวข้อถัดไป

### เมนูผู้ใช้

กดชื่อของคุณที่มุมขวาบนเพื่อเปิดเมนูผู้ใช้

![เมนูผู้ใช้ที่มุมขวาบน](/screenshots/th/profile-menu-open.png)

- ด้านบนสุดแสดงชื่อและอีเมลของคุณ
- **มุมมองผู้ดูแล Cluster**: สลับไปหน้าจอแบบย่อ สำหรับดูแลเฉพาะ Cluster (กลุ่มโรงแรม) ที่คุณรับผิดชอบ แสดงเฉพาะเมื่อคุณเป็นผู้ดูแล Cluster ใดอยู่ เมื่ออยู่ในหน้าจอนั้นแล้ว เมนูนี้จะเปลี่ยนเป็น **มุมมองผู้ดูแล Platform** เพื่อกลับมาหน้าจอหลัก
- **โปรไฟล์**: ดูและแก้ข้อมูลของคุณเอง และเปลี่ยนรหัสผ่าน ดู [โปรไฟล์](/screens/profile)
- **ออกจากระบบ**: ออกจากระบบ

## พื้นที่ทำงานตรงกลาง

ส่วนตรงกลางแสดงหน้าที่คุณเลือกจากเมนู ด้านบนสุดของทุกหน้ามีชื่อหน้าและคำอธิบายสั้น ๆ ปุ่มหลักของหน้า เช่น **เพิ่มผู้ใช้** หรือ **ส่งออก** อยู่ทางขวาของชื่อหน้า

วิธีใช้รายการ ช่องค้นหา ตัวกรอง และการแก้ไขข้อมูล อธิบายไว้ที่ [การใช้งานทั่วไป](./common-actions)

## แถบด้านล่าง

- ด้านซ้าย: เวอร์ชันของระบบ (**แอป** และ **API**) ใช้แจ้งทีมสนับสนุนเมื่อพบปัญหา
- ด้านขวา: วันที่และเวลาปัจจุบันตามเครื่องของคุณ

## ปุ่มลัดคีย์บอร์ด

กดปุ่ม <kbd>?</kbd> บนคีย์บอร์ด (ขณะไม่ได้พิมพ์อยู่ในช่องใด) เพื่อดูรายการปุ่มลัด

![หน้าต่างปุ่มลัดคีย์บอร์ด](/screenshots/th/keyboard-shortcuts.png)

| ปุ่ม | ใช้ทำอะไร |
| --- | --- |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> (บน Mac ใช้ <kbd>⌘</kbd> + <kbd>S</kbd>) | บันทึกการแก้ไข (ในโหมดแก้ไข) |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> (บน Mac ใช้ <kbd>⌘</kbd> + <kbd>K</kbd>) | ไปที่ช่องค้นหา (ในหน้ารายการ) |
| <kbd>Esc</kbd> | ปิดกล่องโต้ตอบหรือยกเลิกการแก้ไข |
| <kbd>?</kbd> | แสดงปุ่มลัดคีย์บอร์ด |
