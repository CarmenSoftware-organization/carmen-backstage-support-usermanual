# ตั้งค่าโรงแรมใหม่

## สิ่งที่คุณจะทำได้

คู่มือนี้พาคุณเปิดใช้งานลูกค้ารายใหม่ตั้งแต่ต้นจนพนักงานคนแรกเข้าใช้งานได้ เมื่อทำครบ คุณจะได้

- **Cluster** (กลุ่มโรงแรมของลูกค้าหนึ่งราย) พร้อมโควตาว่าสร้างโรงแรมได้กี่แห่ง
- **หน่วยธุรกิจ** (Business Unit — โรงแรมหรือสาขาหนึ่งแห่ง) หนึ่งแห่งใน Cluster นั้น
- **ที่นั่ง** (จำนวนผู้ใช้ที่หน่วยธุรกิจนี้มีได้) สำหรับโรงแรมนั้น
- พนักงานหนึ่งคนที่อยู่ใน Cluster และหน่วยธุรกิจ พร้อมบทบาท

**ใครทำได้:** ผู้ดูแลระบบสูงสุด หรือผู้ที่มีบทบาท (Platform Role — ชุดสิทธิ์ที่บอกว่าคุณทำอะไรได้บ้าง) ที่ให้จัดการ Clusters หน่วยธุรกิจ และไลเซนส์ได้

**สิ่งที่ต้องเตรียม**

- ชื่อและรหัสของลูกค้า เช่น ชื่อ "Grand Hotel Group" รหัส `GHG`
- ชื่อโรงแรม เช่น "Grand Hotel Bangkok"
- จำนวนโรงแรมที่ลูกค้าซื้อ และวันหมดอายุ (ถ้ามี)
- จำนวนผู้ใช้ที่ลูกค้าซื้อ และช่วงวันที่ของสัญญา
- บัญชีของพนักงานที่จะเข้าใช้งาน ถ้ายังไม่มี ให้สร้างก่อนตาม [เพิ่มผู้ใช้](/guides/add-user)

::: tip ชื่อในภาพตัวอย่าง
ภาพในคู่มือนี้ใช้ชื่อตัวอย่างที่ขึ้นต้นด้วย `MANUAL-DEMO-` เวลาทำจริง ให้ใช้ชื่อจริงของลูกค้าและโรงแรม
:::

## ขั้นตอน

### ส่วนที่ 1: สร้าง Cluster

1. ที่เมนูด้านซ้าย กด **Clusters**
2. กดปุ่ม **เพิ่ม Cluster** ที่มุมขวาบน ฟอร์มสร้าง Cluster จะเปิดขึ้น

   ![ฟอร์มสร้าง Cluster ที่ยังว่าง](/screenshots/th/guide-setup-hotel-01-cluster-form-empty.png)

3. ในกล่อง **ข้อมูลระบุตัวตน** กรอก **รหัส** เช่น `GHG` ใช้ตัวอักษรภาษาอังกฤษ ตัวเลข `-` หรือ `_` ยาว 2–20 ตัว
4. กรอก **ชื่อ** เช่น "Grand Hotel Group" ช่อง **ชื่อแฝง** ไม่บังคับ ถ้ากรอก ใช้ตัวอักษรหรือตัวเลขไม่เกิน 3 ตัว
5. ในกล่อง **ใบโควตาใบแรก** กรอกช่อง **หน่วยธุรกิจ** เป็นจำนวนโรงแรมที่ลูกค้าซื้อ เช่น `2`
6. เลือก **วันหมดอายุ** ของโควตา หรือติ๊ก **ไม่มีวันหมดอายุ** ถ้าโควตานี้ใช้ได้ตลอด การ์ดด้านขวาจะแสดงตัวอย่างของ Cluster ที่กำลังสร้าง

   ![ฟอร์มที่กรอกครบแล้ว และการ์ดตัวอย่างด้านขวา](/screenshots/th/guide-setup-hotel-02-cluster-form-filled.png)

7. กดปุ่ม **สร้าง Cluster** ระบบจะแสดงข้อความ **สร้าง Cluster สำเร็จ** และเปิดหน้าของ Cluster ใหม่ ด้านขวาบนบอกว่าสร้างหน่วยธุรกิจได้อีกกี่แห่ง

   ![หน้าของ Cluster ใหม่หลังสร้างสำเร็จ](/screenshots/th/guide-setup-hotel-03-cluster-created.png)

### ส่วนที่ 2: สร้างหน่วยธุรกิจ (โรงแรม)

8. ที่เมนูด้านซ้าย กด **หน่วยธุรกิจ** แล้วกดปุ่ม **เพิ่มหน่วยธุรกิจ** แถบด้านล่างจะบอกว่ายังต้องกรอกอะไร เช่น **ยังต้องกรอก: ชื่อ, Cluster**

   ![ฟอร์มสร้างหน่วยธุรกิจ แท็บทั่วไป](/screenshots/th/guide-setup-hotel-04-bu-form-empty.png)

9. กดที่หัวข้อ **(หน่วยธุรกิจที่ยังไม่มีชื่อ)** แล้วพิมพ์ชื่อโรงแรม เช่น "Grand Hotel Bangkok"
10. ที่แถว **Cluster** กด **ตั้งค่า cluster...** แล้วเลือก Cluster ที่สร้างในส่วนที่ 1

    ![ใส่ชื่อโรงแรมและเลือก Cluster แล้ว](/screenshots/th/guide-setup-hotel-05-bu-form-filled.png)

11. แท็บ **ที่ตั้ง** และ **รูปแบบ** ใช้กรอกที่อยู่และรูปแบบการแสดงผลของโรงแรม กรอกตอนนี้หรือภายหลังก็ได้
12. แท็บ **เทคนิค** มีกล่อง **การเชื่อมต่อฐานข้อมูล** ซึ่งบอกว่าโรงแรมนี้เก็บข้อมูลไว้ที่ไหน ให้ปล่อยไว้ตามเดิม ทีมเทคนิคจะเป็นผู้ตั้งค่าส่วนนี้

    ![แท็บเทคนิค กล่องการเชื่อมต่อฐานข้อมูล (ภาพนี้ปิดค่าไว้)](/screenshots/th/guide-setup-hotel-06-bu-technical.png)

    ::: warning อย่าเปลี่ยนการเชื่อมต่อฐานข้อมูลเอง
    ถ้าตั้งค่าในกล่องนี้ผิด โรงแรมอาจเปิดข้อมูลของตัวเองไม่ได้ หรือไปเชื่อมกับฐานข้อมูลที่ไม่ใช่ของตัวเอง ถ้าไม่แน่ใจ ให้ปล่อยว่างไว้และแจ้งทีมเทคนิค
    :::

13. กดปุ่ม **สร้างหน่วยธุรกิจ** ที่แถบด้านล่าง ระบบจะแสดงข้อความ **สร้าง หน่วยธุรกิจ สำเร็จ** หน่วยธุรกิจได้รหัสที่ขึ้นต้นด้วย `BU-` และมีแท็บ **ผู้ใช้งาน** กับ **ไลเซนส์** เพิ่มขึ้นมา

    ![หน้าของหน่วยธุรกิจใหม่หลังสร้างสำเร็จ](/screenshots/th/guide-setup-hotel-07-bu-created.png)

### ส่วนที่ 3: เพิ่มที่นั่งให้โรงแรม

14. เปิดหน้าของ Cluster (เมนู **Clusters** แล้วกดชื่อ Cluster) แล้วกดปุ่ม **จัดการไลเซนส์** หน้าไลเซนส์ของ Cluster จะเปิดที่แท็บ **โควตา BU** คุณจะเห็นใบโควตาที่สร้างพร้อม Cluster และรายชื่อโรงแรมใน Cluster

    ![หน้าไลเซนส์ของ Cluster แท็บโควตา BU](/screenshots/th/guide-setup-hotel-08-license-center.png)

15. กดแท็บ **ที่นั่ง** แถวของโรงแรมใหม่จะขึ้นว่า **ไม่มีใบที่นั่ง**

    ![แท็บที่นั่ง โรงแรมใหม่ยังไม่มีที่นั่ง](/screenshots/th/guide-setup-hotel-09-seats-tab-empty.png)

16. กดปุ่ม **เพิ่มไลเซนส์ที่นั่ง** ที่แถวของโรงแรม
17. กรอกช่อง **ที่นั่ง** เป็นจำนวนผู้ใช้ที่ลูกค้าซื้อ เช่น `5`
18. เลือก **วันที่เริ่ม** และ **วันที่สิ้นสุด** ตามสัญญา ช่อง **เลขที่อ้างอิง** ไม่บังคับ ใช้ใส่เลขที่ใบสั่งซื้อได้ ส่วน **เลขที่ไลเซนส์** ระบบออกให้เองเมื่อบันทึก

    ![ฟอร์มเพิ่มไลเซนส์ที่นั่งที่กรอกแล้ว](/screenshots/th/guide-setup-hotel-10-seat-form-filled.png)

19. กดปุ่ม **สร้างไลเซนส์**
20. กลับไปที่หน้าไลเซนส์ของ Cluster แล้วกดแท็บ **ที่นั่ง** แถวของโรงแรมจะแสดงจำนวนที่นั่ง และมีใบที่นั่งสถานะ **ใช้งาน**

    ![แท็บที่นั่งหลังเพิ่มใบที่นั่งแล้ว](/screenshots/th/guide-setup-hotel-11-seat-license-added.png)

### ส่วนที่ 4: ใส่พนักงานเข้า Cluster และโรงแรม

ผู้ใช้ต้องอยู่ใน Cluster ก่อน จึงจะเพิ่มเข้าหน่วยธุรกิจของ Cluster นั้นได้

21. เปิดหน้าของ Cluster แล้วกดแท็บ **ผู้ใช้งาน**
22. กดปุ่ม **เพิ่มผู้ใช้** กล่อง **เพิ่มผู้ใช้เข้า Cluster** จะเปิดขึ้น
23. พิมพ์ชื่อหรืออีเมลของพนักงาน แล้วกดเลือกชื่อที่ขึ้นมา
24. ที่ **บทบาทใน Cluster** เลือก **ผู้ใช้** (ใช้งานได้อย่างเดียว) หรือ **ผู้ดูแล** (จัดการผู้ใช้คนอื่นใน Cluster ได้) ใต้ช่องจะบอกว่าใช้ที่นั่งไปแล้วเท่าไร

    ![กล่องเพิ่มผู้ใช้เข้า Cluster ที่เลือกผู้ใช้แล้ว](/screenshots/th/guide-setup-hotel-12-cluster-add-user-dialog.png)

25. กดปุ่ม **เพิ่มผู้ใช้** ระบบจะแสดงข้อความ **เพิ่มผู้ใช้เข้า cluster แล้ว** และพนักงานจะอยู่ในรายชื่อ บัญชีของคนที่สร้าง Cluster อยู่ในรายชื่อตั้งแต่แรกแล้ว

    ![รายชื่อผู้ใช้ของ Cluster หลังเพิ่มแล้ว](/screenshots/th/guide-setup-hotel-13-cluster-user-added.png)

26. เปิดหน้าของหน่วยธุรกิจ (เมนู **หน่วยธุรกิจ** แล้วกดชื่อโรงแรม) แล้วกดแท็บ **ผู้ใช้งาน**
27. กดปุ่ม **เพิ่มผู้ใช้** กล่อง **เพิ่มผู้ใช้เข้าหน่วยธุรกิจ** จะเปิดขึ้น กล่องนี้เลือกได้เฉพาะคนที่อยู่ใน Cluster แล้ว
28. พิมพ์ชื่อหรืออีเมล แล้วกดเลือกชื่อที่ขึ้นมา
29. ที่ **บทบาท BU** เลือก **ผู้ดูแล** หรือ **ผู้ใช้**

    ![กล่องเพิ่มผู้ใช้เข้าหน่วยธุรกิจ เลือกบทบาทผู้ดูแล](/screenshots/th/guide-setup-hotel-14-bu-add-user-dialog.png)

30. กดปุ่ม **เพิ่มผู้ใช้** ระบบจะแสดงข้อความ **เพิ่มผู้ใช้เข้าหน่วยธุรกิจแล้ว**

    ![รายชื่อผู้ใช้ของหน่วยธุรกิจหลังเพิ่มแล้ว](/screenshots/th/guide-setup-hotel-15-bu-user-added.png)

## ตรวจสอบว่าสำเร็จ

- หน้าของ Cluster ด้านขวาบน แสดงจำนวนหน่วยธุรกิจที่ใช้ไปเทียบกับโควตา เช่น **1 / 2** และจำนวนที่นั่งที่ใช้ไป
- หน้าไลเซนส์ของ Cluster แถบสรุปด้านบนแสดงจำนวนที่นั่ง และไม่มีป้ายเตือน **1 BU ไม่มีที่นั่ง** แล้ว
- แท็บ **ผู้ใช้งาน** ของหน่วยธุรกิจ มีชื่อพนักงาน พร้อม **บทบาท BU** และสถานะ **ใช้งาน**

## แก้ปัญหาเบื้องต้น

- **มีข้อความสีแดงใต้ช่องรหัส:** รหัสต้องเป็นตัวอักษรภาษาอังกฤษ ตัวเลข `-` หรือ `_` ยาว 2–20 ตัว ห้ามมีช่องว่าง
- **มีข้อความสีแดงใต้ช่องชื่อแฝงของ Cluster:** ชื่อแฝงใช้ได้ไม่เกิน 3 ตัว และต้องเป็นตัวอักษรหรือตัวเลขเท่านั้น
- **กดสร้างหน่วยธุรกิจไม่ได้ และแถบด้านล่างขึ้นว่ายังต้องกรอก:** ใส่ชื่อโรงแรมและเลือก Cluster ให้ครบ
- **สร้างหน่วยธุรกิจไม่ได้ เพราะ Cluster ใช้โควตาครบแล้ว:** เพิ่มใบโควตา BU ตาม [จัดการ License](/guides/manage-license)
- **หาชื่อพนักงานไม่เจอในกล่องเพิ่มผู้ใช้เข้า Cluster:** บัญชีนั้นอาจยังไม่มี ให้สร้างก่อนตาม [เพิ่มผู้ใช้](/guides/add-user)
- **หาชื่อพนักงานไม่เจอในกล่องเพิ่มผู้ใช้เข้าหน่วยธุรกิจ:** ต้องเพิ่มคนนั้นเข้า Cluster ก่อน (ขั้นตอนที่ 21–25)
- **เพิ่มผู้ใช้เข้าหน่วยธุรกิจไม่ได้ เพราะไม่มีที่นั่งว่าง:** เพิ่มใบที่นั่งให้โรงแรมก่อน (ส่วนที่ 3)
- **ไม่เห็นเมนูหรือปุ่มที่คู่มือพูดถึง หรือขึ้นหน้าไม่มีสิทธิ์เข้าถึง:** บทบาทของคุณอาจไม่ครอบคลุมงานนี้ ดู [หน้าแจ้งว่าไม่มีสิทธิ์](/getting-started/common-actions#access-denied)
