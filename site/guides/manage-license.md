# จัดการ License

## สิ่งที่คุณจะทำได้

คู่มือนี้อธิบายวิธีบันทึกสิ่งที่ลูกค้าซื้อลงในระบบ เมื่อทำครบ คุณจะ

- เปิดดูสถานะไลเซนส์ (สิ่งที่ลูกค้าซื้อไว้) ของ **Cluster** (กลุ่มโรงแรมของลูกค้าหนึ่งราย) ได้
- สร้าง **สัญญา** (Subscription — สัญญาการใช้งานของโรงแรมหนึ่งแห่ง) และเลือกชุดฟีเจอร์ที่ลูกค้าซื้อ
- เพิ่ม **ที่นั่ง** (จำนวนผู้ใช้ที่โรงแรมมีได้)
- เพิ่ม **โควตา BU** (จำนวนโรงแรมที่ Cluster สร้างได้)
- เพิ่ม **ใบสิทธิ์ interface** (สิทธิ์ให้โรงแรมเชื่อมต่อกับระบบภายนอก เช่น ระบบบัญชี)
- สร้าง **กลุ่มสิทธิ์ license** (ชุดฟีเจอร์ที่จัดไว้ล่วงหน้า ใช้เลือกตอนขาย) ชุดใหม่

แต่ละส่วนทำแยกกันได้ ทำเฉพาะส่วนที่ต้องการก็ได้

**ใครทำได้:** ผู้ดูแลระบบสูงสุด หรือผู้ที่มีบทบาท (Platform Role — ชุดสิทธิ์ที่บอกว่าคุณทำอะไรได้บ้าง) ที่ให้จัดการไลเซนส์และกลุ่มสิทธิ์ license ได้

**สิ่งที่ต้องเตรียม**

- Cluster และหน่วยธุรกิจ (Business Unit — โรงแรมหรือสาขาหนึ่งแห่ง) ต้องมีอยู่แล้ว ถ้ายังไม่มี ดู [ตั้งค่าโรงแรมใหม่](/guides/setup-hotel)
- รายละเอียดจากใบสั่งซื้อหรือสัญญา เช่น จำนวนที่ซื้อ วันเริ่ม วันสิ้นสุด เลขที่ใบสั่งซื้อ และชุดฟีเจอร์ที่ซื้อ

::: tip ชื่อในภาพตัวอย่าง
ภาพในคู่มือนี้ใช้ชื่อตัวอย่างที่ขึ้นต้นด้วย `MANUAL-DEMO-` เวลาทำจริง คุณจะเห็นชื่อจริงของลูกค้า เช่น "Grand Hotel Group" และ "Grand Hotel Bangkok"
:::

## ขั้นตอน

### ส่วนที่ 1: เปิดหน้าไลเซนส์ของ Cluster

1. ที่เมนูด้านซ้าย กด **ไลเซนส์** ด้านบนของหน้าแสดง **ความจุรวมทั้งระบบ** คือภาพรวมของทุก Cluster รวมกัน
2. ที่แท็บ **ตามคลัสเตอร์** พิมพ์ชื่อหรือรหัสของ Cluster ในช่องค้นหา ดูเพิ่มเติมที่ [ค้นหา](/getting-started/common-actions#search)

   ![หน้าไลเซนส์ ค้นหา Cluster แล้ว](/screenshots/th/guide-manage-license-01-licenses-list.png)

3. กดรหัสของ Cluster (ตัวอักษรสีน้ำเงิน) หน้าไลเซนส์ของ Cluster จะเปิดขึ้น แถบด้านบนสรุปจำนวนโรงแรม ที่นั่ง และสัญญา และมีแท็บ **โควตา BU** **ที่นั่ง** และ **สัญญา**

   ![หน้าไลเซนส์ของ Cluster](/screenshots/th/guide-manage-license-02-license-center.png)

   อีกทางหนึ่ง คุณเปิดหน้านี้ได้จากหน้าของ Cluster โดยกดปุ่ม **จัดการไลเซนส์**

### ส่วนที่ 2: สร้างสัญญาและเลือกชุดฟีเจอร์

4. กดแท็บ **สัญญา** แล้วกดปุ่ม **เพิ่มสัญญา**

   ![แท็บสัญญาที่ยังไม่มีสัญญา](/screenshots/th/guide-manage-license-03-subscriptions-tab-empty.png)

5. ช่อง **Cluster** เลือกไว้ให้แล้ว เลือก **หน่วยธุรกิจ** ที่ทำสัญญา สัญญาหนึ่งใบผูกกับหน่วยธุรกิจเดียว และย้ายไปหน่วยธุรกิจอื่นภายหลังไม่ได้
6. เลือก **วันที่เริ่ม** และ **วันที่สิ้นสุด** หรือกดปุ่มเดือนใต้หัวข้อ **ระยะที่ใช้บ่อย** เพื่อเลือกช่วงเร็วขึ้น การ์ดด้านขวาแสดงว่าสัญญาครอบคลุมกี่เดือน

   ![ฟอร์มเพิ่มสัญญาที่กรอกแล้ว](/screenshots/th/guide-manage-license-04-subscription-form-filled.png)

7. กดปุ่ม **สร้างสัญญา** ระบบจะแสดงข้อความ **สร้าง สัญญา สำเร็จ** และเปิดหน้าของสัญญาใหม่ ซึ่งมีเลขที่ขึ้นต้นด้วย `SUB-` ในกล่อง **แก้ไขสัญญา** คุณแก้ได้เฉพาะช่วงวันที่และสถานะ

   ![หน้าของสัญญาใหม่](/screenshots/th/guide-manage-license-05-subscription-created.png)

8. ในกล่อง **กลุ่มสิทธิ์ที่ซื้อ** ติ๊กชุดฟีเจอร์ที่ลูกค้าซื้อ เช่น **Full Access** ตัวเลขข้างชื่อคือจำนวนฟีเจอร์ในชุดนั้น แถบด้านล่างจะขึ้นว่า **มีการแก้ไขที่ยังไม่บันทึก**

   ![ติ๊กชุดฟีเจอร์ที่ซื้อแล้ว ยังไม่บันทึก](/screenshots/th/guide-manage-license-06-subscription-groups-picked.png)

9. กดปุ่ม **บันทึกการแก้ไข** ระบบจะแสดงข้อความ **บันทึกการแก้ไขแล้ว**

   ![หน้าของสัญญาหลังบันทึก](/screenshots/th/guide-manage-license-07-subscription-saved.png)

### ส่วนที่ 3: เพิ่มที่นั่ง

10. กลับไปที่หน้าไลเซนส์ของ Cluster แล้วกดแท็บ **ที่นั่ง**
11. กดปุ่ม **เพิ่มไลเซนส์ที่นั่ง** ที่แถวของโรงแรม
12. กรอก **ที่นั่ง** เป็นจำนวนผู้ใช้ที่ซื้อเพิ่ม เช่น `10` และกรอก **เลขที่อ้างอิง** เช่น เลขที่ใบสั่งซื้อ (ไม่บังคับ)
13. เลือก **วันที่เริ่ม** และ **วันที่สิ้นสุด** ส่วน **เลขที่ไลเซนส์** ระบบออกให้เองเมื่อบันทึก

    ![ฟอร์มเพิ่มไลเซนส์ที่นั่งที่กรอกแล้ว](/screenshots/th/guide-manage-license-08-seat-form-filled.png)

14. กดปุ่ม **สร้างไลเซนส์**
15. กลับไปที่หน้าไลเซนส์ของ Cluster แล้วกดแท็บ **ที่นั่ง** ใบใหม่จะอยู่ใต้ชื่อโรงแรม พร้อมสถานะ **ใช้งาน**

    ![แท็บที่นั่งหลังเพิ่มใบใหม่](/screenshots/th/guide-manage-license-09-seats-added.png)

ถ้าโรงแรมมีใบที่นั่งหลายใบที่ใช้งานอยู่พร้อมกัน ระบบจะนับรวมกันทั้งหมด เช่น ใบละ 5 ที่นั่งสองใบ เท่ากับ 10 ที่นั่ง

### ส่วนที่ 4: เพิ่มโควตา BU

16. ที่หน้าไลเซนส์ของ Cluster แท็บ **โควตา BU** กดปุ่ม **เพิ่มไลเซนส์โควตา BU**
17. กรอก **โควตา BU** เป็นจำนวนโรงแรมทั้งหมดที่ Cluster นี้มีได้ เช่น `3` และกรอก **เลขที่อ้างอิง** (ไม่บังคับ)
18. เลือก **วันที่เริ่ม** แล้วเลือก **มีวันหมดอายุ** และใส่ **วันที่สิ้นสุด** หรือเลือก **ไม่มีวันหมดอายุ**
19. ช่อง **หมายเหตุ** ใช้จดรายละเอียดเพิ่มเติม (ไม่บังคับ)

    ![ฟอร์มเพิ่มไลเซนส์โควตา BU แบบไม่มีวันหมดอายุ](/screenshots/th/guide-manage-license-10-bu-quota-form-filled.png)

20. กดปุ่ม **สร้างไลเซนส์** แล้วกลับไปที่หน้าไลเซนส์ของ Cluster แท็บ **โควตา BU** จะแสดงใบทั้งหมดของ Cluster

    ![แท็บโควตา BU มีสองใบ](/screenshots/th/guide-manage-license-11-bu-quota-added.png)

โควตา BU ต่างจากที่นั่ง: ระบบไม่นับรวมกัน แต่ใช้ใบเดียว คือใบที่เริ่มล่าสุด ใบอื่นจะขึ้นสถานะ **ถูกแทนที่** ในภาพตัวอย่าง ใบใหม่เริ่มวันเดียวกับใบเดิม ระบบจึงยังใช้ใบเดิม (โควตา 2) และใบใหม่ขึ้นว่า **ถูกแทนที่** ถ้าต้องการให้จำนวนใหม่มีผล ให้ตั้ง **วันที่เริ่ม** ของใบใหม่เป็นวันถัดไป หรือยกเลิกใบเดิม

::: warning ยกเลิกใบ ย้อนกลับไม่ได้
ปุ่ม **ยกเลิกใบ** ในแถวของใบโควตา ทำให้ใบนั้นไม่ให้โควตาอีกต่อไป ใบจะยังอยู่ในรายการเพื่อตรวจย้อนหลังได้ แต่เปิดกลับไม่ได้ ตรวจให้แน่ใจก่อนกด
:::

### ส่วนที่ 5: เพิ่มใบสิทธิ์ interface

21. ที่เมนูด้านซ้าย กด **หน่วยธุรกิจ** แล้วกดชื่อโรงแรม
22. กดแท็บ **ไลเซนส์** กล่อง **ไลเซนส์ผู้ใช้** แสดงที่นั่งและสัญญาของโรงแรม กล่อง **ใบสิทธิ์ interface** แสดงการเชื่อมต่อกับระบบภายนอก

    ![แท็บไลเซนส์ของหน่วยธุรกิจ](/screenshots/th/guide-manage-license-12-bu-licenses-tab.png)

23. กดปุ่ม **เพิ่มใบสิทธิ์ interface**
24. ที่ **กลุ่มสิทธิ์** เลือกระบบที่จะเชื่อมต่อ เช่น **Interface Carmen GL** รายการนี้แสดงเฉพาะกลุ่มชนิด Interface ที่ยังขายอยู่
25. เลือก **วันที่เริ่ม** และ **วันที่สิ้นสุด** หรือเลือก **ไม่มีวันหมดอายุ** ช่อง **เลขที่อ้างอิง** และ **หมายเหตุ** ไม่บังคับ

    ![ฟอร์มเพิ่มใบสิทธิ์ interface ที่กรอกแล้ว](/screenshots/th/guide-manage-license-13-interface-form-filled.png)

26. กดปุ่ม **สร้างไลเซนส์** แล้วกลับไปที่แท็บ **ไลเซนส์** ของหน่วยธุรกิจ ใบใหม่ (เลขที่ขึ้นต้นด้วย `INF-`) จะแสดงพร้อมสถานะ **ใช้งาน**

    ![แท็บไลเซนส์ของหน่วยธุรกิจ มีใบสิทธิ์ interface แล้ว](/screenshots/th/guide-manage-license-14-interface-added.png)

ใบสิทธิ์ interface ใช้ได้เฉพาะเมื่อสัญญาหลักของโรงแรมยังใช้งานอยู่ ถ้าสัญญาหลักหมดอายุ การเชื่อมต่อจะปิด แม้วันที่ของใบสิทธิ์ยังไม่หมด

### ส่วนที่ 6: สร้างกลุ่มสิทธิ์ license ชุดใหม่

ระบบไม่มีปุ่มคัดลอกกลุ่ม ถ้าต้องการชุดที่คล้ายชุดเดิม ให้สร้างกลุ่มใหม่แล้วเลือกฟีเจอร์เอง

27. ที่เมนูด้านซ้าย กด **กลุ่มสิทธิ์ license** หน้า **แค็ตตาล็อก license** จะเปิดที่แท็บ **ชุดที่ขาย**

    ![หน้าแค็ตตาล็อก license แท็บชุดที่ขาย](/screenshots/th/guide-manage-license-15-feature-groups-list.png)

28. กดปุ่ม **สร้างกลุ่ม**
29. กรอก **รหัส** ของกลุ่ม รหัสเปลี่ยนไม่ได้หลังสร้างกลุ่มแล้ว
30. เลือก **ชนิด**: **ทั่วไป** สำหรับชุดที่ขายในสัญญาหลัก หรือ **Interface** สำหรับใบสิทธิ์ interface ชนิดตั้งได้ตอนสร้างเท่านั้น
31. กรอก **ชื่อ** และ **คำอธิบาย** (ไม่บังคับ)
32. กรอก **ลำดับ** คือตำแหน่งของชุดนี้บนฟอร์มขาย เลขน้อยขึ้นก่อน ใช้เลขที่ไม่ซ้ำกับกลุ่มอื่น
33. ที่ **สถานะ** เลือก **ขายอยู่** ถ้าต้องการให้เลือกชุดนี้ในสัญญาใหม่ได้ หรือ **หยุดขาย**
34. ในกล่อง **feature ในกลุ่มนี้** ติ๊กฟีเจอร์ที่ต้องการ หรือกด **เอาทั้งหมดใน** ตามด้วยชื่อหมวด เพื่อเลือกทั้งหมวด ตัวเลขด้านขวาบนบอกว่าเลือกไปกี่รายการ

    ![ฟอร์มสร้างกลุ่มที่กรอกแล้ว](/screenshots/th/guide-manage-license-16-feature-group-form-filled.png)

35. กดปุ่ม **บันทึกการแก้ไข** ที่แถบด้านล่าง ระบบจะแสดงข้อความ **สร้างกลุ่มแล้ว**

    ![หน้าของกลุ่มใหม่หลังบันทึก](/screenshots/th/guide-manage-license-17-feature-group-created.png)

## ตรวจสอบว่าสำเร็จ

- หน้าไลเซนส์ของ Cluster แถบสรุปด้านบนแสดงจำนวนโรงแรม ที่นั่ง และสัญญาที่ตรงกับที่ลูกค้าซื้อ
- แท็บ **ไลเซนส์** ของหน่วยธุรกิจ แสดงสัญญาและใบสิทธิ์ interface พร้อมสถานะ **ใช้งาน**
- ใบโควตา BU ที่ต้องการให้มีผล มีสถานะ **ใช้งาน** ไม่ใช่ **ถูกแทนที่**
- กลุ่มสิทธิ์ใหม่ที่ **ขายอยู่** ขึ้นในกล่อง **กลุ่มสิทธิ์ที่ซื้อ** ของสัญญา (ชนิดทั่วไป) หรือในรายการ **กลุ่มสิทธิ์** ของใบสิทธิ์ interface (ชนิด Interface)

## แก้ปัญหาเบื้องต้น

- **ใบโควตา BU ใหม่ขึ้นว่า ถูกแทนที่:** มีใบอื่นที่เริ่มทีหลังหรือเริ่มพร้อมกันและระบบยังใช้อยู่ ดูคำอธิบายท้ายส่วนที่ 4
- **สร้างสัญญาให้หน่วยธุรกิจผิดแห่ง:** สัญญาย้ายหน่วยธุรกิจไม่ได้ ให้สร้างสัญญาใหม่ให้หน่วยธุรกิจที่ถูกต้อง
- **ข้อความ "ยังไม่มีกลุ่มสิทธิ์ interface ที่ขายอยู่ — สร้างที่หน้ากลุ่มสิทธิ์ก่อน":** สร้างกลุ่มชนิด **Interface** และตั้งสถานะ **ขายอยู่** ก่อน (ส่วนที่ 6)
- **ใบสิทธิ์ interface ขึ้นข้อความว่าวันของใบยังไม่หมด แต่สัญญาหลักหมดอายุ:** ต่อสัญญาหลักของโรงแรมก่อน interface จึงจะกลับมาใช้ได้
- **ข้อความสีส้มใต้ช่องลำดับ ว่าลำดับซ้ำกับกลุ่มอื่น:** เปลี่ยนเป็นเลขที่ยังไม่มีกลุ่มอื่นใช้
- **รหัสหรือชนิดของกลุ่มผิด:** สองช่องนี้แก้ไม่ได้หลังสร้าง ให้สร้างกลุ่มใหม่ที่ถูกต้อง แล้วตั้งกลุ่มที่ผิดเป็น **หยุดขาย**
- **ไม่เห็นปุ่มที่คู่มือพูดถึง หรือขึ้นหน้าไม่มีสิทธิ์เข้าถึง:** ดู [หน้าแจ้งว่าไม่มีสิทธิ์](/getting-started/common-actions#access-denied)
