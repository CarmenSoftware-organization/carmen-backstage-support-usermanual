# เพิ่มผู้ใช้

## สิ่งที่คุณจะทำได้

คู่มือนี้พาคุณสร้างบัญชีให้พนักงานคนใหม่ จนเข้าใช้งานโรงแรมของตัวเองได้ เมื่อทำครบ คุณจะได้

- บัญชีผู้ใช้ใหม่ที่มีชื่อ อีเมล และสถานะ **ใช้งาน**
- ผู้ใช้อยู่ใน **Cluster** (กลุ่มโรงแรมของลูกค้าหนึ่งราย) พร้อมบทบาทใน Cluster
- ผู้ใช้เข้า **หน่วยธุรกิจ** (Business Unit — โรงแรมหรือสาขาหนึ่งแห่ง) ได้ พร้อมบทบาทในหน่วยธุรกิจ
- รหัสผ่านสำหรับเข้าระบบครั้งแรก

นอกจากนี้ คู่มือยังบอกวิธีแก้ชื่อ และวิธีปิดบัญชีชั่วคราว

**ใครทำได้:** ผู้ดูแลระบบสูงสุด หรือผู้ที่มีบทบาท (Platform Role — ชุดสิทธิ์ที่บอกว่าคุณทำอะไรได้บ้าง) ที่ให้จัดการผู้ใช้งานและ Clusters ได้

**สิ่งที่ต้องเตรียม**

- อีเมลของพนักงาน เช่น `somchai@grandhotelbangkok.com`
- ชื่อจริงและนามสกุล
- Cluster และหน่วยธุรกิจที่พนักงานจะใช้ ต้องสร้างไว้แล้ว ถ้ายังไม่มี ดู [ตั้งค่าโรงแรมใหม่](/guides/setup-hotel)
- หน่วยธุรกิจนั้นต้องมีที่นั่งว่าง (จำนวนผู้ใช้ที่โรงแรมมีได้) อย่างน้อย 1 ที่

::: tip ชื่อในภาพตัวอย่าง
ภาพในคู่มือนี้ใช้ชื่อและอีเมลตัวอย่างที่ขึ้นต้นด้วย `manual-demo-` หรือ `MANUAL-DEMO-` เวลาทำจริง ให้ใช้ข้อมูลจริงของพนักงานและโรงแรม
:::

## ขั้นตอน

### ส่วนที่ 1: สร้างบัญชี

1. ที่เมนูด้านซ้าย กด **ผู้ใช้งาน** หน้า **จัดการผู้ใช้** จะเปิดขึ้น

   ![หน้าจัดการผู้ใช้](/screenshots/th/guide-add-user-01-users-list.png)

2. กดปุ่ม **เพิ่มผู้ใช้** ที่มุมขวาบน ฟอร์ม **เพิ่มผู้ใช้** จะเปิดขึ้น

   ![ฟอร์มเพิ่มผู้ใช้ที่ยังว่าง](/screenshots/th/guide-add-user-02-form-empty.png)

3. กรอก **ชื่อผู้ใช้** เป็นอีเมลของพนักงาน ชื่อผู้ใช้นี้ใช้เข้าระบบ และเปลี่ยนไม่ได้หลังสร้างบัญชีแล้ว
4. กรอก **อีเมล** ส่วนใหญ่ใช้อีเมลเดียวกับชื่อผู้ใช้
5. กรอก **ชื่อจริง** และ **นามสกุล** ช่อง **ชื่อกลาง** ไม่บังคับ
6. ช่อง **ชื่อแฝง** ไม่บังคับ ใช้แสดงแทนชื่อเต็มในที่แคบ ถ้ากรอก ใช้ตัวอักษรหรือตัวเลขไม่เกิน 3 ตัว เช่น `SOM`
7. ปล่อยให้ช่อง **ใช้งาน** ติ๊กไว้

   ![ฟอร์มที่กรอกแล้ว](/screenshots/th/guide-add-user-03-form-filled.png)

8. กดปุ่ม **สร้างผู้ใช้** ระบบจะแสดงข้อความ **สร้าง ผู้ใช้ สำเร็จ** และเปิดหน้าของผู้ใช้คนนั้น ใต้ชื่อจะขึ้นว่า **ยังไม่ได้กำหนดสิทธิ์เข้าถึง** เพราะยังไม่ได้ให้เข้า Cluster ใด

   ![หน้าของผู้ใช้หลังสร้างสำเร็จ](/screenshots/th/guide-add-user-04-created.png)

   ในภาพตัวอย่าง ชื่อแฝงยาว 4 ตัว จึงมีข้อความสีแดงขึ้น เวลาทำจริงให้ใช้ไม่เกิน 3 ตัว

### ส่วนที่ 2: แก้ข้อมูลหรือปิดบัญชีชั่วคราว

ทำส่วนนี้เมื่อต้องการแก้ชื่อ หรือหยุดไม่ให้ผู้ใช้เข้าระบบ

9. ที่หน้าของผู้ใช้ กดปุ่ม **แก้ไข** ที่มุมขวาบน ดูเพิ่มเติมที่ [โหมดดูและโหมดแก้ไข](/getting-started/common-actions#view-edit)
10. แก้ชื่อตามต้องการ เช่น เพิ่ม **ชื่อกลาง**
11. ถ้าต้องการปิดบัญชีชั่วคราว ให้เอาติ๊กที่ช่อง **ใช้งาน** ออก ผู้ใช้ที่ปิดอยู่ยังมีสิทธิ์เดิมครบ แต่เข้าระบบไม่ได้ ติ๊กกลับเมื่อต้องการเปิดอีกครั้ง

    ![โหมดแก้ไข เห็นช่องใช้งานและปุ่มบันทึกการแก้ไข](/screenshots/th/guide-add-user-05-edit-status.png)

12. กดปุ่ม **บันทึกการแก้ไข** ระบบจะแสดงข้อความ **บันทึกการแก้ไขแล้ว**

    ![หน้าของผู้ใช้หลังบันทึก](/screenshots/th/guide-add-user-06-saved.png)

### ส่วนที่ 3: ให้ผู้ใช้เข้า Cluster

ผู้ใช้ต้องอยู่ใน Cluster ก่อน จึงจะได้รับหน่วยธุรกิจของ Cluster นั้น

13. ที่เมนูด้านซ้าย กด **Clusters** แล้วกดชื่อ Cluster ของโรงแรม
14. กดแท็บ **ผู้ใช้งาน** แล้วกดปุ่ม **เพิ่มผู้ใช้** กล่อง **เพิ่มผู้ใช้เข้า Cluster** จะเปิดขึ้น
15. พิมพ์ชื่อหรืออีเมลของผู้ใช้ แล้วกดเลือกชื่อที่ขึ้นมา
16. ที่ **บทบาทใน Cluster** เลือก **ผู้ใช้** (ใช้งานได้อย่างเดียว) หรือ **ผู้ดูแล** (จัดการผู้ใช้คนอื่นใน Cluster ได้)

    ![กล่องเพิ่มผู้ใช้เข้า Cluster](/screenshots/th/guide-add-user-07-cluster-add-user-dialog.png)

17. กดปุ่ม **เพิ่มผู้ใช้** ระบบจะแสดงข้อความ **เพิ่มผู้ใช้เข้า cluster แล้ว** และผู้ใช้จะอยู่ในรายชื่อของ Cluster

    ![รายชื่อผู้ใช้ของ Cluster หลังเพิ่มแล้ว](/screenshots/th/guide-add-user-08-cluster-user-added.png)

### ส่วนที่ 4: ให้ผู้ใช้เข้าหน่วยธุรกิจ

18. กลับไปที่หน้าของผู้ใช้ (เมนู **ผู้ใช้งาน** แล้วกดชื่อผู้ใช้)
19. ในกล่อง **สิทธิ์เข้าถึง** กดปุ่ม **เพิ่ม BU** กล่อง **เพิ่มหน่วยธุรกิจ** จะเปิดขึ้น
20. เลือก **Cluster** ก่อน แล้วเลือก **หน่วยธุรกิจ**
21. ที่ **บทบาท BU** เลือกบทบาทในโรงแรมนี้ เช่น **Admin**

    ![กล่องเพิ่มหน่วยธุรกิจ เลือก Cluster หน่วยธุรกิจ และบทบาท](/screenshots/th/guide-add-user-09-add-bu-dialog.png)

22. กดปุ่ม **เพิ่ม** ระบบจะแสดงข้อความ **กำหนดหน่วยธุรกิจสำเร็จ** กล่อง **สิทธิ์เข้าถึง** จะแสดง Cluster พร้อมบทบาท และหน่วยธุรกิจพร้อมบทบาทและสถานะ **ใช้งาน**

    ![กล่องสิทธิ์เข้าถึงแสดง Cluster และหน่วยธุรกิจ](/screenshots/th/guide-add-user-10-bu-assigned.png)

### ส่วนที่ 5: ตั้งรหัสผ่าน

23. ที่หน้าของผู้ใช้ กดปุ่ม **เปลี่ยนรหัสผ่าน** ที่มุมขวาบน

    ![กล่องเปลี่ยนรหัสผ่าน](/screenshots/th/guide-add-user-11-password-dialog.png)

24. พิมพ์รหัสผ่านในช่อง **รหัสผ่านใหม่** อย่างน้อย 6 ตัวอักษร
25. พิมพ์รหัสผ่านเดิมอีกครั้งในช่อง **ยืนยันรหัสผ่าน**

    ![กรอกรหัสผ่านแล้ว (ภาพนี้ปิดรหัสผ่านไว้)](/screenshots/th/guide-add-user-12-password-filled.png)

26. กดปุ่ม **อัปเดตรหัสผ่าน** ระบบจะแสดงข้อความ **เปลี่ยนรหัสผ่านสำเร็จ**

    ![หน้าของผู้ใช้หลังเปลี่ยนรหัสผ่าน](/screenshots/th/guide-add-user-13-password-changed.png)

27. แจ้งชื่อผู้ใช้และรหัสผ่านให้พนักงานทางช่องทางที่ปลอดภัย เช่น บอกด้วยตัวเอง ไม่ส่งรวมกันในอีเมลฉบับเดียว

## ตรวจสอบว่าสำเร็จ

- หน้าของผู้ใช้ มีป้าย **ใช้งาน** ข้างชื่อ
- กล่อง **สิทธิ์เข้าถึง** แสดงชื่อ Cluster พร้อมบทบาท และชื่อหน่วยธุรกิจพร้อมบทบาทและสถานะ **ใช้งาน** ใต้ชื่อผู้ใช้จะบอกจำนวนหน่วยธุรกิจและ Cluster ที่เข้าได้ (บางส่วนของข้อความนี้แสดงเป็นภาษาอังกฤษ)
- ที่หน้าของหน่วยธุรกิจ แท็บ **ผู้ใช้งาน** มีชื่อผู้ใช้คนนี้
- พนักงานเข้าระบบด้วยชื่อผู้ใช้และรหัสผ่านที่ตั้งไว้ได้

## แก้ปัญหาเบื้องต้น

- **ข้อความ "ชื่อผู้ใช้ต้องเป็นอีเมลที่ถูกต้อง":** ชื่อผู้ใช้ต้องเป็นอีเมล เช่น `somchai@grandhotelbangkok.com`
- **ข้อความ "ชื่อย่อต้องเป็นตัวอักษรหรือตัวเลข 1-3 ตัว":** ชื่อแฝงยาวเกิน 3 ตัว หรือมีช่องว่างหรือสัญลักษณ์ ให้แก้ให้สั้นลง
- **พิมพ์ชื่อผู้ใช้ผิด:** ชื่อผู้ใช้เปลี่ยนไม่ได้หลังสร้างแล้ว ให้สร้างบัญชีใหม่ด้วยชื่อผู้ใช้ที่ถูกต้อง แล้วลบบัญชีที่ผิดออก ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)
- **ในกล่องเพิ่มหน่วยธุรกิจ ไม่มี Cluster ที่ต้องการให้เลือก:** ผู้ใช้ยังไม่อยู่ใน Cluster นั้น ให้ทำส่วนที่ 3 ก่อน
- **เพิ่มหน่วยธุรกิจไม่ได้ เพราะที่นั่งเต็ม:** โรงแรมใช้ที่นั่งครบแล้ว ให้เพิ่มใบที่นั่งตาม [จัดการ License](/guides/manage-license) หรือนำผู้ใช้ที่ไม่ได้ใช้งานแล้วออกจากหน่วยธุรกิจนั้น
- **ข้อความ "รหัสผ่านไม่ตรงกัน":** สองช่องในกล่องเปลี่ยนรหัสผ่านต้องพิมพ์เหมือนกันทุกตัว
- **พนักงานเข้าระบบไม่ได้:** ตรวจว่าช่อง **ใช้งาน** ยังติ๊กอยู่ และผู้ใช้มีหน่วยธุรกิจในกล่อง **สิทธิ์เข้าถึง** แล้ว
- **ไม่เห็นปุ่มที่คู่มือพูดถึง หรือขึ้นหน้าไม่มีสิทธิ์เข้าถึง:** ดู [หน้าแจ้งว่าไม่มีสิทธิ์](/getting-started/common-actions#access-denied)
