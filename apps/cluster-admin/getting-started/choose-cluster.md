# เลือก Cluster

**Cluster** (กลุ่มโรงแรมที่บริหารร่วมกัน) คือระดับบนสุดในมุมมองผู้ดูแล Cluster ทุกอย่างที่คุณเห็นเป็นของ Cluster เดียวในแต่ละครั้ง

## เมื่อไรที่คุณเห็นหน้านี้

คุณเห็นรายการ Cluster ก็ต่อเมื่อคุณดูแล **มากกว่าหนึ่ง** Cluster ถ้าคุณดูแลเพียงหนึ่ง Cluster Carmen Blue จะข้ามหน้านี้และเปิด Cluster นั้นให้เลย

![หน้าผู้ดูแล Cluster ที่มีการ์ดหนึ่งใบต่อหนึ่ง Cluster ที่คุณดูแล](/screenshots/th/choose-cluster.png)

หน้านี้ชื่อ **ผู้ดูแล Cluster** และมีข้อความ **เลือก cluster ที่ต้องการดูแล** Cluster แต่ละแห่งที่คุณดูแลเป็นการ์ดหนึ่งใบ มีชื่อของ Cluster

## เปิด Cluster

1. คลิกการ์ดของ Cluster ที่ต้องการ หรือเลือกการ์ดแล้วกด Enter
2. คุณจะเข้าสู่หน้า [Cluster](/screens/cluster) ของ Cluster นั้น

## สลับไป Cluster อื่นภายหลัง

เมื่ออยู่ใน Cluster แล้ว คุณไม่ต้องกลับมาที่รายการนี้ ที่แถบด้านบน ข้างเส้นทางหน้า (breadcrumb) มีกล่องเล็ก ๆ ที่แสดงชื่อย่อของ Cluster และลูกศรขึ้นลง คลิกกล่องนั้นแล้วเลือกหรือค้นหา Cluster อื่น กล่องนี้จะปรากฏเมื่อคุณดูแลมากกว่าหนึ่ง Cluster เท่านั้น

## ถ้ารายการว่าง

ถ้าหน้าจอแสดง **ไม่มี cluster ที่ดูแลอยู่** แปลว่าบัญชีของคุณยังไม่ได้ตั้งให้ดูแล Cluster ใดเลย [ติดต่อทีม support ของ Carmen](/getting-help)

ถ้าหน้าจอบอกว่า **คุณไม่มีสิทธิ์ดูแล cluster นี้อีกต่อไป** แปลว่าสิทธิ์ของคุณใน Cluster นั้นถูกนำออกแล้ว กด **กลับไปยัง cluster ของฉัน** เพื่อเลือก Cluster อื่น หรือ [ติดต่อทีม support ของ Carmen](/getting-help) เพื่อขอสิทธิ์คืน
