# เข้าสู่ระบบ

คุณเข้ามุมมองผู้ดูแล Cluster ได้จากหน้าเข้าสู่ระบบของ Carmen Blue หน้าเดียวกับที่ทุกคนใช้ ไม่มีที่อยู่เว็บหรือบัญชีแยกต่างหาก

## วิธีเข้าสู่ระบบ

1. เปิดหน้าเข้าสู่ระบบของ Carmen Blue หัวข้อของหน้าคือ **เข้าสู่ระบบ** ข้อความใต้หัวข้อมีคำว่า "Carmen Blue Backstage" นี่คือหน้าที่ถูกต้อง
2. พิมพ์อีเมลหรือชื่อผู้ใช้ของคุณในช่อง **อีเมลหรือชื่อผู้ใช้**
3. พิมพ์รหัสผ่านในช่อง **รหัสผ่าน**
4. กดปุ่ม **เข้าสู่ระบบ**

ถ้าบริษัทของคุณเปิดใช้การเข้าสู่ระบบด้วย Google คุณกดปุ่ม **ดำเนินการต่อด้วย Google** แทนก็ได้

## หลังเข้าสู่ระบบ

- ถ้าคุณดูแล **Cluster เดียว** (กลุ่มโรงแรมที่บริหารร่วมกัน) ระบบพาคุณเข้า Cluster นั้นทันที คุณจะเห็นหน้า [Cluster](/screens/cluster)
- ถ้าคุณดูแล **มากกว่าหนึ่ง Cluster** คุณจะเห็นรายการ Cluster ของคุณก่อน ให้เลือกหนึ่งรายการ ดู [เลือก Cluster](/getting-started/choose-cluster)

ถ้าบัญชีของคุณไม่มีสิทธิ์ผู้ดูแล Cluster คุณจะไม่เห็นหน้าเหล่านี้ [ติดต่อทีม support ของ Carmen](/getting-help) เพื่อขอสิทธิ์

## ถ้าคุณมีสิทธิ์ส่วนอื่นของ Carmen Blue ด้วย

บางคนใช้ส่วนอื่นของ Carmen Blue ด้วย ถ้าเป็นคุณ ให้เปิดเมนูผู้ใช้ (ชื่อของคุณ มุมขวาบน) แล้วเลือก **มุมมองผู้ดูแล Cluster** เพื่อเข้ามาที่หน้าจอในคู่มือนี้

## ออกจากระบบ

เปิดเมนูผู้ใช้ (ชื่อของคุณ มุมขวาบน) แล้วเลือก **ออกจากระบบ**
