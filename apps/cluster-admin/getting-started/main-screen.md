# รู้จักหน้าจอหลัก

เมื่อคุณอยู่ใน Cluster แล้ว ทุกหน้าจะมีกรอบเดียวกัน หน้านี้อธิบายกรอบนั้นครั้งเดียว

![หน้า Cluster ที่มีแถบเมนูด้านซ้ายและแถบด้านบน](/screenshots/th/main-screen.png)

## แถบเมนูด้านซ้าย

ด้านบนสุดของแถบเมนูคือชื่อและโลโก้ของ Cluster ที่คุณอยู่ คลิกเพื่อกลับไปหน้า [Cluster](/screens/cluster) ใต้นั้นมีเมนูสี่รายการ

| เมนู | เปิดอะไร |
| --- | --- |
| **Cluster** | รายละเอียด โลโก้ และสรุปของ Cluster ดู [Cluster](/screens/cluster) |
| **หน่วยธุรกิจ** | โรงแรมใน Cluster ดู [หน่วยธุรกิจ](/screens/business-units) |
| **ผู้ใช้งาน** | คนใน Cluster ใครถือที่นั่ง และคำเชิญ ดู [ผู้ใช้งาน](/screens/users) |
| **ไลเซนส์** | ไลเซนส์ที่ Cluster มีและวันสิ้นสุด ดู [ไลเซนส์](/screens/licences) |

เมนูของหน้าที่คุณอยู่จะถูกไฮไลต์ กด **ย่อเมนู** ที่ด้านล่างเพื่อย่อแถบเมนูให้เหลือแต่ไอคอน กดปุ่มเดิมอีกครั้งเพื่อขยายกลับ

::: tip
บริษัทของคุณอาจยังไม่ได้ใช้ทั้งสี่เมนู เมนูที่ยังไม่พร้อมจะแสดงเป็นสีจางหรือไม่แสดง
:::

## แถบด้านบน

| ส่วน | ทำอะไร |
| --- | --- |
| เส้นทางหน้า (เช่น **ผู้ดูแล Cluster** > **Cluster**) | บอกว่าคุณอยู่ที่ไหน คลิกขั้นก่อนหน้าเพื่อย้อนกลับ |
| ตัวสลับ Cluster (ชื่อย่อและลูกศร) | พาคุณไป Cluster อื่น แสดงเมื่อคุณดูแลมากกว่าหนึ่ง Cluster ดู [เลือก Cluster](/getting-started/choose-cluster) |
| ปุ่มภาษา | สลับหน้าจอระหว่างไทยกับอังกฤษ |
| ปุ่มธีม | สลับระหว่างโทนสว่างกับโทนมืด |
| เมนูผู้ใช้ (ชื่อของคุณ) | เปิด [โปรไฟล์](/screens/profile) และ **ออกจากระบบ** ถ้าคุณมีสิทธิ์ส่วนอื่นด้วย จะมี **มุมมองผู้ดูแล Cluster** ให้เลือกด้วย |

## แถบด้านล่าง

แถบบาง ๆ ด้านล่างแสดงเวอร์ชันของแอปและวันที่เวลา ปกติคุณไม่ต้องใช้ แต่มีประโยชน์เมื่อ [ติดต่อทีม support ของ Carmen](/getting-help)
