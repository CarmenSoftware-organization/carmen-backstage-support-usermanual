# ดูไลเซนส์และวันหมดอายุ

คู่มือนี้พาคุณอ่านหน้า **ไลเซนส์** เพื่อดูว่า Cluster มีอะไรบ้าง ใกล้หมดอายุหรือไม่ และที่นั่งแยกตามหน่วยธุรกิจ (โรงแรมหรือสาขาหนึ่งแห่ง) เป็นอย่างไร ผู้ดูแล Cluster ทำได้ หน้านี้เป็นหน้าสำหรับอ่านอย่างเดียว

## ขั้นตอน

1. เปิด **ไลเซนส์** จากแถบเมนูด้านซ้าย

   ![หน้าไลเซนส์](/screenshots/th/guide-licences-01-overview.png)

2. ดูสองการ์ดด้านบน
   - **หน่วยธุรกิจ** เช่น **4 / 5 ที่มีไลเซนส์** คือใช้หน่วยธุรกิจไปเท่าไรจากที่ซื้อ
   - **ที่นั่ง** เช่น **11 / 13 ที่มีไลเซนส์** และ **เหลือที่นั่งว่าง 2 ที่** ดูวิธีอ่านที่ [จัดการที่นั่ง (Seat)](/guides/manage-seats)

3. ดู **สัญญา** (ไลเซนส์หลักของแต่ละหน่วยธุรกิจ) บรรทัดบนบอกว่าใช้ได้จริงกี่ใบ เช่น **ใช้ได้จริง 3 จาก 3 ใบ** แถบแสดงช่วงเวลาที่คุ้มครอง บรรทัดใต้แถบบอกวันสิ้นสุดและวันที่เหลือ เช่น **เหลืออีก 430 วัน** ด้านล่างแสดงสัญญาแต่ละใบพร้อมวันที่และตัวย่อของฟีเจอร์

4. ดู **ใบสิทธิ์ INTERFACE** (การเชื่อมต่อกับระบบอื่น เช่น ระบบ POS) แต่ละแถวคือหนึ่งการเชื่อมต่อ **ไม่มีวันหมดอายุ** แปลว่าไม่มีวันสิ้นสุด

5. เลื่อนลงดู **ที่นั่งแยกตามหน่วยธุรกิจ** หนึ่งแถวต่อหนึ่งหน่วยธุรกิจ แสดงที่นั่ง จำนวนไลเซนส์ และวันสิ้นสุด **ยังไม่ได้ซื้อ** แปลว่าหน่วยนั้นยังไม่มีที่นั่ง

6. เปิดส่วนที่พับอยู่ได้ถ้าต้องการรายละเอียด **ไลเซนส์โควตาหน่วยธุรกิจ** แสดงว่า Cluster มีหน่วยธุรกิจได้กี่แห่ง **อันดับหน่วยธุรกิจ** แสดงลำดับที่หน่วยได้รับความคุ้มครองเมื่อโควตาไม่พอ

## ตรวจว่าใกล้หมดอายุหรือไม่

ดู **สัญญา** และ **ใบสิทธิ์ INTERFACE** หากมีไลเซนส์ที่จะหมดอายุเร็ว ๆ นี้ จะมีข้อความ เช่น **ใกล้หมดอายุ 2 ใบ** และมีวันที่เหลือแสดงไว้ในที่ที่เกี่ยวข้อง ดูคอลัมน์สุดท้ายของ **ที่นั่งแยกตามหน่วยธุรกิจ** เพื่อรู้วันสิ้นสุดของแต่ละหน่วย

## ดูไลเซนส์ของหน่วยธุรกิจหนึ่งแห่ง

คลิกชื่อหน่วยธุรกิจในตาราง หรือเปิดหน่วยธุรกิจแล้วไปแท็บ **ไลเซนส์** แท็บนี้มีแท็บย่อย **ที่นั่ง** **โมดูล** และ **Interface**

![แท็บไลเซนส์ของหน่วยธุรกิจ](/screenshots/th/guide-licences-02-bu-licences.png)

แท็บย่อย **ที่นั่ง** แสดงที่นั่งจากหน่วยนี้ (**BU นี้**) บวกที่นั่งจากหน่วยอื่น (**จาก BU อื่น**) เป็นกองรวมของ Cluster และมีกี่ที่นั่ง **ใช้อยู่**

::: warning
ลิงก์ **จัดการไลเซนส์** มุมขวาบนของแท็บนี้ **ไม่ได้** ให้คุณเพิ่มหรือแก้ไลเซนส์ ลิงก์นี้แค่เปิดหน้า **ไลเซนส์** ที่คุณอ่านอยู่ การเพิ่มหรือต่ออายุไลเซนส์ทำโดยทีม support ของ Carmen [ติดต่อทีม support ของ Carmen](/getting-help) ล่วงหน้าก่อนวันสิ้นสุดให้นานพอ
:::

## ถ้าเจอปัญหา

- เห็น **ต้องระบุวันที่สิ้นสุด** ที่ไลเซนส์ แปลว่ายังไม่มีวันสิ้นสุดบันทึกไว้ [ติดต่อทีม support ของ Carmen](/getting-help)
- เห็นหน่วยธุรกิจที่ **ยังไม่ได้ซื้อ** ที่นั่ง ผู้ใช้ในหน่วยนั้นใช้ที่นั่งจากกองรวมของ Cluster ถ้าต้องการที่นั่งเพิ่ม [ติดต่อทีม support ของ Carmen](/getting-help)
