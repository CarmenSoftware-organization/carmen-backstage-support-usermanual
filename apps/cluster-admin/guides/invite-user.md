# เชิญผู้ใช้เข้าหน่วยธุรกิจ

คู่มือนี้พาคุณเชิญคนใหม่เข้า Cluster และเลือกหน่วยธุรกิจ (โรงแรมหรือสาขาหนึ่งแห่ง) ที่เขาใช้ได้ ผู้ดูแล Cluster ทำได้ ก่อนเริ่ม ให้เตรียมอีเมลของคนที่จะเชิญ และรู้ว่าเขาควรใช้หน่วยธุรกิจใด เขาไม่จำเป็นต้องมีบัญชี Carmen Blue มาก่อน ลิงก์ในคำเชิญจะให้ตั้งรหัสผ่านและเข้าร่วมได้ในขั้นตอนเดียว

## ขั้นตอน

1. เปิด **ผู้ใช้งาน** จากแถบเมนูด้านซ้าย

   ![หน้าผู้ใช้งาน](/screenshots/th/guide-invite-user-01-users-page.png)

2. กด **เชิญผู้ใช้** มุมขวาบน

3. ในช่อง **อีเมล** พิมพ์อีเมลของคนที่จะเชิญ

4. เลือก **บทบาทใน cluster** เป็น **ผู้ดูแล** (ดูแล Cluster ได้) หรือ **ผู้ใช้** (สมาชิกทั่วไป)

   ![กล่องเชิญผู้ใช้](/screenshots/th/guide-invite-user-02-dialog.png)

5. ใต้ **สิทธิ์เข้าถึงหน่วยธุรกิจ** ติ๊กหน่วยธุรกิจที่เขาใช้ได้

6. ใต้แต่ละหน่วยที่ติ๊ก เลือกบทบาทของเขาในหน่วยนั้น ถ้าต้องการ ติ๊ก **ค่าเริ่มต้น** ได้หนึ่งหน่วย

   ![กรอกคำเชิญแล้ว](/screenshots/th/guide-invite-user-03-filled.png)

7. กด **ส่ง**

## ตรวจว่าสำเร็จ

จะมีข้อความ **ส่งคำเชิญแล้ว** อยู่ด้านบน เปิดแท็บ **คำเชิญ** จะเห็นอีเมลนั้นในรายการ สถานะ **รอตอบรับ** แปลว่าเขายังไม่ได้ตอบรับ

![แท็บคำเชิญ](/screenshots/th/guide-invite-user-04-invitations.png)

## ส่งคำเชิญซ้ำหรือยกเลิกคำเชิญ

1. เปิดแท็บ **คำเชิญ**
2. กด **...** ท้ายแถวของคำเชิญนั้น
3. กด **ส่งใหม่** เพื่อส่งอีกครั้ง หรือกด **เพิกถอน** เพื่อยกเลิก
4. ถ้าเพิกถอน ให้อ่านข้อความยืนยันแล้วยืนยัน ผู้รับจะตอบรับคำเชิญนั้นไม่ได้อีก

## ถ้าเจอปัญหา

- **คำเชิญของอีเมลนี้ค้างอยู่แล้ว** แปลว่าเคยเชิญอีเมลนี้ไว้ และยังไม่มีคำตอบ ให้ดูในแท็บ **คำเชิญ** แล้วใช้ **ส่งใหม่** แทน
- **ส่งคำเชิญถี่เกินไป** ให้รอสักครู่แล้วลองใหม่
- ไม่เห็นหน่วยธุรกิจที่ต้องการในรายการ [ติดต่อทีม support ของ Carmen](/getting-help)
