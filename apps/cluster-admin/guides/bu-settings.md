# ดูค่าตั้งค่าหน่วยธุรกิจ

คู่มือนี้พาคุณดูค่าตั้งค่าของหน่วยธุรกิจ (โรงแรมหรือสาขาหนึ่งแห่ง) และแก้ข้อมูลโรงแรมกับบริษัทที่แก้ได้ ผู้ดูแล Cluster ทำได้ ก่อนเริ่ม ให้รู้ว่าต้องการดูหน่วยธุรกิจใด

## เปิดหน่วยธุรกิจ

1. เปิด **หน่วยธุรกิจ** จากแถบเมนูด้านซ้าย
2. คลิกชื่อหน่วยธุรกิจที่ต้องการ

ใต้ส่วนบนของหน้ามีแท็บ **ภาพรวม** **โรงแรม** **บริษัท** **การตั้งค่า** **ไลเซนส์** และ **ผู้ใช้งาน**

## ดูค่าตั้งค่า (ดูได้อย่างเดียว)

1. เปิดแท็บ **การตั้งค่า**

   ![แท็บการตั้งค่า](/screenshots/th/guide-bu-settings-01-configuration.png)

2. อ่านค่าที่แสดง
   - **รูปแบบตามภูมิภาค** เช่น **เขตเวลา** และรูปแบบวันที่กับเวลา
   - **ตั้งค่าการคำนวณ** เช่น **วิธีคำนวณ**
   - **รูปแบบตัวเลข** เช่น **รูปแบบจำนวนเงิน** แต่ละรายการมีตัวอย่าง เช่น 1234.5678 จะแสดงเป็น 1,234.568

::: warning ดูได้อย่างเดียว
ค่าในแท็บ **การตั้งค่า** คุณแก้เองไม่ได้ ถ้าต้องการเปลี่ยน [ติดต่อทีม support ของ Carmen](/getting-help) แจ้งชื่อ Cluster ชื่อหน่วยธุรกิจ และค่าที่ต้องการเปลี่ยน
:::

## ดูและแก้ข้อมูลโรงแรม

1. เปิดแท็บ **โรงแรม**

   ![แท็บโรงแรม](/screenshots/th/guide-bu-settings-02-hotel.png)

2. ดู **ติดต่อ** (**ชื่อโรงแรม** **โทรศัพท์** **อีเมล**) และ **ที่ตั้ง** ลิงก์ **เปิดในแผนที่** แสดงที่อยู่บนแผนที่
3. ถ้าต้องการแก้ ให้คลิกค่านั้น แล้วพิมพ์ค่าใหม่
4. กด **บันทึกการแก้ไข** ที่แถบด้านล่าง หรือกด **ยกเลิก** เพื่อทิ้งการแก้ไข

ข้อความที่คุณแก้ **ยังไม่ถูกบันทึกทันที** ถ้าออกจากหน้าโดยไม่กด **บันทึกการแก้ไข** ข้อความที่แก้จะหายไป

## ดูและแก้ข้อมูลบริษัท

แท็บ **บริษัท** แสดงบริษัทที่ถูกเรียกเก็บเงินสำหรับหน่วยธุรกิจนี้ มี **ข้อมูลออกบิล** และ **ที่อยู่ออกบิล** ใช้วิธีเดียวกับแท็บ **โรงแรม** คือคลิกค่าเพื่อแก้ แล้วกด **บันทึกการแก้ไข** ถ้าที่อยู่เหมือนที่อยู่โรงแรม กด **คัดลอกจากที่อยู่โรงแรม**

## ตรวจว่าสำเร็จ

หลังกด **บันทึกการแก้ไข** แถบด้านล่างหายไป และค่าใหม่แสดงในแท็บนั้น

## ถ้าเจอปัญหา

- คลิกค่าในแท็บ **การตั้งค่า** แล้วแก้ไม่ได้ เป็นเรื่องปกติ แท็บนี้ดูได้อย่างเดียว [ติดต่อทีม support ของ Carmen](/getting-help)
- แก้ค่าแล้วไม่เห็นแถบ **บันทึกการแก้ไข** ให้ตรวจว่าค่านั้นแก้ได้จริง ถ้ายังไม่ได้ [ติดต่อทีม support ของ Carmen](/getting-help)
