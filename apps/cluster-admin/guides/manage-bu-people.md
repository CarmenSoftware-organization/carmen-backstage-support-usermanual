# จัดการคนในหน่วยธุรกิจ

คู่มือนี้พาคุณเปลี่ยนบทบาทของสมาชิกใน Cluster และนำสมาชิกออก ผู้ดูแล Cluster ทำได้ ก่อนเริ่ม ให้รู้ชื่อหรืออีเมลของคนที่จะจัดการ

## เปลี่ยนบทบาทของสมาชิก

1. เปิด **ผู้ใช้งาน** จากแถบเมนูด้านซ้าย
2. พิมพ์ชื่อหรืออีเมลในช่อง **ค้นหาสมาชิก...** เพื่อหาคนนั้น
3. กด **...** ท้ายแถวของเขา

   ![เมนูท้ายแถว](/screenshots/th/guide-manage-bu-people-01-row-menu.png)

4. กด **ตั้งเป็น ผู้ดูแล** หรือ **ตั้งเป็น ผู้ใช้** (เมนูจะแสดงบทบาทที่ยังไม่ใช่ของเขา)

จะมีข้อความ **อัปเดตบทบาทแล้ว** และคอลัมน์ **บทบาทใน Cluster** เปลี่ยนตาม

![เปลี่ยนบทบาทแล้ว](/screenshots/th/guide-manage-bu-people-02-role-changed.png)

## นำสมาชิกออกจาก Cluster

::: warning
**นำออก** จะนำคนนั้นออกจากทั้ง Cluster ไม่ใช่แค่หน่วยธุรกิจเดียว ตรวจชื่อในข้อความถามให้ดีก่อนยืนยัน
:::

::: tip ถ้าต้องการคืนที่นั่ง
การนำคนออกอาจยังไม่คืนที่นั่ง (Seat) ให้ Cluster ทันที ถ้านำออกเพื่อให้มีที่นั่งว่างสำหรับคนใหม่ ให้ **ปล่อยที่นั่ง** ของคนนั้นก่อน ดู [จัดการที่นั่ง](/guides/manage-seats) แล้วค่อยนำออก ถ้าจำนวนที่นั่งยังไม่ลดลง [ติดต่อ support](/getting-help)
:::

1. กด **...** ท้ายแถวของคนนั้น
2. กด **นำออก**
3. อ่านคำถาม เช่น นำ "ชื่อ" ออกจาก cluster นี้? ถ้าถูกคนแล้วกด **นำออก** ถ้าไม่ใช่กด **ยกเลิก**

   ![ยืนยันการนำออก](/screenshots/th/guide-manage-bu-people-03-remove-confirm.png)

## ตรวจว่าสำเร็จ

จะมีข้อความ **นำสมาชิกออกแล้ว** และคนนั้นไม่อยู่ในรายการสมาชิกอีก ตัวเลขข้าง **สมาชิก** ลดลงหนึ่ง

![นำออกแล้ว](/screenshots/th/guide-manage-bu-people-04-removed.png)

## ดูว่าใครอยู่ในหน่วยธุรกิจหนึ่งแห่ง

หน้า **ผู้ใช้งาน** แสดงคนทั้ง Cluster ถ้าต้องการดูเฉพาะหน่วยธุรกิจหนึ่งแห่ง ให้เปิดหน่วยธุรกิจนั้นแล้วไปแท็บ **ผู้ใช้งาน** ที่นั่นเปลี่ยนบทบาทหรือสถานะของเขาในหน่วยนั้น หรือเอาเขาออกจากหน่วยนั้นได้ ดู [หน้าหน่วยธุรกิจ](/screens/business-unit-detail)

## ถ้าเจอปัญหา

- ไม่เห็นคนที่ค้นหา ลองลบคำค้นหรือกดปุ่มกรอง **สมาชิกทั้งหมด** บางคนยังไม่ได้ตอบรับคำเชิญ ให้ดูในแท็บ **คำเชิญ**
- ถ้าทำไม่ได้หรือไม่แน่ใจ [ติดต่อทีม support ของ Carmen](/getting-help)
