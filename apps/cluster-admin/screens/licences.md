# ไลเซนส์

**หาได้ที่ไหน:** แถบเมนูด้านซ้าย > **ไลเซนส์** หัวหน้าเป็นชื่อ Cluster และมีคำว่า **ไลเซนส์** ใต้ชื่อ

หน้านี้แสดงไลเซนส์ทุกใบที่ Cluster ของคุณมีและวันสิ้นสุดของแต่ละใบ เป็นหน้าสำหรับอ่าน ใช้ตรวจว่ามีอะไรใกล้หมดอายุหรือไม่

![หน้าไลเซนส์](/screenshots/th/licences-overview.png)

## ทำอะไรได้บ้าง

- ดูการใช้หน่วยธุรกิจและที่นั่งด้านบน เหมือนในหน้า [Cluster](/screens/cluster)
- ตรวจสัญญาของแต่ละหน่วยธุรกิจและวันสิ้นสุด
- ตรวจใบสิทธิ์ interface
- ดูว่าหน่วยธุรกิจใดยังไม่มีที่นั่ง
- คลิกแถวเพื่อเปิดแท็บไลเซนส์ของหน่วยธุรกิจนั้น

## สิ่งที่อยู่บนหน้าจอ

| ส่วน | แสดงอะไร |
| --- | --- |
| **หน่วยธุรกิจ** และ **ที่นั่ง** | ใช้หน่วยธุรกิจและที่นั่งไปเท่าไรจากที่มีไลเซนส์ |
| **สัญญา** | เช่น **ใช้ได้จริง 3 จาก 3 ใบ** แถบแสดงช่วงเวลาที่คุ้มครอง บรรทัดใต้แถบบอกวันสิ้นสุดและวันที่เหลือ เช่น **เหลืออีก 430 วัน** ด้านล่างแสดงสัญญาของแต่ละหน่วยธุรกิจพร้อมวันที่และจำนวนฟีเจอร์ |
| **ใบสิทธิ์ INTERFACE** | เช่น **ใช้ได้จริง 4 จาก 4 ใบ** แต่ละแถวคือ interface หนึ่งตัว (การเชื่อมต่อกับระบบอื่น) ของหน่วยธุรกิจ **ไม่มีวันหมดอายุ** แปลว่าไม่มีวันสิ้นสุด |
| **ที่นั่งแยกตามหน่วยธุรกิจ** | หนึ่งแถวต่อหนึ่งหน่วยธุรกิจ แสดงที่นั่ง จำนวนไลเซนส์ และวันสิ้นสุด **ยังไม่ได้ซื้อ** แปลว่าหน่วยนั้นไม่มีที่นั่ง หัวข้อบอกว่ามีกี่หน่วยที่ยังไม่มี |
| **ไลเซนส์โควตาหน่วยธุรกิจ** | ส่วนที่พับอยู่ เปิดเพื่อดูว่า Cluster มีหน่วยธุรกิจได้กี่แห่ง พร้อมวันเริ่ม วันสิ้นสุด สถานะ และเลขอ้างอิง |
| **อันดับหน่วยธุรกิจ** | ส่วนที่พับอยู่ เปิดเพื่อดูลำดับที่หน่วยธุรกิจได้รับความคุ้มครองเมื่อโควตาไม่พอ คือ HQ ก่อน แล้วตามด้วยหน่วยที่เก่าที่สุด หน่วยที่ขึ้น **เกินโควตา** อ่านได้อย่างเดียว |

การ์ดที่ขึ้นข้อความ เช่น **ใกล้หมดอายุ 2 ใบ** กำลังบอกว่ามีไลเซนส์สองใบจะหมดอายุเร็ว ๆ นี้

## งานที่ทำบ่อย

### ตรวจว่าอะไรใกล้สิ้นสุด

1. เปิด **ไลเซนส์**
2. ดู **สัญญา** และ **ใบสิทธิ์ INTERFACE** ว่ามี **ใกล้หมดอายุ** หรือวันที่เหลือเท่าไร
3. ใน **ที่นั่งแยกตามหน่วยธุรกิจ** ดูคอลัมน์สุดท้ายเพื่อรู้วันสิ้นสุดของแต่ละหน่วย

### ดูไลเซนส์ของหน่วยธุรกิจหนึ่งแห่ง

คลิกที่แถวของหน่วยนั้น คุณจะเข้าแท็บ **ไลเซนส์** ของหน่วยธุรกิจนั้น ดู [หน้าหน่วยธุรกิจ](/screens/business-unit-detail)

## ข้อควรระวัง

::: warning
ในคู่มือนี้ไม่มีหน้าจอไหนให้คุณเพิ่ม ต่ออายุ หรือแก้ไลเซนส์ Carmen เป็นผู้ทำ เมื่อไลเซนส์ใกล้สิ้นสุด หรือคุณต้องการที่นั่ง หน่วยธุรกิจ หรือ interface เพิ่ม [ติดต่อทีม support ของ Carmen](/getting-help) ล่วงหน้าก่อนวันสิ้นสุดให้นานพอ
