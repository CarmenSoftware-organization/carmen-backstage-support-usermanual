# หน่วยธุรกิจ

**หาได้ที่ไหน:** แถบเมนูด้านซ้าย > **หน่วยธุรกิจ**

**หน่วยธุรกิจ** (Business Unit — โรงแรมหรือสาขาหนึ่งแห่งใน Cluster) คือที่เก็บพนักงาน ที่นั่ง และไลเซนส์ หน้านี้แสดงรายการหน่วยธุรกิจทั้งหมดใน Cluster เปิดหน่วยใดหน่วยหนึ่งเพื่อดูและแก้รายละเอียด

![รายการหน่วยธุรกิจ](/screenshots/th/business-units-list.png)

หน้านี้ชื่อ **หน่วยธุรกิจ** และมีข้อความ **จัดการหน่วยธุรกิจใน cluster นี้**

## ทำอะไรได้บ้าง

- หาหน่วยธุรกิจด้วยช่อง **ค้นหาหน่วยธุรกิจ...**
- แสดงเฉพาะหน่วยที่ใช้งานหรือไม่ใช้งานด้วย **ตัวกรอง**
- เรียงรายการโดยคลิกหัวคอลัมน์
- บันทึกรายการเป็นไฟล์ด้วย **ส่งออก**
- เปิดหน่วยธุรกิจโดยคลิกชื่อ ดู [หน้าหน่วยธุรกิจ](/screens/business-unit-detail)

## คอลัมน์ในรายการ

| คอลัมน์ | แสดงอะไร |
| --- | --- |
| **#** | ลำดับแถว |
| **ชื่อ** | ชื่อหน่วยธุรกิจ คลิกเพื่อเปิด |
| **HQ** | เครื่องหมายถ้าเป็นสำนักงานใหญ่ |
| **สถานะ** | **ใช้งาน** หรือ **ไม่ใช้งาน** |
| **สร้างเมื่อ** | สร้างมานานเท่าไรและโดยใคร |
| **แก้ไขเมื่อ** | แก้ไขล่าสุดนานเท่าไรและโดยใคร |

ด้านล่างเลือกจำนวนแถวที่แสดงได้ (**10** **25** **50** หรือ **100**) และเลื่อนไปหน้าอื่นได้

## งานที่ทำบ่อย

### เปิดหน่วยธุรกิจ

1. ถ้ารายการยาว พิมพ์บางส่วนของชื่อในช่อง **ค้นหาหน่วยธุรกิจ...**
2. คลิกชื่อหน่วยธุรกิจ

### แสดงเฉพาะหน่วยที่ใช้งานอยู่

1. กด **ตัวกรอง**
2. เลือก **ใช้งาน** กด **ล้าง** เพื่อแสดงทั้งหมดอีกครั้ง

## ข้อควรระวัง

- ไม่มีปุ่มเพิ่มหน่วยธุรกิจ Carmen เป็นผู้สร้างให้ ถ้า Cluster ของคุณต้องการหน่วยเพิ่ม [ติดต่อทีม support ของ Carmen](/getting-help)
- ถ้า Cluster มีหน่วยธุรกิจเกินที่มีไลเซนส์ หน้านี้จะบอกจำนวนที่เกิน หน่วยเหล่านั้นอ่านได้อย่างเดียวจนกว่าจะเพิ่มโควตา ดู [ไลเซนส์](/screens/licences)
