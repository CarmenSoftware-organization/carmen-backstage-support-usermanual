# Cluster

**หาได้ที่ไหน:** แถบเมนูด้านซ้าย > **Cluster** นี่คือหน้าแรกที่คุณเห็นหลังเปิด Cluster

หน้านี้คือภาพสรุปของ Cluster (กลุ่มโรงแรมที่บริหารร่วมกัน) แสดงว่าใช้หน่วยธุรกิจและที่นั่งไปเท่าไร ใครดูแล Cluster และชื่อกับโลโก้ของ Cluster

![หน้า Cluster](/screenshots/th/cluster-overview.png)

## ทำอะไรได้บ้าง

- ดูว่า Cluster ใช้หน่วยธุรกิจ (โรงแรม) และที่นั่งไปเท่าไร เทียบกับที่มีไลเซนส์
- เปิดหน่วยธุรกิจจากรายการ หรือกด **ดูทั้งหมด** เพื่อดูทุกแห่ง
- ดูว่าใครเป็นผู้ดูแล Cluster และกด **ดูทั้งหมด** เพื่อเปิดหน้า [ผู้ใช้งาน](/screens/users)
- เปลี่ยนชื่อ ชื่อแฝง และโลโก้ของ Cluster ด้วยปุ่ม **แก้ไข**

## สิ่งที่อยู่บนหน้าจอ

| ส่วน | แสดงอะไร |
| --- | --- |
| ชื่อและบรรทัดใต้ชื่อ | ชื่อ Cluster บรรทัดใต้ชื่อเขียนว่า **กลุ่มผู้เช่า** เป็นป้ายคงที่ที่ทุก Cluster มี |
| **หน่วยธุรกิจ** (กล่องสรุปด้านบน) | เช่น **4 / 5 ที่มีไลเซนส์** และ **ว่าง 1 จากโควตา 5** Cluster ใช้ 4 จาก 5 หน่วยที่มีไลเซนส์ เพิ่มได้อีก 1 |
| **ที่นั่ง** | เช่น **11 / 13 ที่มีไลเซนส์** และ **เหลือที่นั่งว่าง 2 ที่** ใช้ไป 11 จาก 13 ที่นั่ง แถบหนึ่งช่องคือหนึ่งที่นั่ง |
| **หน่วยธุรกิจ** (การ์ดรายการ) | หน่วยธุรกิจใน Cluster พร้อมรหัสสั้น |
| **บุคคล** | **ผู้ดูแล** ของ Cluster และจำนวนสมาชิกที่ไม่มีสิทธิ์ผู้ดูแล |
| **ข้อมูลระบุตัวตน** | **ชื่อ** **ชื่อแฝง** (ชื่อสั้นไม่เกิน 3 ตัวอักษร) และ **สถานะ** |
| **แบรนด์** | โลโก้ของ Cluster แสดงในแถบเมนู ตัวสลับ Cluster และรายการต่าง ๆ ทั่ว Carmen Blue ถ้าไม่มีโลโก้ จะแสดงตัวอักษรย่อของชื่อ |

## งานที่ทำบ่อย

### เปลี่ยนชื่อ ชื่อแฝง หรือโลโก้ของ Cluster

1. กด **แก้ไข** มุมขวาบน
2. คลิกค่าที่ต้องการเปลี่ยนใน **ข้อมูลระบุตัวตน** แล้วพิมพ์ค่าใหม่
3. ถ้าจะเปลี่ยนโลโก้ ใช้ปุ่มอัปโหลดใน **แบรนด์** แล้วเลือกไฟล์รูป
4. กด **บันทึกการแก้ไข** ถ้าจะออกโดยไม่บันทึก กด **ยกเลิก**

คุณเปลี่ยน **สถานะ** เองไม่ได้ ถ้าสถานะไม่ถูกต้อง [ติดต่อทีม support ของ Carmen](/getting-help)

### ดูว่ามีหน่วยธุรกิจอะไรใน Cluster

กด **ดูทั้งหมด** ข้าง **หน่วยธุรกิจ** หรือคลิกชื่อหน่วยธุรกิจเพื่อเปิด ดู [หน่วยธุรกิจ](/screens/business-units)

## ข้อควรระวัง

::: warning
ชื่อและโลโก้ที่คุณบันทึกที่นี่ ทุกคนใน Cluster จะเห็นในแถบเมนูและรายการต่าง ๆ ทั่ว Carmen Blue
:::

- คุณเพิ่มหน่วยธุรกิจหรือเพิ่มที่นั่งจากหน้านี้ไม่ได้ สองอย่างนี้ Carmen เป็นผู้ตั้งให้ [ติดต่อทีม support ของ Carmen](/getting-help)
- ถ้า Cluster ใช้หน่วยธุรกิจเกินที่มีไลเซนส์ หน่วยที่เกินจะอ่านได้อย่างเดียว แก้ไม่ได้ ดู [ไลเซนส์](/screens/licences)
