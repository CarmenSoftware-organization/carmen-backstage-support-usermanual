# ผู้ใช้งาน

**หาได้ที่ไหน:** แถบเมนูด้านซ้าย > **ผู้ใช้งาน**

หน้านี้เกี่ยวกับคนใน Cluster แสดงว่าใครเป็นสมาชิก ใครถือ **ที่นั่ง** (สิทธิ์ใช้ Carmen Blue) และมีคำเชิญใดที่ยังรออยู่ หน้านี้มีข้อความ **จัดการสมาชิกและคำเชิญที่รอดำเนินการสำหรับ cluster นี้**

![หน้าผู้ใช้งาน](/screenshots/th/users-list.png)

## ทำอะไรได้บ้าง

- ดูว่าใช้ที่นั่งไปเท่าไรและเหลือว่างเท่าไร
- เชิญคนใหม่ด้วย **เชิญผู้ใช้**
- หาสมาชิกด้วยช่อง **ค้นหาสมาชิก...**
- เปลี่ยนบทบาทของสมาชิกระหว่าง **ผู้ดูแล** กับ **ผู้ใช้**
- ปล่อยที่นั่งจากสมาชิก หรือคืนที่นั่งให้
- นำสมาชิกออกจาก Cluster
- ส่งคำเชิญซ้ำ หรือยกเลิกคำเชิญ

## แถบที่นั่ง

ด้านบน **ที่นั่งของ CLUSTER** แสดงเช่น **11 / 13 ที่มีไลเซนส์** และ **เหลือที่นั่งว่าง 2 ที่** แถบหนึ่งช่องคือหนึ่งที่นั่ง ถ้ามีคนถือที่นั่งมากกว่าที่ Cluster มีไลเซนส์ จะมีข้อความบอกว่ามีผู้ใช้กี่คนเกินจำนวนที่นั่งที่มีไลเซนส์

::: warning
ถ้าที่นั่งที่ใช้อยู่มากกว่าที่นั่งที่มีไลเซนส์ จะมีคำเตือนให้ปล่อยที่นั่ง ระหว่างนั้น Carmen Blue จะบันทึกการเปลี่ยนแปลงในหน่วยธุรกิจของ Cluster ไม่ได้ ให้ปล่อยที่นั่งส่วนเกิน หรือ [ติดต่อทีม support ของ Carmen](/getting-help) เพื่อเพิ่มที่นั่ง
:::

## แท็บสมาชิก

แท็บ **สมาชิก** มีตัวเลขบอกจำนวนสมาชิกของ Cluster

| คอลัมน์ | แสดงอะไร |
| --- | --- |
| **#** | ลำดับแถว |
| **ชื่อ** และ **อีเมล** | ตัวคนนั้น |
| **บทบาทใน Cluster** | **ผู้ดูแล** (ดูแล Cluster ได้) หรือ **ผู้ใช้** (สมาชิกทั่วไป) |
| **ที่นั่ง** | หน่วยธุรกิจที่คนนั้นถือที่นั่ง หรือข้อความถ้าไม่มีที่นั่ง |
| **สร้างเมื่อ** และ **แก้ไขเมื่อ** | สมาชิกภาพถูกสร้างและแก้ไขล่าสุดเมื่อไร |

เหนือตารางมีปุ่มกรองรายการสามปุ่ม คือ **สมาชิกทั้งหมด** **ถือที่นั่ง** และ **ไม่มีที่นั่ง** แต่ละปุ่มมีตัวเลขจำนวน

ปุ่ม **...** ท้ายแถวเปิดเมนู

- **ตั้งเป็น ผู้ดูแล** หรือ **ตั้งเป็น ผู้ใช้** เปลี่ยนบทบาทใน Cluster ของคนนั้น
- **ปล่อยที่นั่ง** หรือ **คืนที่นั่ง** (แสดงเมื่อใช้ได้)
- **นำออก** นำคนนั้นออกจาก Cluster

## แท็บคำเชิญ

แท็บ **คำเชิญ** แสดงคำเชิญที่คุณส่งไป คอลัมน์คือ **อีเมล** **บทบาทใน Cluster** **สถานะ** **วันหมดอายุ** และ **วันที่เชิญ** สถานะคือ **รอตอบรับ** **ตอบรับแล้ว** **ปฏิเสธแล้ว** หรือ **เพิกถอนแล้ว**

เมนู **...** ที่แถวมี **ส่งใหม่** (ส่งคำเชิญอีกครั้ง) และ **เพิกถอน** (ยกเลิกคำเชิญ)

## งานที่ทำบ่อย

### เชิญคน

1. กด **เชิญผู้ใช้** มุมขวาบน
2. พิมพ์อีเมลของเขาในช่อง **อีเมล** เขาไม่จำเป็นต้องมีบัญชี Carmen Blue มาก่อน ลิงก์ในคำเชิญจะให้ตั้งรหัสผ่านและเข้าร่วมได้
3. เลือก **บทบาทใน cluster** เป็น **ผู้ดูแล** หรือ **ผู้ใช้**
4. ใต้ **สิทธิ์เข้าถึงหน่วยธุรกิจ** ติ๊กหน่วยธุรกิจที่เขาใช้ได้ แต่ละหน่วยเลือกบทบาทได้ และติ๊ก **ค่าเริ่มต้น** ได้หนึ่งหน่วย
5. กด **ส่ง**

คนนั้นจะปรากฏในแท็บ **คำเชิญ** ด้วยสถานะ **รอตอบรับ**

### ปล่อยที่นั่ง

1. หาคนนั้น กด **...** ท้ายแถว
2. กด **ปล่อยที่นั่ง**
3. อ่านข้อความแล้วยืนยัน

คนนั้นจะไม่ใช้ที่นั่งอีก และเข้าหน่วยธุรกิจของ Cluster ไม่ได้ จนกว่าคุณจะกด **คืนที่นั่ง** ถ้าเป็นบัญชีของคุณเอง คุณจะเข้าไม่ได้ด้วย โปรดระวัง

### คืนที่นั่ง

1. กด **...** ที่แถวของคนนั้น แล้วกด **คืนที่นั่ง** และยืนยัน
2. ถ้าไม่มีที่นั่งว่าง จะมีข้อความว่าที่นั่งเต็มแล้ว [ติดต่อทีม support ของ Carmen](/getting-help) เพื่อเพิ่มที่นั่ง

### เปลี่ยนบทบาทของคน

กด **...** ที่แถวของเขา แล้วกด **ตั้งเป็น ผู้ดูแล** หรือ **ตั้งเป็น ผู้ใช้** จะมีข้อความยืนยันการเปลี่ยน

## ข้อควรระวัง

::: warning
**นำออก** จะนำคนนั้นออกจากทั้ง Cluster ตรวจชื่อในข้อความถามให้ดีก่อนยืนยัน
:::

- เพิ่มที่นั่งจากหน้านี้ไม่ได้ [ติดต่อทีม support ของ Carmen](/getting-help)
- คำเชิญที่ **เพิกถอนแล้ว** ผู้รับตอบรับไม่ได้อีก
- ผู้ถือที่นั่งบางคนอาจไม่อยู่ในรายชื่อสมาชิก เพราะสมาชิกภาพใน Cluster ไม่ได้ใช้งานอยู่ ให้ปล่อยที่นั่งจากแท็บ **ผู้ใช้งาน** ของหน่วยธุรกิจ ดู [หน้าหน่วยธุรกิจ](/screens/business-unit-detail)
