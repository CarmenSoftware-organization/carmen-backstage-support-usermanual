# หน้าหน่วยธุรกิจ

**หาได้ที่ไหน:** แถบเมนูด้านซ้าย > **หน่วยธุรกิจ** > คลิกชื่อหน่วยธุรกิจ เส้นทางหน้าแสดง **ผู้ดูแล Cluster** > **หน่วยธุรกิจ** > **แก้ไข** คลิก **หน่วยธุรกิจ** (ซ้ายบน มีลูกศร) เพื่อกลับไปรายการ

นี่คือหน้าของหน่วยธุรกิจหนึ่งแห่ง (โรงแรมหรือสาขาหนึ่งแห่ง) ส่วนบนจะอยู่บนจอตลอด ใต้ส่วนบนมีหกแท็บ คือ **ภาพรวม** **โรงแรม** **บริษัท** **การตั้งค่า** **ไลเซนส์** และ **ผู้ใช้งาน**

## ส่วนบนของหน้า

- **ชื่อ** ของหน่วยธุรกิจ คลิกเพื่อแก้ได้
- ชื่อโรงแรม พร้อมเมืองและประเทศ อยู่ใต้ชื่อ
- ป้ายสถานะ **ใช้งาน** หรือ **ไม่ใช้งาน** คลิกเพื่อสลับ
- ป้าย **HQ** หรือ **ไม่ใช่ HQ** คลิกเพื่อสลับ
- รหัสสั้นของหน่วยธุรกิจ เช่น T03 แก้ไม่ได้
- **ที่นั่งของ CLUSTER** ด้านขวา เช่น **11 / 13 ที่มีไลเซนส์** และ **เหลือที่นั่งว่าง 2 ที่** นี่คือที่นั่งของทั้ง Cluster ไม่ใช่เฉพาะหน่วยนี้

## วิธีบันทึก

ในหน้านี้ ข้อความที่คุณแก้ **ยังไม่ถูกบันทึกทันที** หลังแก้ครั้งแรกจะมีแถบด้านล่างบอกจำนวน **การแก้ไขที่ยังไม่บันทึก**

- กด **บันทึกการแก้ไข** เพื่อเก็บ
- กด **ยกเลิก** เพื่อทิ้งการแก้ไข

โลโก้และรูปประจำตัวเป็นข้อยกเว้น จะบันทึกทันทีที่คุณเลือกไฟล์

::: warning
ไลเซนส์ที่นั่งของหน่วยธุรกิจที่ **ไม่ใช้งาน** จะไม่ถูกนับเข้าพูลที่นั่งของ Cluster การสลับ **ใช้งาน** หรือ **HQ** อาจเปลี่ยนวิธีนับที่นั่งและโควตา ถ้าไม่แน่ใจ [ติดต่อทีม support ของ Carmen](/getting-help) ก่อน
:::

## โรงแรม

![แท็บโรงแรม](/screenshots/th/bu-hotel.png)

ข้อมูลที่ใช้ติดต่อโรงแรม

- **ติดต่อ:** **ชื่อโรงแรม** **โทรศัพท์** และ **อีเมล**
- **ที่ตั้ง:** ที่อยู่โรงแรม **เปิดในแผนที่** แสดงที่อยู่บนแผนที่

คลิกค่าเพื่อแก้ แล้วกด **บันทึกการแก้ไข**

## บริษัท

![แท็บบริษัท](/screenshots/th/bu-company.png)

บริษัทที่ถูกเรียกเก็บเงินสำหรับหน่วยธุรกิจนี้

- **ข้อมูลออกบิล:** **ชื่อบริษัท** **โทรศัพท์** **อีเมล** **เลขประจำตัวผู้เสียภาษี** และ **สาขา**
- **ที่อยู่ออกบิล:** ที่อยู่ของบริษัท ถ้าเหมือนที่อยู่โรงแรม กด **คัดลอกจากที่อยู่โรงแรม**

คลิกค่าเพื่อแก้ แล้วกด **บันทึกการแก้ไข**

- **รูปแบบตามภูมิภาค:** **เขตเวลา** **รูปแบบวันที่** **รูปแบบวันที่-เวลา** **รูปแบบเวลา** **รูปแบบเวลาแบบยาว** และ **รูปแบบเวลาแบบสั้น**
- **ตั้งค่าการคำนวณ:** **วิธีคำนวณ** เช่น FIFO
- **รูปแบบตัวเลข:** **รูปแบบจำนวนเงิน** **รูปแบบจำนวน** และ **รูปแบบสูตร** แต่ละรายการมีตัวอย่าง เช่น "1234.5678 จะแสดงเป็น 1,234.568"

## ไลเซนส์

แท็บนี้มีเมนูย่อยของตัวเอง คือ **ที่นั่ง** **โมดูล** และ **Interface** แต่ละแท็บมีตัวเลขจำนวน ทุกอย่างในนี้อ่านได้อย่างเดียว

ลิงก์ **จัดการไลเซนส์** (มุมขวาบนของแท็บ) **ไม่ได้** ให้คุณเพิ่มหรือแก้ไลเซนส์ ลิงก์นี้เปิดหน้า [ไลเซนส์](/screens/licences) ของ Cluster ซึ่งคุณดูไลเซนส์ทั้งหมดและวันสิ้นสุดได้ ถ้าต้องการเพิ่มหรือแก้ไลเซนส์ [ติดต่อทีม support ของ Carmen](/getting-help)

### ที่นั่ง

![แท็บย่อยที่นั่ง](/screenshots/th/bu-licences-seats.png)

แสดงว่าที่นั่งของ Cluster มาจากไหน

- **BU นี้:** ที่นั่งจากไลเซนส์ของหน่วยธุรกิจนี้เอง
- **จาก BU อื่น:** ที่นั่งจากหน่วยธุรกิจอื่นใน Cluster
- **พูลระดับ cluster:** สองส่วนรวมกัน และจำนวนที่ **ใช้อยู่**

ข้อความใต้แถบเตือนว่าที่นั่งใช้ร่วมกันทั้ง Cluster ใต้ **ใบที่นั่ง** แต่ละไลเซนส์แสดงเลขที่ วันที่ จำนวนที่นั่ง และสถานะ ไลเซนส์ที่ขึ้น **ต้องระบุวันที่สิ้นสุด** แปลว่ายังไม่มีวันสิ้นสุดบันทึกไว้ ถ้าเห็นแล้วไม่แน่ใจว่าต้องทำอย่างไร [ติดต่อทีม support ของ Carmen](/getting-help)

### โมดูล

![แท็บย่อยโมดูล](/screenshots/th/bu-licences-modules.png)

แสดง **โมดูล** (ส่วนของ Carmen Blue) ที่เปิดให้ใช้ และใช้ได้ถึงเมื่อไร ใต้ **สัญญา** คุณเห็นสัญญาหลัก วันที่ แถบวันที่เหลือ และสถานะ

### Interface

![แท็บย่อย Interface](/screenshots/th/bu-licences-interface.png)

แสดง **interface** (การเชื่อมต่อกับระบบอื่น) ที่หน่วยธุรกิจนี้ใช้ได้ พร้อมวันที่ เช่น "ไม่มีวันหมดอายุ" บรรทัดบนบอกจำนวนที่ใช้ได้จริง เช่น "ใช้ได้จริง 1 จาก 1 ใบ"

## ผู้ใช้งาน

![แท็บผู้ใช้งาน](/screenshots/th/bu-users.png)

คนที่ทำงานในหน่วยธุรกิจนี้ คอลัมน์คือ **ชื่อ** **อีเมล** **บทบาท BU** และ **สถานะ BU** **ผู้ดูแล** แสดงเป็นตัวหนา **ผู้ใช้** แสดงเป็นตัวจาง

| ต้องการ | ทำอย่างไร |
| --- | --- |
| เพิ่มคนที่อยู่ใน Cluster แล้ว | กด **เพิ่มผู้ใช้** ค้นหาแล้วเลือกคนนั้น |
| เปลี่ยนบทบาทหรือสถานะของคน | กดไอคอนดินสอที่แถวของเขา เลือก **บทบาท BU** และ **สถานะ BU** แล้วบันทึก |
| เอาคนออกจากหน่วยธุรกิจนี้ | กดไอคอนถังขยะสีแดงที่แถวของเขา แล้วยืนยันด้วย **นำออก** |

เมื่อคุณตั้งใครเป็น **ไม่ใช้งาน** กล่องข้อความจะบอกว่าการนี้คืนที่นั่งของ Cluster หรือไม่ ถ้าคนนั้นยังใช้งานอยู่ในหน่วยธุรกิจอื่นของ Cluster จะไม่คืนที่นั่ง

ถ้าจะนำคนที่ **ยังไม่อยู่** ใน Cluster เข้ามา ให้ใช้ **เชิญผู้ใช้** ที่หน้า [ผู้ใช้งาน](/screens/users)

## ข้อควรระวัง

- คุณแก้แท็บ **การตั้งค่า** หรือไลเซนส์ใด ๆ ไม่ได้ [ติดต่อทีม support ของ Carmen](/getting-help)
- การนำคนออกจากหน่วยธุรกิจ ทำให้เขาเข้าหน่วยนั้นไม่ได้
- ถ้าออกจากหน้านี้โดยไม่กด **บันทึกการแก้ไข** ข้อความที่แก้จะหายไป
