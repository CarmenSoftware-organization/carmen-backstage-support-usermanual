# อภิธานศัพท์

คำที่คุณจะเจอในหน้าจอผู้ดูแล Cluster ถ้าหน้าจอไทยกับอังกฤษใช้คำต่างกัน จะแสดงทั้งสองคำ

| ป้ายบนหน้าจอภาษาไทย | ป้ายภาษาอังกฤษ | ความหมาย |
| --- | --- | --- |
| Cluster | Cluster | กลุ่มโรงแรมที่บริหารร่วมกัน เช่น เครือโรงแรม คุณดูแลหนึ่ง Cluster หรือมากกว่า |
| หน่วยธุรกิจ | Business Unit (BU) | โรงแรมหรือสาขาหนึ่งแห่งใน Cluster Carmen เป็นผู้สร้างหน่วยธุรกิจให้คุณ |
| โควตาหน่วยธุรกิจ | Business Unit quota | จำนวนหน่วยธุรกิจที่ Cluster มีไลเซนส์ให้มีได้ ข้อความ "4 / 5 ที่มีไลเซนส์" แปลว่าใช้ไป 4 จาก 5 |
| ที่นั่ง | Seat | สิทธิ์ให้คนหนึ่งคนใช้ Carmen Blue ใน Cluster คนที่ทำงานในหลายหน่วยธุรกิจของ Cluster เดียวกันใช้ที่นั่งเพียงหนึ่งที่ |
| พูลระดับ cluster | Cluster pool | ที่นั่งทั้งหมดของทั้ง Cluster รวมกัน ที่นั่งใช้ร่วมกัน คนในหน่วยธุรกิจไหนก็ใช้จากพูลเดียวกัน |
| เหลือที่นั่งว่าง | Seats open | ที่นั่งที่มีไลเซนส์แต่ยังไม่มีคนใช้ |
| ปล่อยที่นั่ง / คืนที่นั่ง | Release seat / Restore seat | เอาที่นั่งคืนจากคน หรือคืนที่นั่งให้คน ระหว่างที่ปล่อยที่นั่ง คนนั้นเข้าหน่วยธุรกิจของ Cluster ไม่ได้ |
| ไลเซนส์ | License (ชื่อเมนู "Licenses") | ใบอนุญาตจาก Carmen ให้ใช้บางอย่างในช่วงเวลาหนึ่ง บางหน้าจอเขียนว่า "licence" ความหมายเดียวกัน |
| ใบที่นั่ง | Seat license | ไลเซนส์ที่เพิ่มที่นั่งให้พูลของ Cluster มีวันเริ่มและวันสิ้นสุด |
| สัญญา | Subscription | สัญญาหลักของหน่วยธุรกิจ บอกว่าเปิดโมดูลไหนบ้างและนานเท่าไร |
| โมดูล | Module | ส่วนหนึ่งของ Carmen Blue ที่สัญญาเปิดให้ใช้ แต่ละโมดูลครอบคลุมฟีเจอร์จำนวนหนึ่ง |
| Interface | Interface | การเชื่อมต่อระหว่าง Carmen Blue กับระบบอื่น เช่น ระบบขายหน้าร้าน (POS) |
| ใบสิทธิ์ interface | Interface license | ไลเซนส์ที่อนุญาตให้หน่วยธุรกิจหนึ่งแห่งใช้ interface หนึ่งตัว |
| HQ | HQ | สำนักงานใหญ่ หน่วยธุรกิจหนึ่งแห่งทำเครื่องหมายเป็น HQ ได้ เมื่อโควตาไม่พอ จะครอบคลุม HQ ก่อน |
| ผู้ดูแล / ผู้ใช้ (บทบาทใน Cluster) | Admin / User (Cluster Role) | ในรายการ **ผู้ใช้งาน** **ผู้ดูแล** คือคนที่ดูแลทั้ง Cluster ได้ **ผู้ใช้** คือสมาชิกทั่วไปที่ไม่มีสิทธิ์ผู้ดูแล |
| ผู้ดูแล / ผู้ใช้ (บทบาท BU) | Admin / User (BU Role) | บทบาทของคนนั้นภายในหน่วยธุรกิจหนึ่งแห่ง ตั้งแยกจากบทบาทใน Cluster |
| ใช้งาน / ไม่ใช้งาน | Active / Inactive | หน่วยธุรกิจหรือที่ของคนในหน่วยนั้นเปิดอยู่หรือปิดอยู่ |
| คำเชิญ | Invitation | ข้อความที่ชวนคนเข้าร่วม Cluster อยู่ในสถานะ **รอตอบรับ** จนกว่าเขาจะตอบ |
| การตั้งค่า | Configuration | เขตเวลา รูปแบบวันที่และตัวเลข และวิธีคำนวณของหน่วยธุรกิจ คุณดูได้อย่างเดียว |
