# ติดต่อ support

บางเรื่องคุณทำเองในหน้าจอไม่ได้ เช่น เปลี่ยนค่าตั้งค่าของหน่วยธุรกิจ (โรงแรม) หรือเพิ่มไลเซนส์ ทุกหน้าในคู่มือนี้ที่บอกให้ "ติดต่อทีม support ของ Carmen" จะพามาที่หน้านี้

## วิธีติดต่อ

ติดต่อทีม support ของ Carmen ผ่านช่องทางที่บริษัทของคุณใช้อยู่

## สิ่งที่ควรแจ้ง

- ชื่อ Cluster และชื่อหน่วยธุรกิจที่เกี่ยวข้อง
- สิ่งที่ต้องการให้ทำ หรือสิ่งที่เห็นบนหน้าจอ (ถ้ามีข้อความแจ้งเตือน ให้คัดลอกข้อความนั้นมาด้วย)
- ภาพหน้าจอ ถ้าถ่ายได้
