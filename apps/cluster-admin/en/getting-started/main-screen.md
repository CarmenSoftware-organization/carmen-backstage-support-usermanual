# The Main Screen

Once you are inside a Cluster, every screen has the same frame. This page explains it once.

![A Cluster screen with the sidebar on the left and the top bar above](/screenshots/en/main-screen.png)

## The sidebar (left)

At the top of the sidebar is the name and logo of the Cluster you are in. Click it to go back to the [Cluster](/en/screens/cluster) screen. Under it are four items:

| Menu item | What it opens |
| --- | --- |
| **Cluster** | The Cluster's details, logo and a summary. See [Cluster](/en/screens/cluster). |
| **Business Units** | The hotels in the Cluster. See [Business Units](/en/screens/business-units). |
| **Users** | The people in the Cluster, who holds a seat, and invitations. See [Users](/en/screens/users). |
| **Licenses** | The licenses the Cluster holds and when they end. See [Licenses](/en/screens/licences). |

The item for the screen you are on is highlighted. Click **Collapse** at the bottom to shrink the sidebar to icons. Click the same button again to open it.

::: tip
Your company may not use all four items yet. An item that is not ready is shown greyed out or is missing.
:::

## The top bar

| Part | What it does |
| --- | --- |
| Breadcrumb (for example **Cluster Admin** > **Cluster**) | Shows where you are. Click an earlier step to go back. |
| Cluster switcher (short name and arrows) | Moves you to another Cluster. Only shown if you look after more than one. See [Choose a Cluster](/en/getting-started/choose-cluster). |
| Language button | Switches the screen between Thai and English. |
| Theme button | Switches between a light and a dark look. |
| User menu (your name) | Opens your [Profile](/en/screens/profile) and **Log out**. If you also have other access, it has **Cluster Admin view** too. |

## The bottom strip

The thin strip at the bottom shows the app version and the date and time. You do not need it for daily work. It can be useful when you [contact Carmen support](/en/getting-help).
