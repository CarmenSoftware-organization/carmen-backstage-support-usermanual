# Glossary

These are the terms you meet on the Cluster Admin screens. Where the Thai and English screens use different words, both are shown.

| English label | Thai label | What it means |
| --- | --- | --- |
| Cluster | Cluster | A group of hotels managed together, for example a hotel chain. You look after one or more Clusters. |
| Business Unit (BU) | หน่วยธุรกิจ | One hotel or branch inside a Cluster. Carmen creates Business Units for you. |
| Business Unit quota | โควตาหน่วยธุรกิจ | How many Business Units the Cluster is licensed to have. A line like "4 / 5 licensed" means 4 are used out of 5 allowed. |
| Seat | ที่นั่ง | The right for one person to use Carmen Blue in the Cluster. A person who works in several Business Units of the same Cluster still takes only one seat. |
| Cluster pool | พูลระดับ cluster | All the seats of the whole Cluster put together. Seats are shared: people in any Business Unit draw from the same pool. |
| Seats open | เหลือที่นั่งว่าง | Seats that are licensed but not yet used. |
| Release seat / Restore seat | ปล่อยที่นั่ง / คืนที่นั่ง | Take a seat back from a person, or give it back. While a seat is released, the person cannot get into the Cluster's Business Units. |
| License (menu spelling "Licenses") | ไลเซนส์ | A permit from Carmen to use something for a period of time. Some screens write "licence". It is the same thing. |
| Seat license | ใบที่นั่ง | A license that adds seats to the Cluster pool, with a start date and an end date. |
| Subscription | สัญญา | The main contract of a Business Unit. It lists which modules are switched on and for how long. |
| Module | โมดูล | A part of Carmen Blue that a subscription switches on. Each module covers a number of features. |
| Interface | Interface | A connection between Carmen Blue and another system, for example a point-of-sale system. |
| Interface license | ใบสิทธิ์ interface | The license that allows one interface for one Business Unit. |
| HQ | HQ | Head office. A Business Unit can be marked as HQ. When quota runs short, HQ is covered first. |
| Admin / User (Cluster Role) | ผู้ดูแล / ผู้ใช้ | In the **Users** list, **Admin** means the person can look after the whole Cluster. **User** is an ordinary member without admin rights. |
| Admin / User (BU Role) | ผู้ดูแล / ผู้ใช้ | The person's role inside one Business Unit. It is set separately from the Cluster Role. |
| Active / Inactive | ใช้งาน / ไม่ใช้งาน | Whether a Business Unit or a person's place in it is switched on. |
| Invitation | คำเชิญ | A message that asks a person to join the Cluster. It stays **Pending** until they answer. |
| Configuration | การตั้งค่า | A Business Unit's time zone, date and number formats and calculation method. You can only view these. |
