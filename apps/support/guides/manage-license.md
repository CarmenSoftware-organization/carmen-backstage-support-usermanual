# จัดการ License

## สิ่งที่คุณจะทำได้

คู่มือนี้อธิบายวิธีบันทึกสิ่งที่ลูกค้าซื้อลงในระบบ เมื่อทำครบ คุณจะ

- เปิดดูสถานะไลเซนส์ (สิ่งที่ลูกค้าซื้อไว้) ของ **Cluster** (กลุ่มโรงแรมของลูกค้าหนึ่งราย) ได้
- สร้าง **สัญญา** (Subscription — สัญญาการใช้งานของโรงแรมหนึ่งแห่ง) และเลือกโมดูลที่ลูกค้าซื้อ
- เพิ่ม **ที่นั่ง** (จำนวนผู้ใช้ที่โรงแรมมีได้)
- เพิ่ม **โควตา BU** (จำนวนโรงแรมที่ Cluster สร้างได้)
- เพิ่ม **ใบสิทธิ์ interface** (สิทธิ์ให้โรงแรมเชื่อมต่อกับระบบภายนอก เช่น ระบบบัญชี)
- สร้าง **โมดูล license** (License Modules — ชุดฟีเจอร์ที่จัดไว้ล่วงหน้า ใช้เลือกตอนขาย) ใหม่

แต่ละส่วนทำแยกกันได้ ทำเฉพาะส่วนที่ต้องการก็ได้

**ใครทำได้:** ผู้ดูแลระบบสูงสุด หรือผู้ที่มีบทบาท (Backstage Role — ชุดสิทธิ์ที่บอกว่าคุณทำอะไรได้บ้าง) ที่ให้จัดการไลเซนส์และโมดูล license ได้

**สิ่งที่ต้องเตรียม**

- Cluster และหน่วยธุรกิจ (Business Unit — โรงแรมหรือสาขาหนึ่งแห่ง) ต้องมีอยู่แล้ว ถ้ายังไม่มี ดู [ตั้งค่าโรงแรมใหม่](/guides/setup-hotel)
- รายละเอียดจากใบสั่งซื้อหรือสัญญา เช่น จำนวนที่ซื้อ วันเริ่ม วันสิ้นสุด เลขที่ใบสั่งซื้อ และโมดูลที่ซื้อ

::: tip ชื่อในภาพตัวอย่าง
ภาพในคู่มือนี้ใช้ชื่อตัวอย่างที่ขึ้นต้นด้วย `MANUAL-DEMO-` เวลาทำจริง คุณจะเห็นชื่อจริงของลูกค้า เช่น "Grand Hotel Group" และ "Grand Hotel Bangkok"
:::

## ขั้นตอน

### ส่วนที่ 1: เปิดหน้าไลเซนส์ของ Cluster {#open}

1. ที่เมนูด้านซ้าย กด **ไลเซนส์** ด้านบนของหน้าแสดง **ความจุรวมทั้งระบบ** คือภาพรวมของทุก Cluster รวมกัน
2. ที่แท็บ **ตามคลัสเตอร์** พิมพ์ชื่อหรือรหัสของ Cluster ในช่องค้นหา ดูเพิ่มเติมที่ [ค้นหา](/getting-started/common-actions#search)

   ![หน้าไลเซนส์ ค้นหา Cluster แล้ว](/screenshots/th/guide-manage-license-01-licenses-list.png)

3. กดรหัสของ Cluster (ตัวอักษรสีน้ำเงิน) หน้าไลเซนส์ของ Cluster จะเปิดขึ้น แถบด้านบนสรุปจำนวนโรงแรม ที่นั่ง และสัญญา และมีแท็บ **โควตา BU** **ที่นั่ง** และ **สัญญา**

   ![หน้าไลเซนส์ของ Cluster](/screenshots/th/guide-manage-license-02-license-center.png)

   อีกทางหนึ่ง คุณเปิดหน้านี้ได้จากหน้าของ Cluster โดยกดปุ่ม **จัดการไลเซนส์**

### ส่วนที่ 2: สร้างสัญญาและเลือกโมดูล {#subscription}

1. กดแท็บ **สัญญา** แล้วกดปุ่ม **เพิ่มสัญญา**

   ![แท็บสัญญาที่ยังไม่มีสัญญา](/screenshots/th/guide-manage-license-03-subscriptions-tab-empty.png)

2. ช่อง **Cluster** เลือกไว้ให้แล้ว เลือก **หน่วยธุรกิจ** ที่ทำสัญญา สัญญาหนึ่งใบผูกกับหน่วยธุรกิจเดียว และย้ายไปหน่วยธุรกิจอื่นภายหลังไม่ได้
3. เลือก **วันที่เริ่ม** และ **วันที่สิ้นสุด** หรือกดปุ่มเดือนใต้หัวข้อ **ระยะที่ใช้บ่อย** เพื่อเลือกช่วงเร็วขึ้น การ์ดด้านขวาแสดงว่าสัญญาครอบคลุมกี่เดือน

   ![ฟอร์มเพิ่มสัญญาที่กรอกแล้ว](/screenshots/th/guide-manage-license-04-subscription-form-filled.png)

4. กดปุ่ม **สร้างสัญญา** ระบบจะแสดงข้อความ **สร้าง สัญญา สำเร็จ** และเปิดหน้าของสัญญาใหม่ ซึ่งมีเลขที่ขึ้นต้นด้วย `SUB-` ในกล่อง **แก้ไขสัญญา** คุณแก้ได้เฉพาะช่วงวันที่และสถานะ

   ![หน้าของสัญญาใหม่](/screenshots/th/guide-manage-license-05-subscription-created.png)

5. ในกล่อง **โมดูลที่ซื้อ** ติ๊กโมดูลที่ลูกค้าซื้อ เช่น **Full Access** ตัวเลขข้างชื่อคือจำนวนฟีเจอร์ในโมดูลนั้น แถบด้านล่างจะขึ้นว่า **มีการแก้ไขที่ยังไม่บันทึก**

   ![ติ๊กโมดูลที่ซื้อแล้ว ยังไม่บันทึก](/screenshots/th/guide-manage-license-06-subscription-groups-picked.png)

6. กดปุ่ม **บันทึกการแก้ไข** ระบบจะแสดงข้อความ **บันทึกการแก้ไขแล้ว**

   ![หน้าของสัญญาหลังบันทึก](/screenshots/th/guide-manage-license-07-subscription-saved.png)

### ส่วนที่ 3: เพิ่มที่นั่ง {#seats}

1. กลับไปที่หน้าไลเซนส์ของ Cluster แล้วกดแท็บ **ที่นั่ง**
2. กดปุ่ม **เพิ่มไลเซนส์ที่นั่ง** ที่แถวของโรงแรม
3. กรอก **ที่นั่ง** เป็นจำนวนผู้ใช้ที่ซื้อเพิ่ม เช่น `10` และกรอก **เลขที่อ้างอิง** เช่น เลขที่ใบสั่งซื้อ (ไม่บังคับ)
4. เลือก **วันที่เริ่ม** และ **วันที่สิ้นสุด** ส่วน **เลขที่ไลเซนส์** ระบบออกให้เองเมื่อบันทึก

   ![ฟอร์มเพิ่มไลเซนส์ที่นั่งที่กรอกแล้ว](/screenshots/th/guide-manage-license-08-seat-form-filled.png)

5. กดปุ่ม **สร้างไลเซนส์**
6. กลับไปที่หน้าไลเซนส์ของ Cluster
7. กดแท็บ **ที่นั่ง** ใบใหม่จะอยู่ใต้ชื่อโรงแรม พร้อมสถานะ **ใช้งาน**

   ![แท็บที่นั่งหลังเพิ่มใบใหม่](/screenshots/th/guide-manage-license-09-seats-added.png)

ถ้าโรงแรมมีใบที่นั่งหลายใบที่ใช้งานอยู่พร้อมกัน ระบบจะนับรวมกันทั้งหมด เช่น ใบละ 5 ที่นั่งสองใบ เท่ากับ 10 ที่นั่ง

### ส่วนที่ 4: เพิ่มโควตา BU {#bu-quota}

1. ที่หน้าไลเซนส์ของ Cluster แท็บ **โควตา BU** กดปุ่ม **เพิ่มไลเซนส์โควตา BU**
2. กรอก **โควตา BU** เป็นจำนวนโรงแรมทั้งหมดที่ Cluster นี้มีได้ เช่น `3` และกรอก **เลขที่อ้างอิง** (ไม่บังคับ)
3. เลือก **วันที่เริ่ม** แล้วเลือก **มีวันหมดอายุ** และใส่ **วันที่สิ้นสุด** หรือเลือก **ไม่มีวันหมดอายุ**
4. ช่อง **หมายเหตุ** ใช้จดรายละเอียดเพิ่มเติม (ไม่บังคับ)

   ![ฟอร์มเพิ่มไลเซนส์โควตา BU แบบไม่มีวันหมดอายุ](/screenshots/th/guide-manage-license-10-bu-quota-form-filled.png)

5. กดปุ่ม **สร้างไลเซนส์**
6. กลับไปที่หน้าไลเซนส์ของ Cluster แท็บ **โควตา BU** จะแสดงใบทั้งหมดของ Cluster

   ![แท็บโควตา BU มีสองใบ](/screenshots/th/guide-manage-license-11-bu-quota-added.png)

โควตา BU ต่างจากที่นั่ง: ระบบไม่นับรวมกัน แต่ใช้ใบเดียว คือใบที่เริ่มล่าสุด ใบอื่นจะขึ้นสถานะ **ถูกแทนที่**

ทำไมใบใหม่ในภาพจึงขึ้นว่า **ถูกแทนที่**: ใบโควตาใบแรกที่สร้างพร้อม Cluster เริ่มนับตั้งแต่เวลาที่สร้าง Cluster พอดี ส่วนใบที่สร้างจากฟอร์มนี้เริ่มนับตั้งแต่ต้นวันที่เลือก

- ถ้าใบใหม่เริ่มวันเดียวกับวันที่สร้าง Cluster ใบแรกจะนับว่าเริ่มทีหลัง จึงยังเป็นใบที่ใช้อยู่ (โควตา 2 ในภาพ)
- ถ้าใบใหม่เริ่มตั้งแต่วันถัดไป ใบใหม่จะมีผลทันทีที่ถึงวันเริ่ม
- ถ้าสร้างจากฟอร์มนี้สองใบที่เริ่มวันเดียวกัน ใบที่สร้างทีหลังจะเป็นใบที่ใช้

::: warning ยกเลิกใบ ย้อนกลับไม่ได้
ปุ่ม **ยกเลิกใบ** ในแถวของใบโควตา ทำให้ใบนั้นไม่ให้โควตาอีกต่อไป ใบจะยังอยู่ในรายการเพื่อตรวจย้อนหลังได้ แต่เปิดกลับไม่ได้ ตรวจให้แน่ใจก่อนกด
:::

### ส่วนที่ 5: เพิ่มใบสิทธิ์ interface {#interface}

1. ที่เมนูด้านซ้าย กด **หน่วยธุรกิจ** แล้วกดชื่อโรงแรม
2. กดแท็บ **ไลเซนส์** กล่อง **ไลเซนส์ผู้ใช้** แสดงที่นั่งและสัญญาของโรงแรม กล่อง **ใบสิทธิ์ interface** แสดงการเชื่อมต่อกับระบบภายนอก

   ![แท็บไลเซนส์ของหน่วยธุรกิจ](/screenshots/th/guide-manage-license-12-bu-licenses-tab.png)

3. กดปุ่ม **เพิ่มใบสิทธิ์ interface**
4. ที่ **โมดูล** เลือกระบบที่จะเชื่อมต่อ เช่น **Interface Carmen GL** รายการนี้แสดงเฉพาะโมดูลชนิด Interface ที่ยังขายอยู่
5. เลือก **วันที่เริ่ม** และ **วันที่สิ้นสุด** หรือเลือก **ไม่มีวันหมดอายุ** ช่อง **เลขที่อ้างอิง** และ **หมายเหตุ** ไม่บังคับ

   ![ฟอร์มเพิ่มใบสิทธิ์ interface ที่กรอกแล้ว](/screenshots/th/guide-manage-license-13-interface-form-filled.png)

6. กดปุ่ม **สร้างไลเซนส์**
7. กลับไปที่แท็บ **ไลเซนส์** ของหน่วยธุรกิจ ใบใหม่ (เลขที่ขึ้นต้นด้วย `INF-`) จะแสดงพร้อมสถานะ **ใช้งาน**

   ![แท็บไลเซนส์ของหน่วยธุรกิจ มีใบสิทธิ์ interface แล้ว](/screenshots/th/guide-manage-license-14-interface-added.png)

ใบสิทธิ์ interface ใช้ได้เฉพาะเมื่อสัญญาหลักของโรงแรมยังใช้งานอยู่ ถ้าสัญญาหลักหมดอายุ การเชื่อมต่อจะปิด แม้วันที่ของใบสิทธิ์ยังไม่หมด

### ส่วนที่ 6: สร้างโมดูลใหม่ {#module}

ระบบไม่มีปุ่มคัดลอกโมดูล ถ้าต้องการโมดูลที่คล้ายโมดูลเดิม ให้สร้างโมดูลใหม่แล้วเลือกฟีเจอร์เอง

1. ที่เมนูด้านซ้าย กด **โมดูล license** หน้า **แค็ตตาล็อก license** จะเปิดที่แท็บ **โมดูล**

   ![หน้าแค็ตตาล็อก license แท็บโมดูล](/screenshots/th/guide-manage-license-15-modules-list.png)

2. กดปุ่ม **สร้างโมดูล**
3. กรอก **รหัส** ของโมดูล รหัสเปลี่ยนไม่ได้หลังสร้างโมดูลแล้ว
4. เลือก **ชนิด**: **ทั่วไป** สำหรับโมดูลที่ขายในสัญญาหลัก หรือ **Interface** สำหรับใบสิทธิ์ interface ชนิดตั้งได้ตอนสร้างเท่านั้น
5. กรอก **ชื่อ** และ **คำอธิบาย** (ไม่บังคับ)
6. กรอก **ลำดับ** คือตำแหน่งของโมดูลนี้บนฟอร์มขาย เลขน้อยขึ้นก่อน ใช้เลขที่ไม่ซ้ำกับโมดูลอื่น
7. ที่ **สถานะ** เลือก **ขายอยู่** ถ้าต้องการให้เลือกโมดูลนี้ในสัญญาใหม่ได้ หรือ **หยุดขาย**
8. ในกล่อง **feature ในโมดูลนี้** ติ๊กฟีเจอร์ที่ต้องการ หรือกด **เอาทั้งหมดใน** ตามด้วยชื่อหมวด เพื่อเลือกทั้งหมวด ตัวเลขด้านขวาบนบอกว่าเลือกไปกี่รายการ

   ![ฟอร์มสร้างโมดูลที่กรอกแล้ว](/screenshots/th/guide-manage-license-16-module-form-filled.png)

9. กดปุ่ม **บันทึกการแก้ไข** ที่แถบด้านล่าง ระบบจะแสดงข้อความ **สร้างโมดูลแล้ว**

   ![หน้าของโมดูลใหม่หลังบันทึก](/screenshots/th/guide-manage-license-17-module-created.png)

## ตรวจสอบว่าสำเร็จ

- หน้าไลเซนส์ของ Cluster แถบสรุปด้านบนแสดงจำนวนโรงแรม ที่นั่ง และสัญญาที่ตรงกับที่ลูกค้าซื้อ
- แท็บ **ไลเซนส์** ของหน่วยธุรกิจ แสดงสัญญาและใบสิทธิ์ interface พร้อมสถานะ **ใช้งาน**
- ใบโควตา BU ที่ต้องการให้มีผล มีสถานะ **ใช้งาน** ไม่ใช่ **ถูกแทนที่**
- โมดูลใหม่ที่ **ขายอยู่** ขึ้นในกล่อง **โมดูลที่ซื้อ** ของสัญญา (ชนิดทั่วไป) หรือในรายการ **โมดูล** ของใบสิทธิ์ interface (ชนิด Interface)

## แก้ปัญหาเบื้องต้น

- **ใบโควตา BU ใหม่ขึ้นว่า ถูกแทนที่:** มีใบอื่นที่เริ่มทีหลังและระบบยังใช้อยู่ หรือใบใหม่เริ่มวันเดียวกับวันที่สร้าง Cluster ดูคำอธิบายท้ายส่วนที่ 4
- **สร้างสัญญาให้หน่วยธุรกิจผิดแห่ง:** สัญญาย้ายหน่วยธุรกิจไม่ได้ ให้สร้างสัญญาใหม่ให้หน่วยธุรกิจที่ถูกต้อง
- **ข้อความ "ยังไม่มีโมดูล interface ที่ขายอยู่ — สร้างที่หน้าโมดูล license ก่อน":** สร้างโมดูลชนิด **Interface** และตั้งสถานะ **ขายอยู่** ก่อน (ส่วนที่ 6)
- **ใบสิทธิ์ interface ขึ้นข้อความว่าวันของใบยังไม่หมด แต่สัญญาหลักหมดอายุ:** ต่อสัญญาหลักของโรงแรมก่อน interface จึงจะกลับมาใช้ได้
- **ข้อความสีส้มใต้ช่องลำดับ ว่าลำดับซ้ำกับโมดูลอื่น:** เปลี่ยนเป็นเลขที่ยังไม่มีโมดูลอื่นใช้
- **รหัสหรือชนิดของโมดูลผิด:** สองช่องนี้แก้ไม่ได้หลังสร้าง ให้สร้างโมดูลใหม่ที่ถูกต้อง แล้วตั้งโมดูลที่ผิดเป็น **หยุดขาย**
- **ไม่เห็นปุ่มที่คู่มือพูดถึง หรือขึ้นหน้าไม่มีสิทธิ์เข้าถึง:** ดู [หน้าแจ้งว่าไม่มีสิทธิ์](/getting-started/common-actions#access-denied)
