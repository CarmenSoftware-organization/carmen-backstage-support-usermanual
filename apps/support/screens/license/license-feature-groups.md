# กลุ่มสิทธิ์ license

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **จัดการใบอนุญาต** > **กลุ่มสิทธิ์ license** หน้า **แค็ตตาล็อก license** จะเปิดที่แท็บ **ชุดที่ขาย**

**กลุ่มสิทธิ์ license** (License Feature Group — ชุดฟีเจอร์ที่จัดไว้ล่วงหน้า) คือ "แพ็กเกจ" ที่คุณเลือกตอนขาย แทนการติ๊กฟีเจอร์ทีละตัว กลุ่มมี 2 ชนิด:

- **ทั่วไป:** ขายบนสัญญาหลักของโรงแรม เลือกได้หลายกลุ่มต่อสัญญา
- **Interface:** ขายบนใบสิทธิ์ interface (สิทธิ์เชื่อมต่อกับระบบภายนอก) ใบละหนึ่งกลุ่ม

ใช้หน้านี้สร้างกลุ่มใหม่ เปลี่ยนฟีเจอร์ในกลุ่ม เปลี่ยนลำดับบนฟอร์มขาย และหยุดขายกลุ่มที่เลิกขายแล้ว แท็บ **ฟีเจอร์** ในหน้าเดียวกันคือหน้า [ฟีเจอร์ที่ขายได้](/screens/license/license-features)

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ**

- **ค้นหา** ด้วยรหัสหรือชื่อ ดู [ค้นหา](/getting-started/common-actions#search)
- ติ๊ก **เฉพาะที่ใช้งาน** เพื่อซ่อนกลุ่มที่หยุดขายแล้ว
- **ส่งออก** เป็นไฟล์ CSV ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **สร้างกลุ่ม:** ปุ่ม **สร้างกลุ่ม**
- **อ่านตาราง:** **ลำดับ** (ตำแหน่งบนฟอร์มขาย) **รหัส** (กลุ่มชนิด Interface มีป้าย Interface) **ชื่อ** **จำนวน feature** (เช่น "98 จาก 111 สิทธิ์") **สัญญาที่ใช้** (กี่สัญญาใช้ชุดนี้อยู่) และ **สถานะ**
- **เมนูของแถว** (ปุ่ม `⋯`): **แก้ไข** และ **ลบ** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)

ระบบไม่มีปุ่มคัดลอกกลุ่ม ถ้าต้องการชุดที่คล้ายชุดเดิม ให้สร้างกลุ่มใหม่แล้วเลือกฟีเจอร์เอง

**หน้าของกลุ่ม**

- ช่องข้อมูลของกลุ่ม (ดูตารางด้านล่าง)
- แผง **สิทธิ์ในชุดนี้** ด้านขวา: จำนวนฟีเจอร์ที่บันทึกจริงเทียบกับทั้งแค็ตตาล็อก และบรรทัด "ติ๊กเอง ... · module แม่ที่ติดมา ..." ถ้ามีสัญญาใช้กลุ่มนี้อยู่ แผงนี้จะเตือนว่าการเพิ่มหรือถอดฟีเจอร์กระทบทุกสัญญาพร้อมกัน
- กล่อง **feature ในกลุ่มนี้:** ฟีเจอร์ทั้งหมดแยกตามหมวด (module) ค้นหาได้ กาง/พับหมวดได้ และแต่ละหมวดมีปุ่มเลือกทั้งหมวดหรือไม่เอาทั้งหมวด

## อธิบายช่องข้อมูล

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **รหัส** (จำเป็น) | รหัสสั้นของกลุ่ม | เช่น `FULL_ACC` เปลี่ยนไม่ได้หลังสร้างกลุ่มแล้ว |
| **ชนิด** | กลุ่มนี้ขายบนใบแบบไหน | **ทั่วไป** หรือ **Interface** ตั้งได้ตอนสร้างเท่านั้น |
| **ชื่อ** (จำเป็น) | ชื่อที่เห็นตอนเลือกในสัญญา | เช่น "Full Accounting" |
| **คำอธิบาย** | ข้อความอธิบายกลุ่ม | ไม่บังคับ |
| **ลำดับ** | ตำแหน่งของชุดนี้บนฟอร์มขาย | เลขน้อยขึ้นก่อน ถ้าซ้ำกับกลุ่มอื่น จะมีข้อความสีส้มเตือนว่าลำดับบนฟอร์มขายจะไม่ถูกกำหนด |
| **สถานะ** | ยังขายชุดนี้อยู่หรือไม่ | **ขายอยู่** = เลือกใส่สัญญาใหม่ได้ **หยุดขาย** = ไม่ขึ้นบนฟอร์มขาย สัญญาที่ผูกไว้แล้วไม่ถูกแตะ |
| **feature ในกลุ่มนี้** | ฟีเจอร์ที่อยู่ในชุด | การเลือกฟีเจอร์จะได้สิทธิ์ระดับหมวดติดมาด้วย รายการที่บันทึกจึงยาวกว่าที่ติ๊กไว้ได้ |

## งานที่ทำบ่อย

**สร้างกลุ่มใหม่**

ดูขั้นตอนพร้อมภาพที่ [จัดการ License ส่วนที่ 6](/guides/manage-license#feature-group)

**เพิ่มหรือถอดฟีเจอร์ในกลุ่ม**

1. ที่หน้ารายการ กดรหัสของกลุ่ม (ตัวอักษรสีน้ำเงิน) หรือกด `⋯` > **แก้ไข**
2. ดูแผง **สิทธิ์ในชุดนี้** ว่ามีสัญญาใช้ชุดนี้อยู่กี่ฉบับ
3. ในกล่อง **feature ในกลุ่มนี้** ติ๊กหรือเอาติ๊กออก
4. กดปุ่ม **บันทึกการแก้ไข** ที่แถบด้านล่าง ระบบจะแสดงข้อความ **บันทึกกลุ่มแล้ว**

**หยุดขายกลุ่ม**

1. เปิดหน้าของกลุ่ม
2. ที่ **สถานะ** กด **หยุดขาย** ถ้ามีสัญญาผูกอยู่ หน้าจอจะเตือนให้ตรวจสัญญาเหล่านั้นก่อน
3. กดปุ่ม **บันทึกการแก้ไข**

**ลบกลุ่ม**

1. ที่หน้ารายการ กด `⋯` > **ลบ**
2. กล่อง **ลบกลุ่มนี้?** จะถามยืนยัน ถ้ามีสัญญาใช้ชุดนี้อยู่ กล่องจะบอกจำนวน กด **ลบ**

## ข้อควรระวัง

::: warning การลบกลุ่มย้อนกลับไม่ได้
กล่องยืนยันบอกว่ากลุ่มและรายการฟีเจอร์ข้างในจะถูกลบ ย้อนกลับไม่ได้ และหน้าจอนี้ไม่มีปุ่มกู้คืน ถ้าแค่ไม่ต้องการขายชุดนี้แล้ว ให้ตั้งเป็น **หยุดขาย** แทน
:::

- การเพิ่มหรือถอดฟีเจอร์ในกลุ่มที่มีสัญญาใช้อยู่ มีผลกับทุกสัญญาที่ผูกกลุ่มนี้พร้อมกัน ไม่ใช่แค่สัญญาใหม่
- **รหัส** และ **ชนิด** แก้ไม่ได้หลังสร้าง ถ้าผิด ให้สร้างกลุ่มใหม่ที่ถูกต้อง แล้วตั้งกลุ่มเดิมเป็น **หยุดขาย**
