# โมดูล license

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **จัดการใบอนุญาต** > **โมดูล license** หน้า **แค็ตตาล็อก license** จะเปิดที่แท็บ **โมดูล**

**โมดูล license** (License Modules — ชุดฟีเจอร์ที่จัดไว้ล่วงหน้า) คือ "แพ็กเกจ" ที่คุณเลือกตอนขาย แทนการติ๊กฟีเจอร์ทีละตัว โมดูลมี 2 ชนิด:

- **ทั่วไป:** ขายบนสัญญาหลักของโรงแรม เลือกได้หลายโมดูลต่อสัญญา
- **Interface:** ขายบนใบสิทธิ์ interface (สิทธิ์เชื่อมต่อกับระบบภายนอก) ใบละหนึ่งโมดูล

ใช้หน้านี้สร้างโมดูลใหม่ เปลี่ยนฟีเจอร์ในโมดูล เปลี่ยนลำดับบนฟอร์มขาย และหยุดขายโมดูลที่เลิกขายแล้ว แท็บ **ฟีเจอร์** ในหน้าเดียวกันคือหน้า [ฟีเจอร์ที่ขายได้](/screens/license/license-features)

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ**

- **ค้นหา** ด้วยรหัสหรือชื่อ ดู [ค้นหา](/getting-started/common-actions#search)
- ติ๊ก **เฉพาะที่ใช้งาน** เพื่อซ่อนโมดูลที่หยุดขายแล้ว
- **ส่งออก** เป็นไฟล์ CSV ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **สร้างโมดูล:** ปุ่ม **สร้างโมดูล**
- **อ่านตาราง:** **ลำดับ** (ตำแหน่งบนฟอร์มขาย) **รหัส** (โมดูลชนิด Interface มีป้าย Interface) **ชื่อ** **จำนวน feature** (เช่น "98 จาก 111 สิทธิ์") **สัญญาที่ใช้** (กี่สัญญาใช้โมดูลนี้อยู่) และ **สถานะ**
- **เมนูของแถว** (ปุ่ม `⋯`): **แก้ไข** และ **ลบ** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)

ระบบไม่มีปุ่มคัดลอกโมดูล ถ้าต้องการโมดูลที่คล้ายโมดูลเดิม ให้สร้างโมดูลใหม่แล้วเลือกฟีเจอร์เอง

**หน้าของโมดูล**

- ช่องข้อมูลของโมดูล (ดูตารางด้านล่าง)
- แผง **สิทธิ์ในโมดูลนี้** ด้านขวา: จำนวนฟีเจอร์ที่บันทึกจริงเทียบกับทั้งแค็ตตาล็อก และบรรทัด "ติ๊กเอง ... · หมวดฟีเจอร์แม่ที่ติดมา ..." ถ้ามีสัญญาใช้โมดูลนี้อยู่ แผงนี้จะเตือนว่าการเพิ่มหรือถอดฟีเจอร์กระทบทุกสัญญาพร้อมกัน
- กล่อง **feature ในโมดูลนี้:** ฟีเจอร์ทั้งหมดแยกตามหมวดฟีเจอร์ (feature area เช่น Accounting) ค้นหาได้ กาง/พับหมวดได้ และแต่ละหมวดมีปุ่มเลือกทั้งหมวดหรือไม่เอาทั้งหมวด

## อธิบายช่องข้อมูล

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **รหัส** (จำเป็น) | รหัสสั้นของโมดูล | เช่น `FULL_ACC` เปลี่ยนไม่ได้หลังสร้างโมดูลแล้ว |
| **ชนิด** | โมดูลนี้ขายบนใบแบบไหน | **ทั่วไป** หรือ **Interface** ตั้งได้ตอนสร้างเท่านั้น |
| **ชื่อ** (จำเป็น) | ชื่อที่เห็นตอนเลือกในสัญญา | เช่น "Full Accounting" |
| **คำอธิบาย** | ข้อความอธิบายโมดูล | ไม่บังคับ |
| **ลำดับ** | ตำแหน่งของโมดูลนี้บนฟอร์มขาย | เลขน้อยขึ้นก่อน ถ้าซ้ำกับโมดูลอื่น จะมีข้อความสีส้มเตือนว่าลำดับบนฟอร์มขายจะไม่ถูกกำหนด |
| **สถานะ** | ยังขายโมดูลนี้อยู่หรือไม่ | **ขายอยู่** = เลือกใส่สัญญาใหม่ได้ **หยุดขาย** = ไม่ขึ้นบนฟอร์มขาย สัญญาที่ผูกไว้แล้วไม่ถูกแตะ |
| **feature ในโมดูลนี้** | ฟีเจอร์ที่อยู่ในโมดูล | การเลือกฟีเจอร์จะได้สิทธิ์ระดับหมวดฟีเจอร์ติดมาด้วย รายการที่บันทึกจึงยาวกว่าที่ติ๊กไว้ได้ |

## งานที่ทำบ่อย

**สร้างโมดูลใหม่**

ดูขั้นตอนพร้อมภาพที่ [จัดการ License ส่วนที่ 6](/guides/manage-license#module)

**เพิ่มหรือถอดฟีเจอร์ในโมดูล**

1. ที่หน้ารายการ กดรหัสของโมดูล (ตัวอักษรสีน้ำเงิน) หรือกด `⋯` > **แก้ไข**
2. ดูแผง **สิทธิ์ในโมดูลนี้** ว่ามีสัญญาใช้โมดูลนี้อยู่กี่ฉบับ
3. ในกล่อง **feature ในโมดูลนี้** ติ๊กหรือเอาติ๊กออก
4. กดปุ่ม **บันทึกการแก้ไข** ที่แถบด้านล่าง ระบบจะแสดงข้อความ **บันทึกโมดูลแล้ว**

**หยุดขายโมดูล**

1. เปิดหน้าของโมดูล
2. ที่ **สถานะ** กด **หยุดขาย** ถ้ามีสัญญาผูกอยู่ หน้าจอจะเตือนให้ตรวจสัญญาเหล่านั้นก่อน
3. กดปุ่ม **บันทึกการแก้ไข**

**ลบโมดูล**

1. ที่หน้ารายการ กด `⋯` > **ลบ**
2. กล่อง **ลบโมดูลนี้?** จะถามยืนยัน ถ้ามีสัญญาใช้โมดูลนี้อยู่ กล่องจะบอกจำนวน กด **ลบ**

## ข้อควรระวัง

::: warning การลบโมดูลย้อนกลับไม่ได้
กล่องยืนยันบอกว่าโมดูลและรายการฟีเจอร์ข้างในจะถูกลบ ย้อนกลับไม่ได้ และหน้าจอนี้ไม่มีปุ่มกู้คืน ถ้าแค่ไม่ต้องการขายโมดูลนี้แล้ว ให้ตั้งเป็น **หยุดขาย** แทน
:::

- การเพิ่มหรือถอดฟีเจอร์ในโมดูลที่มีสัญญาใช้อยู่ มีผลกับทุกสัญญาที่ผูกโมดูลนี้พร้อมกัน ไม่ใช่แค่สัญญาใหม่
- **รหัส** และ **ชนิด** แก้ไม่ได้หลังสร้าง ถ้าผิด ให้สร้างโมดูลใหม่ที่ถูกต้อง แล้วตั้งโมดูลเดิมเป็น **หยุดขาย**
