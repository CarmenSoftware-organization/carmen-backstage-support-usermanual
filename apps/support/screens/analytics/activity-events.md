# บันทึกกิจกรรม

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **การวิเคราะห์** > **บันทึกกิจกรรม**

หน้านี้แสดงการกระทำของผู้ใช้บนหน้าจอทีละรายการ ว่าใครเปิดหน้าไหนหรือคลิกอะไร และเมื่อไหร่ ใช้เมื่อต้องการตรวจย้อนหลังว่าผู้ใช้คนหนึ่งทำอะไรไปบ้าง เช่น เมื่อลูกค้าแจ้งปัญหาแล้วต้องการรู้ว่าเขากดอะไรก่อนเกิดปัญหา หน้านี้ใช้ดูอย่างเดียว

แต่ละแถวคือ **เหตุการณ์** (การกระทำหนึ่งครั้ง) ซึ่งมีสองประเภท คือ **เปิดหน้า** และ **คลิก** ถ้าต้องการดูภาพรวมเป็นตัวเลข ให้ไปที่ [สถิติการใช้งาน](/screens/analytics/usage-analytics)

## สิ่งที่ทำได้ในหน้านี้

- **ค้นหา** ด้วยเส้นทางหน้า (ที่อยู่ของหน้าในโปรแกรม เช่น `/vendor-management`) หรือชื่อและข้อความของปุ่มที่ถูกคลิก ดู [ค้นหา](/getting-started/common-actions#search)
- **เลือกช่วงวัน:** **7 วันล่าสุด** (ค่าเริ่มต้น), **30 วันล่าสุด**, **90 วันล่าสุด** หรือ **กำหนดเอง** สูงสุด 90 วัน วันที่เป็นเวลาประเทศไทย
- **กรอง** (ปุ่ม **ตัวกรอง**) ตาม **ประเภทเหตุการณ์**, **หน่วยธุรกิจ**, **แอปพลิเคชัน**, **ผู้ใช้ (User ID)** (รหัสประจำตัวผู้ใช้), **เส้นทางหน้า** และ **รหัสเซสชัน** (รหัสของการใช้งานหนึ่งรอบ) ตัวกรองที่ใช้อยู่จะแสดงเป็นป้ายใต้ช่องค้นหา กดกากบาทที่ป้ายเพื่อเอาออก ดู [ตัวกรอง](/getting-started/common-actions#filters)
- **อ่านตาราง:** **เวลา**, **ผู้ใช้** (ชื่อและอีเมล), **หน่วยธุรกิจ**, **ประเภท**, **หน้า**, **องค์ประกอบ** (ปุ่มหรือลิงก์ที่ถูกคลิก) และ **แอป** เรียงจากล่าสุดก่อน
- **ดูรายละเอียดเหตุการณ์:** กดไอคอนรูปตาท้ายแถว
- **ส่งออก CSV** ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export) ไฟล์มีเฉพาะแถวที่แสดงอยู่ในหน้าตารางปัจจุบัน ถ้าต้องการมากกว่านั้น ให้เพิ่มจำนวนแถวต่อหน้าก่อนส่งออก

หน้านี้เปิดได้เฉพาะผู้ที่บทบาทอนุญาตให้ดูรายละเอียดรายบุคคล บางคนอาจเห็นหน้า [สถิติการใช้งาน](/screens/analytics/usage-analytics) แต่ไม่เห็นหน้านี้

## อธิบายช่องข้อมูล

หน้านี้ไม่มีฟอร์มให้กรอก แผง **รายละเอียดเหตุการณ์** แสดงข้อมูลต่อไปนี้:

| ช่อง | ความหมาย |
| --- | --- |
| **เวลา (เซิร์ฟเวอร์)** | เวลาที่ระบบได้รับบันทึก |
| **เวลา (ไคลเอนต์)** | เวลาบนเครื่องของผู้ใช้ตอนที่กด อาจต่างจากเวลาเซิร์ฟเวอร์เล็กน้อยถ้านาฬิกาเครื่องผู้ใช้ไม่ตรง |
| **ประเภท** | **เปิดหน้า** หรือ **คลิก** |
| **ผู้ใช้**, **อีเมล** | ผู้ที่ทำ |
| **หน่วยธุรกิจ** | โรงแรมที่ผู้ใช้กำลังทำงานอยู่ ขึ้น `-` ถ้าไม่ได้อยู่ในหน่วยธุรกิจใด |
| **แอปพลิเคชัน** | โปรแกรมที่ใช้ เช่น เว็บ Carmen Blue |
| **โดเมน** | ที่อยู่เว็บที่ผู้ใช้เปิด |
| **หน้า** | เส้นทางของหน้าที่ผู้ใช้อยู่ |
| **องค์ประกอบ**, **ข้อความองค์ประกอบ** | ปุ่มหรือลิงก์ที่ถูกคลิก และข้อความบนปุ่ม (เฉพาะเหตุการณ์คลิก) |
| **เซสชัน** | รหัสของการใช้งานรอบนั้น |
| **Event ID** | รหัสของเหตุการณ์นี้ ใช้อ้างอิงเมื่อแจ้งทีมระบบ |
| **props**, **user agent** | ข้อมูลเพิ่มเติมที่โปรแกรมส่งมา และข้อมูลเบราว์เซอร์ของผู้ใช้ ส่วนใหญ่ใช้โดยทีมระบบ |

## งานที่ทำบ่อย

**ดูว่าผู้ใช้คนหนึ่งทำอะไรก่อนเกิดปัญหา**

1. เลือก **ช่วงวัน** ที่ครอบคลุมเวลาที่เกิดปัญหา
2. ที่ช่อง **ค้นหา** พิมพ์ชื่อหน้าที่ลูกค้าแจ้ง หรือเปิด **ตัวกรอง** แล้วเลือก **หน่วยธุรกิจ** ของลูกค้า
3. หาแถวของผู้ใช้คนนั้น แล้วกดไอคอนรูปตา
4. ในแผงรายละเอียด กดปุ่ม **ดูเซสชันนี้ทั้งหมด**
5. ตารางจะแสดงทุกเหตุการณ์ในการใช้งานรอบนั้น เรียงตามเวลา

**ล้างตัวกรองทั้งหมด**

1. กดกากบาทที่ป้ายตัวกรองแต่ละป้ายใต้ช่องค้นหา

## ข้อควรระวัง

- หน้านี้ใช้ดูอย่างเดียว ไม่มีการกระทำใดที่เปลี่ยนข้อมูล
- ข้อมูลในหน้านี้ระบุตัวบุคคลได้ (ชื่อ อีเมล และสิ่งที่เขาทำ) ใช้และส่งต่อไฟล์ CSV ด้วยความระมัดระวัง
