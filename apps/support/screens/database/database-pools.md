# Database Pools

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **ฐานข้อมูล** > **Database Pools** หัวหน้าจอเขียนว่า **Database Pool**

**Database Pool** คือ **ข้อมูลสำหรับเชื่อมต่อเครื่องที่เก็บฐานข้อมูลของโรงแรม** ที่บันทึกไว้หนึ่งชุด เช่น ที่อยู่ของเครื่อง ชื่อผู้ใช้ และรหัสผ่านที่ระบบใช้เข้าไปอ่านและเขียนข้อมูล ฐานข้อมูลของโรงแรมหลายแห่งเก็บอยู่บนเครื่องเดียวกันได้ จึงใช้ Pool เดียวกันได้หลาย **หน่วยธุรกิจ** (Business Unit — โรงแรมหรือสาขาหนึ่งแห่ง) แต่ละหน่วยธุรกิจเลือก Pool ของตัวเองที่ช่อง **Database Pool** ในกล่อง **การเชื่อมต่อฐานข้อมูล** แท็บ **เทคนิค** ของหน้า [หน่วยธุรกิจ](/screens/organization/business-units)

ข้อมูลการเชื่อมต่อเป็น **ความลับ** ใครได้ไปก็เข้าถึงข้อมูลของโรงแรมได้โดยตรง

**ใครใช้หน้านี้และเมื่อไร:** เป็นงานของทีมเทคนิค ใช้เมื่อเพิ่มเครื่องเก็บฐานข้อมูลใหม่ หรือเมื่อที่อยู่หรือรหัสผ่านของเครื่องเปลี่ยน ผู้ดูแลทั่วไปไม่ต้องใช้หน้านี้ในงานประจำวัน

## สิ่งที่ทำได้ในหน้านี้

- **ดูรายการ Pool:** คอลัมน์ **การเชื่อมต่อ** แสดงที่อยู่ในรูป ชื่อผู้ใช้@โฮสต์:พอร์ต/ฐานข้อมูล ใต้ที่อยู่อาจมีชื่อของ Pool และหมายเหตุ เช่น Pool ที่ระบบสร้างให้อัตโนมัติจากข้อมูลการเชื่อมต่อเดิมของหน่วยธุรกิจ จะมีหมายเหตุขึ้นต้นว่า **สร้างอัตโนมัติจาก** (หมายเหตุเป็นข้อมูลที่บันทึกไว้ จึงแสดงเป็นภาษาไทยทั้งสองภาษา)
- **คัดลอกที่อยู่การเชื่อมต่อ:** ไอคอนคัดลอกข้างที่อยู่ ระบบจะขึ้นว่า **คัดลอกที่อยู่การเชื่อมต่อแล้ว** ที่อยู่ที่คัดลอกไม่มีรหัสผ่าน
- **ค้นหา** และ **ตัวกรอง** ตามสถานะ **ใช้งาน** / **ไม่ใช้งาน** ดู [ค้นหา](/getting-started/common-actions#search) และ [ตัวกรอง](/getting-started/common-actions#filters)
- **ส่งออก CSV** ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export) ไฟล์มีที่อยู่ โฮสต์ พอร์ต ฐานข้อมูล และชื่อผู้ใช้ แต่ไม่มีรหัสผ่าน
- **ดูรายละเอียด:** กดที่อยู่ในคอลัมน์ **การเชื่อมต่อ** เพื่อเปิด รหัสผ่านจะขึ้นว่า **เก็บไว้แล้ว ซ่อนอยู่** เสมอ
- **เพิ่ม Pool**, **แก้ไข** และ **ลบ** (ปุ่ม `⋯` ท้ายแถว) แสดงเฉพาะผู้ที่บทบาทให้แก้ไข Database Pool ได้ ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)
- หน้ารายละเอียดเปิดในโหมดดู กด **แก้ไข** เพื่อเปลี่ยนค่า ดู [โหมดดูและโหมดแก้ไข](/getting-started/common-actions#view-edit) และ [บันทึกและยกเลิก](/getting-started/common-actions#save-cancel)

## อธิบายช่องข้อมูล

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ชื่อ** (จำเป็น) | ชื่อที่ใช้เรียก Pool นี้ ห้ามซ้ำกับ Pool อื่น | เช่น `tenant-primary` ถ้าซ้ำ ระบบจะขึ้นว่า **มี database pool ชื่อนี้อยู่แล้ว** |
| **สถานะ** | ติ๊ก **ใช้งาน** เพื่อให้หน่วยธุรกิจใช้ Pool นี้ได้ | ค่าเริ่มต้นคือติ๊กไว้ ถ้าเอาออก โรงแรมที่ใช้ Pool นี้จะเชื่อมต่อฐานข้อมูลไม่ได้ ดูข้อควรระวัง |
| **คำอธิบาย** | ข้อความอธิบาย Pool นี้ | ไม่บังคับ |
| **โฮสต์** (จำเป็น) | ที่อยู่ของเครื่องที่เก็บฐานข้อมูล | ทีมเทคนิคเป็นผู้ให้ค่า เป็นความลับ |
| **พอร์ต** (จำเป็น) | หมายเลขช่องทางเข้าเครื่อง | ตัวเลข 1 ถึง 65535 ค่าที่พบบ่อยคือ `5432` ถ้าผิด จะขึ้น **พอร์ตต้องเป็นตัวเลขระหว่าง 1 ถึง 65535** |
| **ฐานข้อมูล** (จำเป็น) | ชื่อฐานข้อมูลบนเครื่องนั้น | เช่น `carmen_tenant` |
| **ชื่อผู้ใช้** (จำเป็น) | ชื่อบัญชีที่ระบบใช้เข้าฐานข้อมูล | ไม่ใช่ชื่อผู้ใช้ของคนในระบบ Carmen Blue เป็นความลับ |
| **รหัสผ่าน** (จำเป็นตอนสร้าง) | รหัสผ่านของบัญชีด้านบน | ตอนแก้ไข ให้เว้นว่างไว้เพื่อใช้รหัสผ่านเดิม กดไอคอนรูปตาเพื่อดูสิ่งที่พิมพ์ ระบบเก็บแบบเข้ารหัส และไม่แสดงรหัสผ่านที่บันทึกแล้วอีก |
| **หมายเหตุ** | บันทึกเพิ่มเติม | ไม่บังคับ แสดงใต้ที่อยู่ในหน้ารายการ |

## งานที่ทำบ่อย

**ดูว่าโรงแรมเก็บข้อมูลไว้ที่ไหน**

1. เปิดหน้า [หน่วยธุรกิจ](/screens/organization/business-units) แล้วเปิดหน่วยธุรกิจที่ต้องการ
2. ไปที่แท็บ **เทคนิค** ดูช่อง **Database Pool** ในกล่อง **การเชื่อมต่อฐานข้อมูล**
3. กลับมาที่หน้า **Database Pools** แล้วค้นหา Pool นั้น

**เพิ่ม Pool ใหม่ (เมื่อทีมเทคนิคให้ข้อมูลมา)**

1. กด **เพิ่ม Pool**
2. กรอก **ชื่อ** และช่องที่จำเป็นทั้งหมดตามที่ทีมเทคนิคให้มา
3. ตรวจว่าติ๊ก **ใช้งาน** อยู่
4. กด **สร้าง Pool** ระบบจะขึ้นว่า **สร้าง database pool แล้ว**

**เปลี่ยนรหัสผ่านหรือที่อยู่ (เมื่อทีมเทคนิคแจ้ง)**

1. ในหน้ารายการ กดปุ่ม `⋯` ที่แถว แล้วเลือก **แก้ไข**
2. แก้ช่องที่ทีมเทคนิคบอก ถ้าไม่ได้เปลี่ยนรหัสผ่าน ให้เว้นช่อง **รหัสผ่าน** ว่างไว้
3. กด **บันทึกการแก้ไข** ระบบจะขึ้นว่า **บันทึกการแก้ไขแล้ว**
4. ขอให้ทีมเทคนิคตรวจว่าโรงแรมที่ใช้ Pool นี้ยังเปิดข้อมูลได้

**ลบ Pool ที่ไม่ใช้แล้ว**

1. ในหน้ารายการ กดปุ่ม `⋯` ที่แถว แล้วเลือก **ลบ**
2. กล่อง **ลบ Database Pool** จะถามยืนยัน กด **ลบ**
3. ถ้ายังมีหน่วยธุรกิจใช้ Pool นี้อยู่ ระบบจะไม่ลบ และขึ้นว่า **database pool นี้ยังถูกใช้งานโดยหน่วยธุรกิจเหล่านี้: ...** ตามด้วยรายชื่อ ให้ย้ายหน่วยธุรกิจเหล่านั้นไป Pool อื่นก่อน (เป็นงานของทีมเทคนิค)

## ข้อควรระวัง

::: warning ข้อมูลการเชื่อมต่อเป็นความลับ
ที่อยู่ ชื่อผู้ใช้ และรหัสผ่านในหน้านี้ใช้เข้าถึงข้อมูลของโรงแรมได้โดยตรง อย่าส่งต่อทางแชตหรืออีเมล อย่าถ่ายภาพหน้าจอนี้ไปแชร์ และเก็บไฟล์ CSV ที่ส่งออกไว้ในที่ปลอดภัย
:::

::: warning การแก้ไขมีผลกับทุกโรงแรมที่ใช้ Pool นี้
เมื่อกด **บันทึกการแก้ไข** ค่าใหม่จะถูกบันทึกทันที ถ้าใส่โฮสต์ ชื่อผู้ใช้ หรือรหัสผ่านผิด หรือเอาติ๊ก **ใช้งาน** ออก ทุกโรงแรมที่ใช้ Pool นี้อาจเปิดข้อมูลไม่ได้ ระบบจะไม่ตรวจว่าเชื่อมต่อได้จริงก่อนบันทึก หน้านี้ไม่มีปุ่มทดสอบการเชื่อมต่อ แก้เฉพาะเมื่อทีมเทคนิคแจ้ง
:::

::: warning การลบย้อนกลับไม่ได้
กล่องยืนยันบอกว่า **การกระทำนี้ย้อนกลับไม่ได้** Pool ที่ลบแล้วจะหายจากรายการ และหน้าจอนี้ไม่มีปุ่มกู้คืน
:::

## คู่มือที่เกี่ยวข้อง

ยังไม่มีคู่มือแบบทีละขั้นสำหรับหน้านี้ เพราะเป็นงานของทีมเทคนิค หน้าที่เกี่ยวข้อง:

- [หน่วยธุรกิจ](/screens/organization/business-units) เลือก Pool ของแต่ละโรงแรมในแท็บ **เทคนิค**
- [ตั้งค่าโรงแรมใหม่](/guides/setup-hotel) ขั้นตอนสร้างหน่วยธุรกิจ บอกให้ปล่อยกล่อง **การเชื่อมต่อฐานข้อมูล** ไว้ให้ทีมเทคนิค
- [Tenant Migrations](/screens/organization/tenant-migrations) คอลัมน์ **Schema** บอกด้วยว่าโรงแรมใช้ Pool ใด <!-- plain-ok -->
