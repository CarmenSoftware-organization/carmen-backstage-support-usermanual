# ผู้ใช้

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **Backstage** > **ผู้ใช้** (หัวหน้าจอแสดงว่า **ผู้ใช้ Backstage**)

หน้านี้แสดงทุกคนที่ได้รับ **บทบาท** (ชุดสิทธิ์ที่กำหนดว่าทำอะไรในระบบหลังบ้านนี้ได้) และใช้มอบหรือถอนบทบาท ผู้ใช้ที่ไม่มีบทบาทเลยจะไม่แสดงในหน้านี้ และใช้หน้าจอผู้ดูแล Backstage ไม่ได้ (ยกเว้นผู้ดูแลระบบสูงสุด ซึ่งจัดการที่หน้าของตัวเอง)

ความต่างระหว่างสองหน้า:

- [บทบาท](/screens/backstage/backstage-roles) กำหนดว่าบทบาทหนึ่ง **ทำอะไรได้บ้าง**
- หน้านี้กำหนดว่า **ใครได้บทบาทไหน** และใช้ได้ในขอบเขตใด

**ขอบเขต** มีสองแบบ:

- **ทั้ง Backstage:** บทบาทมีผลกับทุก Cluster และทุกหน่วยธุรกิจ
- **เฉพาะ Cluster:** บทบาทมีผลเฉพาะใน Cluster (กลุ่มโรงแรมของลูกค้าหนึ่งราย) ที่เลือก

บัญชีผู้ใช้ต้องมีอยู่ก่อนจึงจะมอบบทบาทได้ ถ้ายังไม่มี ให้สร้างที่หน้า [ผู้ใช้งาน](/screens/organization/users)

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ**

- **ดูภาพรวม:** จำนวน **ผู้ถือสิทธิ์** แยกเป็น **ทั้ง Backstage** และ **เฉพาะ Cluster** และจำนวน **การมอบสิทธิ์** ทั้งหมด ถ้ามีบัญชีที่ถูกปิดใช้งานแล้วแต่ยังถือบทบาทอยู่ จะมีคำเตือน
- **ค้นหา** และ **กรอง** ตามสถานะ **บทบาท** และ **ขอบเขต** ดู [ค้นหา](/getting-started/common-actions#search) และ [ตัวกรอง](/getting-started/common-actions#filters)
- **อ่านตาราง:** **ผู้ใช้** (ชื่อและอีเมล), **บทบาทและขอบเขต** และ **มอบเมื่อ** (พร้อมชื่อผู้มอบ)
- **เมนูของแถว** (ปุ่ม `⋯`): **จัดการบทบาท** (เปิดหน้าของผู้ใช้) และ **เพิกถอนสิทธิ์ทั้งหมด** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)
- **ส่งออก** ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **มอบสิทธิ์:** ปุ่ม **มอบสิทธิ์** เปิดกล่อง **มอบสิทธิ์เข้าถึง Backstage**

**หน้าของผู้ใช้**

- ด้านบนบอกว่าผู้ใช้นี้ **เอื้อมถึงทั้ง Backstage** หรือเอื้อมถึงกี่ Cluster
- **บทบาทและขอบเขต:** รายการบทบาทที่ได้รับ พร้อมชื่อผู้มอบและเวลา ถ้าผู้ใช้มอบบทบาทให้ตัวเอง จะมีป้าย **มอบให้ตัวเอง** ปุ่ม **เพิ่มบทบาท** และ **นำออก** อยู่ในส่วนนี้
- **สังกัด:** Cluster และหน่วยธุรกิจที่ผู้ใช้สังกัดในฐานะพนักงาน ส่วนนี้ใช้ดูอย่างเดียว และไม่ใช่สิทธิ์ในระบบหลังบ้าน

การมอบ เพิ่ม นำออก และเพิกถอนบทบาท **มีผลทันทีที่ยืนยัน** หน้านี้ไม่มีปุ่มบันทึกแยก

## อธิบายช่องข้อมูล

**กล่องมอบสิทธิ์เข้าถึง Backstage** (จากหน้ารายการ)

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ผู้ใช้** (จำเป็น) | คนที่จะได้รับบทบาท | ค้นด้วยชื่อหรืออีเมล |
| **บทบาท** (จำเป็น) | บทบาทที่จะมอบ | เลือกได้หลายบทบาท บทบาทที่ผู้ใช้มีอยู่แล้วจะขึ้น **มอบสิทธิ์ไปแล้ว** |
| **ขอบเขต** | บทบาทใช้ได้กว้างแค่ไหน | **ทั้ง Backstage** หรือ **เฉพาะ Cluster ที่เลือก** ทุกบทบาทในครั้งนี้ได้ขอบเขตเดียวกัน |
| **Cluster** (จำเป็นเมื่อเลือกเฉพาะ Cluster) | Cluster ที่บทบาทมีผล | |

**กล่องเพิ่มบทบาท** (จากหน้าของผู้ใช้)

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **บทบาท** (จำเป็น) | บทบาทที่จะเพิ่ม | ครั้งละหนึ่งบทบาท |
| **ขอบเขต** | **ทั้ง Backstage** หรือ **เฉพาะ Cluster** | |
| **Cluster** (จำเป็นเมื่อเลือกเฉพาะ Cluster) | Cluster ที่บทบาทมีผล | |

## งานที่ทำบ่อย

**ให้พนักงานใหม่เข้าระบบหลังบ้านได้**

1. ตรวจว่าพนักงานมีบัญชีแล้วที่หน้า [ผู้ใช้งาน](/screens/organization/users) ถ้ายังไม่มี ให้สร้างก่อน ดู [เพิ่มผู้ใช้](/guides/add-user)
2. ที่หน้านี้ กดปุ่ม **มอบสิทธิ์**
3. ค้นหาและเลือก **ผู้ใช้**
4. ติ๊ก **บทบาท** ที่ต้องการ
5. เลือก **ขอบเขต** ถ้าเลือก **เฉพาะ Cluster ที่เลือก** ให้เลือก **Cluster**
6. กดปุ่ม **มอบสิทธิ์** ระบบแสดงข้อความ **มอบสิทธิ์แล้ว** และผู้ใช้ปรากฏในตาราง

**นำบทบาทหนึ่งออกจากผู้ใช้**

1. คลิกชื่อผู้ใช้ในตาราง (หรือเลือก **จัดการบทบาท** จากเมนูของแถว)
2. ที่บทบาทที่ต้องการ กด **นำออก**
3. กล่อง **นำบทบาทออก** ถามยืนยัน ถ้าเป็นบทบาทสุดท้าย กล่องจะเตือนว่าผู้ใช้จะไม่ปรากฏในหน้านี้อีก กดยืนยัน

**ถอนสิทธิ์ทั้งหมดเมื่อพนักงานลาออก**

1. ที่หน้ารายการ กดปุ่ม `⋯` ที่แถวของผู้ใช้
2. เลือก **เพิกถอนสิทธิ์ทั้งหมด**
3. กล่อง **เพิกถอนสิทธิ์ Backstage ทั้งหมด** บอกจำนวนบทบาทที่จะถูกนำออก กด **เพิกถอนทั้งหมด**
4. ระบบแสดงข้อความ **เพิกถอนสิทธิ์แล้ว**

## ข้อควรระวัง

::: warning มีผลทันที
การมอบและถอนบทบาทมีผลทันทีที่ยืนยัน ไม่มีปุ่มบันทึกหรือยกเลิก ถ้าถอนผิด ต้องมอบบทบาทกลับไปใหม่ ข้อมูลว่าใครมอบให้เมื่อไหร่ของบทบาทเดิมจะไม่กลับมา
:::

- การถอนบทบาทไม่ได้ลบบัญชีผู้ใช้ และไม่ได้เอาผู้ใช้ออกจาก Cluster หรือหน่วยธุรกิจที่สังกัด
- ป้าย **มอบให้ตัวเอง** แปลว่าผู้ใช้คนนั้นมอบบทบาทให้บัญชีตัวเอง ควรตรวจว่าเป็นเรื่องที่ตั้งใจ
- ผู้ดูแลระบบสูงสุดจัดการที่หน้า [ผู้ดูแลระบบสูงสุด](/screens/backstage/super-admins) ไม่ใช่หน้านี้
