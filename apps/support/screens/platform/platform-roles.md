# บทบาท

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **Platform** > **บทบาท** (หัวหน้าจอแสดงว่า **บทบาท Platform**)

**บทบาท** (Platform Role — ชุดสิทธิ์ที่กำหนดว่าผู้ที่ได้รับบทบาทนี้ทำอะไรในระบบหลังบ้านนี้ได้บ้าง) เช่น บทบาท "Support Staff" อาจดูข้อมูลได้อย่างเดียว ส่วน "Platform Admin" ทำได้เกือบทุกอย่าง

หน้านี้ใช้สร้างและแก้ไขบทบาท คือกำหนดว่าบทบาทหนึ่งได้ **สิทธิ์** (การอนุญาตให้ทำสิ่งหนึ่งในหน้าจอหนึ่ง เช่น ดู สร้าง แก้ไข หรือลบ) อะไรบ้าง ส่วนการมอบบทบาทให้ผู้ใช้แต่ละคน ทำที่หน้า [ผู้ใช้](/screens/platform/platform-users)

ลำดับการทำงานโดยย่อ: สร้างบทบาทที่นี่ → มอบบทบาทให้คนที่หน้า **ผู้ใช้** → คนนั้นจะเห็นเมนูและปุ่มตามสิทธิ์ของบทบาท

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ**

- **ดูภาพรวม:** จำนวนบทบาท (ใช้งานกี่บทบาท ถูกลบกี่บทบาท) และ **บทบาทที่มีสิทธิ์กว้างที่สุด** เทียบกับจำนวนสิทธิ์ทั้งหมด แถบสีส้มพร้อมไอคอนเตือน = ได้ครบทุกสิทธิ์
- **ค้นหา** และ **กรอง** ตามสถานะ ดู [ค้นหา](/getting-started/common-actions#search) และ [ตัวกรอง](/getting-started/common-actions#filters)
- **อ่านตาราง:** **ชื่อ** (พร้อมคำอธิบาย), **สิทธิ์** (ได้กี่สิทธิ์จากทั้งหมด ครอบคลุมกี่หน้าจอ), **สถานะ**, **สร้างเมื่อ** และ **แก้ไขเมื่อ**
- **เมนูของแถว** (ปุ่ม `⋯`): **แก้ไข** และ **ลบ** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)
- **รายการสิทธิ์ทั้งหมด:** ปุ่มนี้เปิดหน้ารายการอ้างอิงของทุกสิทธิ์ที่มีในระบบ พร้อมคำอธิบายภาษาอังกฤษ ใช้อ่านอย่างเดียว หน้านี้ไม่มีในเมนูด้านซ้าย เข้าได้จากปุ่มนี้เท่านั้น
- **ส่งออก** ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **เพิ่มบทบาท:** ปุ่ม **เพิ่มบทบาท**

**หน้าของบทบาท**

- ด้านบนสรุปว่าบทบาทนี้ได้กี่สิทธิ์ ครอบคลุมกี่หน้าจอ
- ถ้าบทบาทนี้มีสิทธิ์ที่ทำให้ผู้ถือบทบาทเพิ่มสิทธิ์ให้ตัวเองได้ (เช่น แก้บทบาท หรือมอบบทบาทให้ผู้ใช้) จะมีคำเตือน **ให้สิทธิ์เพิ่มแก่ตัวเองได้** พร้อมรายการสิทธิ์นั้น
- เปิดในโหมดดู กดปุ่ม **แก้ไข** เพื่อเปลี่ยน ดู [โหมดดูและโหมดแก้ไข](/getting-started/common-actions#view-edit)

## อธิบายช่องข้อมูล

**การตั้งค่า**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ชื่อ** (จำเป็น) | ชื่อบทบาท | เช่น "Support Staff" |
| **คำอธิบาย** | บอกว่าบทบาทนี้มีไว้สำหรับใคร | ไม่บังคับ เช่น "ทีมซัพพอร์ต ดูข้อมูลได้อย่างเดียว" |
| **สถานะ** | ติ๊ก **ใช้งาน** เพื่อให้บทบาทนี้มีผล | |

**สิทธิ์**

สิทธิ์จัดกลุ่มตามเมนูด้านซ้าย แต่ละแถวคือหนึ่งหน้าจอ (เช่น **Clusters**, **ผู้ใช้งาน**) และมีปุ่มของการกระทำที่อนุญาตได้ ชื่อการกระทำบนหน้าจอเป็นภาษาอังกฤษ:

| ปุ่มบนหน้าจอ | ความหมาย |
| --- | --- |
| **read** | เปิดดูหน้าจอนั้น |
| **create** | สร้างรายการใหม่ |
| **update** | แก้ไขรายการ |
| **delete** | ลบรายการ |
| **manage** | จัดการทั้งหมดของหน้านั้น (เพิ่ม แก้ไข ลบ หรือสั่งงาน) |
| **apply** | สั่งให้ระบบลงมือทำจริง เช่น อัปเดตโครงสร้างฐานข้อมูลของโรงแรม |
| **detail** | ดูข้อมูลรายละเอียดรายบุคคล เช่น บันทึกกิจกรรมทีละรายการ |

- กดปุ่มการกระทำเพื่อเลือกหรือยกเลิก ปุ่มที่ได้รับแล้วเป็นสีทึบ ปุ่มเส้นประคือสิทธิ์ที่มีแต่บทบาทนี้ไม่ได้รับ
- กด **ทั้งหมด** ท้ายแถวเพื่อเลือกทุกการกระทำของหน้าจอนั้น หรือ **ทั้งหมด** ท้ายหัวกลุ่มเพื่อเลือกทั้งกลุ่ม
- ตอนแก้ไข สิทธิ์ที่เพิ่งเพิ่มหรือเพิ่งถอดจะมีป้าย **(เพิ่มใหม่)** หรือ **(ถอดออก)** และด้านบนบอกจำนวนที่เปลี่ยน เช่น "+2 −1 สิทธิ์" ช่วยให้ตรวจก่อนบันทึก

## งานที่ทำบ่อย

**สร้างบทบาทใหม่สำหรับทีมซัพพอร์ต**

1. กดปุ่ม **เพิ่มบทบาท**
2. ที่ **การตั้งค่า** พิมพ์ **ชื่อ** และ **คำอธิบาย**
3. ที่ **สิทธิ์** กดปุ่ม **read** ของหน้าจอที่ทีมต้องดู
4. กดปุ่มอื่นเพิ่มเฉพาะงานที่ทีมต้องทำ เช่น **update** ของ **ผู้ใช้งาน**
5. กดปุ่ม **สร้างบทบาท**
6. ไปที่หน้า [ผู้ใช้](/screens/platform/platform-users) เพื่อมอบบทบาทนี้ให้คนในทีม

**ถอดสิทธิ์ออกจากบทบาท**

1. คลิกชื่อบทบาทในตาราง
2. กดปุ่ม **แก้ไข**
3. กดปุ่มการกระทำที่ต้องการถอด ปุ่มจะมีป้าย **(ถอดออก)**
4. ตรวจจำนวนที่เปลี่ยนด้านบน แล้วกด **บันทึกการแก้ไข**

## ข้อควรระวัง

::: warning การเปลี่ยนสิทธิ์มีผลกับทุกคนที่ถือบทบาทนี้
เมื่อบันทึก ทุกคนที่ได้รับบทบาทนี้จะได้หรือเสียสิทธิ์นั้นพร้อมกัน ก่อนถอดสิทธิ์ ให้ตรวจที่หน้า [ผู้ใช้](/screens/platform/platform-users) ว่ามีใครถือบทบาทนี้อยู่บ้าง
:::

::: warning การลบบทบาท
กล่องยืนยันเตือนว่าการลบย้อนกลับไม่ได้ บทบาทที่ลบแล้วนับอยู่ในตัวเลข "ถูกลบ" ด้านบน แต่หน้าจอนี้ไม่มีปุ่มกู้คืน ถ้าต้องการหยุดใช้ชั่วคราว ให้เอาติ๊ก **ใช้งาน** ออกแทน
:::

- ระวังสิทธิ์ที่มีคำเตือน **ให้สิทธิ์เพิ่มแก่ตัวเองได้** ผู้ถือบทบาทนั้นแก้บทบาทหรือมอบบทบาทให้ตัวเองได้ ให้เฉพาะคนที่ไว้ใจได้
- ผู้ดูแลระบบสูงสุดไม่ต้องใช้บทบาท เพราะทำได้ทุกอย่างอยู่แล้ว ดู [ผู้ดูแลระบบสูงสุด](/screens/platform/super-admins)
