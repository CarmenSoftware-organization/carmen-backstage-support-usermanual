# ตั้งค่า

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **Platform** > **ตั้งค่า** (หัวหน้าจอแสดงว่า **ตั้งค่า Platform**)

หน้านี้รวมค่าตั้งที่มีผลกับทั้งระบบ เปลี่ยนแล้วมีผลโดยไม่ต้องรอทีมระบบติดตั้งโปรแกรมใหม่ เช่น ลิงก์ในอีเมลเชิญและอีเมลตั้งรหัสผ่านใหม่ใช้ได้นานแค่ไหน ใครได้รับอีเมลแจ้งเตือน และระบบบังคับใช้ไลเซนส์ (สิทธิ์การใช้งานที่ลูกค้าซื้อ) จริงหรือไม่

แถบด้านบนสรุปสถานะสามเรื่องที่สำคัญที่สุด: **การบังคับใช้ License**, **อีเมลแจ้งเตือน** และ **API migration ของฐานข้อมูลแพลตฟอร์ม**

## สิ่งที่ทำได้ในหน้านี้

- **อ่านค่าที่ใช้อยู่:** แต่ละการ์ดแสดงค่าปัจจุบัน และท้ายการ์ดบอกว่าใครแก้ล่าสุดเมื่อไหร่
- **แก้ทีละการ์ด:** กดปุ่ม **แก้ไข** ที่มุมขวาบนของการ์ด ปุ่มจะเปลี่ยนเป็น **บันทึกการแก้ไข** และ **ยกเลิก** ที่ตำแหน่งเดิม การ์ดแต่ละใบบันทึกแยกกัน การกดบันทึกที่การ์ดหนึ่งไม่ได้บันทึกการ์ดอื่น
- การ์ดแบ่งเป็นหมวด:
  - **ลิงก์อีเมลและอายุลิงก์:** **คำเชิญ**, **การสมัคร**, **ยืนยันอีเมล**, **ตั้งรหัสผ่านใหม่**
  - **ขีดจำกัดคำเชิญ:** **เพดานอัตรา**
  - **การแจ้งเตือน:** **อีเมลแจ้งเตือน**
  - **ไลเซนส์:** **การบังคับใช้ License** และ **เกณฑ์ใกล้หมดอายุ**
  - **การเข้าสู่ระบบ:** **เข้าสู่ระบบด้วย Google**
  - **External API:** ที่อยู่ที่ระบบภายนอกใช้เชื่อมต่อ
  - **ฐานข้อมูลแพลตฟอร์ม:** **API migration ของฐานข้อมูลแพลตฟอร์ม**

ใครแก้อะไรได้:

- ปุ่ม **แก้ไข** แสดงเฉพาะผู้ที่บทบาทอนุญาตให้จัดการค่าตั้ง
- การ์ด **การบังคับใช้ License** ต้องมีสิทธิ์จัดการไลเซนส์เพิ่มด้วย
- การ์ด **API migration ของฐานข้อมูลแพลตฟอร์ม** แก้ได้เฉพาะผู้ดูแลระบบสูงสุด (Super Admin — ผู้ที่ทำได้ทุกอย่างในระบบ)

**เพดานอัตรา** (หมวดขีดจำกัดคำเชิญ)

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ต่อผู้ดูแลหนึ่งคน / ชั่วโมง** (จำเป็น) | ผู้ดูแลหนึ่งคนส่งคำเชิญได้กี่ฉบับต่อชั่วโมง | จำนวนเต็มตั้งแต่ 1 ขึ้นไป |
| **ต่อคลัสเตอร์ / วัน** (จำเป็น) | หนึ่ง Cluster ส่งคำเชิญได้กี่ฉบับต่อวัน | จำนวนเต็มตั้งแต่ 1 ขึ้นไป |

ค่าเริ่มต้นตั้งไว้สูงโดยตั้งใจ เพราะการเปิดโรงแรมใหม่แล้วเชิญพนักงาน 30–50 คนพร้อมกันเป็นเรื่องปกติ เพดานนี้มีไว้กันการใช้ผิดปกติ ไม่ควรลดลงมาใกล้จำนวนที่ใช้จริง ถ้าระบบทำงานอยู่หลายเครื่อง เพดานจริงจะคูณตามจำนวนเครื่อง เช่น ตั้ง 100 บนสองเครื่อง ได้จริงถึง 200

## งานที่ทำบ่อย

**เปลี่ยนอายุลิงก์ตั้งรหัสผ่านใหม่**

1. ที่การ์ด **ตั้งรหัสผ่านใหม่** กดปุ่ม **แก้ไข**
2. แก้ **อายุลิงก์ (ชั่วโมง)** เช่น เป็น 48
3. กดปุ่ม **บันทึกการแก้ไข** ที่มุมขวาบนของการ์ด
4. ระบบแสดงข้อความ **บันทึกการตั้งค่า ตั้งรหัสผ่านใหม่ แล้ว** ลิงก์ที่ส่งหลังจากนี้จะใช้อายุใหม่

**เปิดการบังคับใช้ไลเซนส์**

1. ตรวจที่หน้า [ไลเซนส์](/screens/license/licenses) ก่อน ว่าทุกหน่วยธุรกิจมีสัญญาที่ยังใช้งานได้และมีฟีเจอร์ครบ
2. ที่การ์ด **การบังคับใช้ License** กดปุ่ม **แก้ไข**
3. ติ๊ก **บังคับใช้ license จริง**
4. กดปุ่ม **บันทึกการแก้ไข**
5. กล่อง **เปิดการบังคับใช้ license?** จะเตือนผลที่จะเกิด กดปุ่ม **เปิดการบังคับใช้**
6. ระบบแสดงข้อความว่ามีผลภายใน 60 วินาที

ถ้าต้องการปิดกลับ ทำขั้นตอนเดียวกันแต่เอาติ๊กออก การปิดไม่มีกล่องยืนยัน

## ข้อควรระวัง

::: warning การบังคับใช้ License
เมื่อเปิด ภายในประมาณ 60 วินาที ทุกหน่วยธุรกิจที่ไม่มีสัญญาครอบคลุมฟีเจอร์ที่ใช้อยู่จะถูกปฏิเสธทันที และเชิญผู้ใช้เกินจำนวนที่นั่งไม่ได้อีก ตรวจสัญญาของทุกโรงแรมให้ครบก่อน ปิดกลับได้ทันทีด้วยการเอาติ๊กออก
:::

::: warning API migration ของฐานข้อมูลแพลตฟอร์ม
เมื่อเปิด ผู้ดูแลระบบสูงสุดจะสั่งอัปเดตโครงสร้างฐานข้อมูลกลางของทุก Cluster ได้จากหน้าจอ การอัปเดตนั้นมีผลกับทุกโรงแรมพร้อมกัน เปิดเฉพาะเมื่อมีแผนอัปเดตแล้ว และปิดกลับเมื่อเสร็จ ค่านี้มีผลภายในประมาณหนึ่งนาที ไม่ใช่ทันที
:::

- การ์ด **คำเชิญ**, **การสมัคร**, **ยืนยันอีเมล** และ **ตั้งรหัสผ่านใหม่** ถ้ากรอกที่อยู่ผิด ผู้รับอีเมลจะเปิดลิงก์ไม่ได้ ทดสอบด้วยการส่งอีเมลจริงหลังเปลี่ยน
- การปิด **การส่ง** ใน **อีเมลแจ้งเตือน** หยุดอีเมลรายงานและการแจ้งเตือนทั้งหมด
