# แอปพลิเคชัน

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **Platform** > **แอปพลิเคชัน** (หัวหน้าจอแสดงว่า **จัดการแอปพลิเคชัน**)

**แอปพลิเคชัน** คือโปรแกรมที่ได้รับอนุญาตให้เชื่อมต่อกับ Carmen Blue เช่น เว็บ Carmen Blue ที่โรงแรมใช้ แอปบนมือถือ เครื่องขายหน้าร้าน (POS) หรือระบบภายนอกที่ส่งข้อมูลเข้ามา ทุกโปรแกรมต้องมีรายการของตัวเองในหน้านี้ ถ้าไม่มี ระบบจะไม่รับการเชื่อมต่อจากโปรแกรมนั้น

แต่ละแอปพลิเคชันมี:

- **App ID** (รหัสประจำแอปพลิเคชัน — ระบบใช้รหัสนี้เพื่อรู้ว่าการเชื่อมต่อมาจากโปรแกรมใด) ระบบสร้างให้อัตโนมัติ
- **สิทธิ์เข้าถึง API** (API — ช่องทางที่โปรแกรมใช้ขอหรือส่งข้อมูลกับ Carmen Blue) ว่าโปรแกรมนี้ใช้ช่องทางใดได้บ้าง
- **รหัสลับของแอป** (รหัสที่โปรแกรมต้องส่งมาพร้อม App ID เพื่อยืนยันว่าเป็นโปรแกรมตัวจริง) ไม่บังคับ
- **สถานะการให้บริการ** ใช้ปิดปรับปรุงหรือปิดการใช้งานโปรแกรมนั้นชั่วคราว

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ**

- **ดูภาพรวม (ทะเบียน):** จำนวนแอปพลิเคชัน แยกตาม **สถานะการให้บริการ**, **รหัสลับของแอป** (**บังคับใช้**, **มีแต่ไม่บังคับ**, **ไม่มี secret**), **ขอบเขตการเข้าถึง API** (**เข้าถึงทั้งหมด** หรือ **จำกัดขอบเขต**) และ **อุปกรณ์**
- **ค้นหา** และ **กรอง** ตามสถานะและอุปกรณ์ ดู [ค้นหา](/getting-started/common-actions#search) และ [ตัวกรอง](/getting-started/common-actions#filters)
- **อ่านตาราง:** **ชื่อ** (พร้อม App ID และปุ่มคัดลอก), **สถานะ**, **สิทธิ์เข้าถึง** (แถบบอกว่าใช้ช่องทางได้กี่รายการจากทั้งหมด แถบสีส้มพร้อมไอคอนเตือน = เข้าถึงได้ทุกช่องทาง), **อุปกรณ์**, **สร้างเมื่อ** และ **แก้ไขเมื่อ**
- **คัดลอก App ID:** กดไอคอนคัดลอกข้าง App ID
- **เมนูของแถว** (ปุ่ม `⋯`): **แก้ไข**, **ประวัติการเปลี่ยนแปลง** และ **ลบ** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)
- **ส่งออก** ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **เพิ่มแอปพลิเคชัน:** ปุ่ม **เพิ่มแอปพลิเคชัน**

**หน้าของแอปพลิเคชัน** แบ่งเป็นสองส่วนที่บันทึกต่างกัน:

- **นิยามการเข้าถึง** (**สิทธิ์เข้าถึง API** และ **การตั้งค่า**): กดปุ่ม **แก้ไข** ด้านบน แก้แล้วกด **บันทึกการแก้ไข** ที่แถบด้านล่าง ดู [โหมดดูและโหมดแก้ไข](/getting-started/common-actions#view-edit)
- **ควบคุมทันที** (**สถานะการให้บริการ**, **ผู้ใช้ที่ได้รับการยกเว้น** และ **รหัสลับของแอป**): แต่ละส่วนมีปุ่มของตัวเอง และ **มีผลทันทีที่กด ไม่ต้องกดบันทึก** ส่วนนี้แสดงหลังสร้างแอปพลิเคชันแล้วเท่านั้น

## อธิบายช่องข้อมูล

**การตั้งค่า**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ชื่อ** (จำเป็น) | ชื่อของแอปพลิเคชัน | เช่น "mobile-app", "interface-opera-pos" |
| **คำอธิบาย** | บันทึกเพิ่มเติม | ไม่บังคับ |
| **อุปกรณ์** | ชนิดของโปรแกรม | mobile, web, desktop หรือ pos |

**สิทธิ์เข้าถึง API**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **เข้าถึงได้ทุก API** | ติ๊กเพื่อให้โปรแกรมใช้ได้ทุกช่องทาง | แนะนำให้ใช้กับโปรแกรมหลักของ Carmen Blue เท่านั้น โปรแกรมของบุคคลภายนอกควรได้เฉพาะช่องทางที่จำเป็น เมื่อติ๊ก หน้าจะเตือนว่า **แอปนี้ไม่ได้ถูกจำกัด endpoint จึงเรียกได้ทุก API ในแพลตฟอร์ม** <!-- plain-ok --> |
| รายการช่องทาง (เมื่อไม่ได้ติ๊กข้อบน) | เลือกทีละช่องทางที่โปรแกรมใช้ได้ จัดกลุ่มตามโมดูล (หมวดงาน เช่น ap-invoice) | กดลูกศรเพื่อขยายโมดูล กด **ทั้งหมด** เพื่อเลือกทั้งโมดูล หรือพิมพ์ในช่องกรองเพื่อหา ด้านล่างบอกจำนวนที่เลือกจากทั้งหมด เช่น `3/1091` |

ช่องทางที่ลบหรืออนุมัติข้อมูลได้จะถูกนับแยกและเน้นสี (เช่น **ลบหรืออนุมัติได้ 266**) ตรวจรายการนี้ให้ดีก่อนให้สิทธิ์โปรแกรมภายนอก

**สถานะการให้บริการ** (มีผลภายในประมาณ 1 นาที)

| ตัวเลือก | ผลที่ผู้ใช้โปรแกรมนี้จะได้รับ |
| --- | --- |
| **ทำงานปกติ** | ใช้งานได้ตามปกติ |
| **ปิดปรับปรุง** | ใช้งานส่วนใหญ่ไม่ได้ ยกเว้นการเข้าสู่ระบบ เว็บ Carmen Blue จะแสดงหน้าปิดปรับปรุง โปรแกรมอื่นจะแสดงข้อผิดพลาด ผู้ใช้ที่ได้รับการยกเว้นยังใช้ได้เต็มที่ |
| **อ่านอย่างเดียว** | ดูข้อมูลได้ แต่บันทึกหรือแก้ไขไม่ได้ (บางการดู เช่น ดูตัวอย่างก่อนพิมพ์ ก็ใช้ไม่ได้ด้วย) ผู้ใช้ที่ได้รับการยกเว้นยังใช้ได้เต็มที่ |
| **ปิดใช้งาน** | ใช้งานเกือบทั้งหมดไม่ได้ รวมทั้งการเข้าสู่ระบบ และรวมถึงผู้ใช้ที่ได้รับการยกเว้น |

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ข้อความถึงผู้ใช้** | ข้อความที่ผู้ใช้เห็นระหว่างปิดปรับปรุง | เช่น "กำลังอัปเกรดฐานข้อมูล" |
| **คาดว่าจะกลับมา** | เวลาที่คาดว่าจะกลับมาใช้ได้ | ต้องเป็นเวลาในอนาคต แสดงให้ผู้ใช้เห็นเท่านั้น ระบบไม่สลับกลับเอง ต้องมีคนกลับมาเลือก **ทำงานปกติ** |
| **ผู้ใช้ที่ได้รับการยกเว้น** | ผู้ใช้ที่ยังใช้งานได้เต็มที่ระหว่าง **ปิดปรับปรุง** และ **อ่านอย่างเดียว** | ค้นด้วยชื่อหรืออีเมล แล้วกด **บันทึกรายชื่อยกเว้น** ไม่มีผลกับ **ปิดใช้งาน** |

**รหัสลับของแอป**

| ปุ่มหรือช่อง | ความหมาย |
| --- | --- |
| **สร้างรหัสลับ** | สร้างรหัสลับครั้งแรก แล้วคัดลอกไปใส่ในโปรแกรมนั้น |
| **แสดงรหัสลับ** / **ซ่อนรหัสลับ** | ดูรหัสเต็ม รหัสจะซ่อนเองหลัง 30 วินาที ทุกครั้งที่กดแสดง ระบบบันทึกไว้ว่าใครดู |
| **คัดลอกรหัสลับ** | คัดลอกรหัสโดยไม่ต้องแสดงบนจอ |
| **เปลี่ยนรหัสลับ** | สร้างรหัสใหม่แทนรหัสเดิม รหัสเดิมยังใช้ได้อีก 24 ชั่วโมง เพื่อให้มีเวลาเปลี่ยนในโปรแกรม |
| **บังคับใช้รหัสลับ** | เปิด = ปฏิเสธการเชื่อมต่อที่ไม่มีรหัสลับที่ถูกต้อง ปิด = รับทั้งที่มีและไม่มีรหัส ต้องสร้างรหัสลับก่อนจึงเปิดได้ |

## งานที่ทำบ่อย

**เพิ่มแอปพลิเคชันสำหรับระบบภายนอก**

1. กดปุ่ม **เพิ่มแอปพลิเคชัน**
2. ที่ **การตั้งค่า** พิมพ์ **ชื่อ** และเลือก **อุปกรณ์**
3. ที่ **สิทธิ์เข้าถึง API** ไม่ต้องติ๊ก **เข้าถึงได้ทุก API** แล้วเลือกเฉพาะช่องทางที่ระบบนั้นต้องใช้
4. กดปุ่ม **สร้างแอปพลิเคชัน**
5. ที่หน้าของแอปพลิเคชัน ส่วน **รหัสลับของแอป** กด **สร้างรหัสลับ**
6. คัดลอก **App ID** และรหัสลับ ส่งให้ผู้ดูแลระบบภายนอกทางช่องทางที่ปลอดภัย
7. เมื่อระบบภายนอกตั้งค่าเสร็จแล้ว เปิด **บังคับใช้รหัสลับ**

**ปิดปรับปรุงโปรแกรมชั่วคราว**

1. เปิดหน้าของแอปพลิเคชัน
2. ที่ **สถานะการให้บริการ** เลือก **ปิดปรับปรุง**
3. พิมพ์ **ข้อความถึงผู้ใช้** และ **คาดว่าจะกลับมา**
4. (ถ้าต้องการ) เพิ่มผู้ใช้ที่ต้องทดสอบระหว่างปิดปรับปรุงใน **ผู้ใช้ที่ได้รับการยกเว้น** แล้วกด **บันทึกรายชื่อยกเว้น**
5. กดปุ่ม **ใช้สถานะนี้** แล้วยืนยันในกล่องที่ขึ้นมา
6. เมื่อเสร็จงาน กลับมาเลือก **ทำงานปกติ** แล้วกด **ใช้สถานะนี้** อีกครั้ง

## ข้อควรระวัง

::: warning รหัสลับต้องเก็บเป็นความลับ
ใครที่ได้ทั้ง App ID และรหัสลับ จะเชื่อมต่อกับ Carmen Blue ในนามโปรแกรมนั้นได้ อย่าส่งรหัสลับทางแชตกลุ่มหรืออีเมลที่หลายคนเห็น อย่าบันทึกภาพหน้าจอตอนที่รหัสแสดงอยู่ ถ้าสงสัยว่ารหัสรั่ว ให้กด **เปลี่ยนรหัสลับ** ทันที
:::

::: warning ควบคุมทันทีมีผลกับผู้ใช้จริง
**สถานะการให้บริการ** และ **บังคับใช้รหัสลับ** มีผลกับทุกคนที่ใช้โปรแกรมนั้นภายในประมาณ 1 นาที โดยไม่ต้องกดบันทึก ถ้าเปิด **บังคับใช้รหัสลับ** ก่อนที่โปรแกรมจะส่งรหัสมา ทุกการเชื่อมต่อจะถูกปฏิเสธ ถ้าแอปพลิเคชันนั้นเป็นตัวที่หน้าผู้ดูแลนี้ใช้อยู่ หน้าจอจะเตือน และระบบจะไม่ให้เปลี่ยนสถานะที่ทำให้หน้านี้ถูกล็อก
:::

::: warning การลบแอปพลิเคชัน
การลบย้อนกลับไม่ได้ โปรแกรมที่ใช้ App ID นั้นจะเชื่อมต่อไม่ได้อีก ถ้าต้องการหยุดชั่วคราว ให้ใช้ **ปิดใช้งาน** ใน **สถานะการให้บริการ** แทน
:::

- **เปลี่ยนรหัสลับ** ซ้ำภายใน 24 ชั่วโมง จะทำให้รหัสจากสองรอบก่อนใช้ไม่ได้ทันที
- **คาดว่าจะกลับมา** ไม่ได้สลับสถานะกลับเอง ต้องกลับมาเลือก **ทำงานปกติ** ด้วยตัวเอง
