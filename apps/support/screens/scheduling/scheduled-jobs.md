# งานตามเวลา

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **งานตามเวลา** > **งานตามเวลา**

**งานตามเวลา** (Scheduled Jobs — งานที่ระบบทำเองโดยอัตโนมัติตามเวลาที่ตั้งไว้) เช่น ออกรายงานทุกเช้า ส่งการแจ้งเตือน หรือล้างข้อมูลเก่าทุกคืน หน้านี้ใช้ดูว่ามีงานอะไรบ้าง งานไหนกำลังทำงาน รันล่าสุดเมื่อไหร่ และครั้งถัดไปเมื่อไหร่ รวมทั้งสร้าง แก้ไข หยุด หรือสั่งรันทันที

งานบางงานถูกสร้างจากโปรแกรมอื่นให้หน่วยธุรกิจ (โรงแรม) หนึ่งแห่ง เช่น รายงานที่ผู้ใช้ตั้งเวลาไว้ในเว็บ Carmen Blue งานเหล่านี้คอลัมน์ **เจ้าของ** จะแสดงชื่อโปรแกรมนั้น ส่วนงานที่สร้างจากหน้านี้จะแสดง **Backstage**

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ**

- **ดูภาพรวม:** การ์ด **ทั้งหมด**, **กำลังทำงาน**, **หยุดทำงาน**, **มีข้อผิดพลาด**, **เป็นของ service อื่น** และ **กำลังทำงานใน scheduler** (จำนวนงานที่ตัวจัดเวลาของระบบถืออยู่จริง) การ์ดกำลังทำงาน หยุดทำงาน มีข้อผิดพลาด และเป็นของ service อื่น นับเฉพาะแถวที่แสดงในหน้าตารางนี้
- **ค้นหา** และ **กรอง** ตาม **ประเภทงาน** หรือ **สถานะ** ดู [ค้นหา](/getting-started/common-actions#search) และ [ตัวกรอง](/getting-started/common-actions#filters)
- **อ่านตาราง:** **ชื่อ**, **ประเภท**, **หน่วยธุรกิจ**, **กำหนดเวลา** (รหัสกำหนดเวลา พร้อมคำอธิบายสั้น ๆ ใต้รหัส เช่น "เมื่อ 03:30 AM"), **สถานะ**, **เจ้าของ**, **รันล่าสุด**, **รันครั้งถัดไป** และ **จำนวนครั้งที่รัน** ถ้ารอบล่าสุดมีปัญหา จะมีไอคอนสามเหลี่ยมสีเหลืองข้างเวลา **รันล่าสุด** ชี้เมาส์ที่ไอคอนเพื่ออ่านข้อความ
- **ปุ่มท้ายแถว** (เรียงจากซ้าย):
  - **หยุด** หรือ **เริ่ม** หยุดหรือเริ่มให้งานทำตามเวลา มีผลทันทีโดยไม่มีกล่องยืนยัน
  - **รันทันที** สั่งให้งานทำหนึ่งรอบเดี๋ยวนี้ มีผลทันทีโดยไม่มีกล่องยืนยัน
  - **แก้ไข** เปิดหน้าของงาน
  - **ลบ** มีกล่องยืนยัน
- **ส่งออก CSV** ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **สร้างงาน:** ปุ่ม **เพิ่มงานตามเวลา**

ปุ่มท้ายแถวและปุ่มเพิ่มงานแสดงเฉพาะผู้ที่บทบาทอนุญาตให้จัดการงานตามเวลา

**หน้าของงาน (สร้างหรือแก้ไข)**

- แบ่งเป็นส่วน **ข้อมูลพื้นฐาน**, **กำหนดเวลา**, **การรัน** และ **การตั้งค่าตามประเภทงาน**
- แถบด้านล่างมีปุ่ม **ยกเลิก** และ **บันทึกการแก้ไข** ดู [บันทึกและยกเลิก](/getting-started/common-actions#save-cancel)
- งานที่เป็นของโปรแกรมอื่น จะมีแถบสีเหลืองด้านบนบอกว่าการแก้ที่นี่มีผลกับหน่วยธุรกิจนั้นทันที

## อธิบายช่องข้อมูล

**ข้อมูลพื้นฐาน**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ชื่อ** (จำเป็น) | ชื่อของงาน | เช่น "ล้างบันทึกกิจกรรมเก่า" |
| **ประเภทงาน** | งานนี้ทำอะไร | **รายงาน**, **การแจ้งเตือน**, **ล้างข้อมูล**, **รีเฟรชแดชบอร์ด**, **สรุปยอดกิจกรรม** หรือ **เก็บรักษากิจกรรม** เลือกได้ตอนสร้างเท่านั้น สร้างแล้วเปลี่ยนไม่ได้ ช่องในส่วน **การตั้งค่าตามประเภทงาน** จะเปลี่ยนตามประเภทที่เลือก |
| **คำอธิบาย** | บันทึกเพิ่มเติม | ไม่บังคับ |
| **สถานะ** | ติ๊ก **ใช้งาน** ให้งานทำตามเวลา เอาติ๊กออกเพื่อหยุด | มีผลเมื่อกดบันทึก |

**กำหนดเวลา**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **รูปแบบ** | ความถี่ของงาน | **ทุกไม่กี่นาที**, **ทุกชั่วโมง**, **ทุกวัน**, **ทุกสัปดาห์**, **ทุกเดือน** หรือ **กำหนดเอง** เมื่อเลือกแล้วจะมีช่องเวลา วัน หรือจำนวนนาทีให้เลือกต่อ |
| **Cron expression** (จำเป็น) | รหัสกำหนดเวลาที่ระบบใช้จริง ระบบเติมให้เองเมื่อคุณเลือกรูปแบบและเวลา | ใต้ช่องจะมีคำอธิบายเป็นภาษาคน และเวลาที่จะรัน 3 ครั้งถัดไป ดูตัวอย่างในตารางถัดไป |
| **เวลาแจ้งผู้รับ** (เฉพาะงานรายงาน) | เวลาที่จะบอกผู้รับว่ารายงานพร้อมแล้ว | คนละเวลากับตอนที่รายงานรัน เว้นว่างไว้เพื่อแจ้งทันทีที่รันเสร็จ |

ตัวอย่างกำหนดเวลา

| ต้องการ | เลือกบนหน้าจอ | Cron expression ที่ได้ |
| --- | --- | --- |
| ทุกวัน เวลา 02:00 | **ทุกวัน** แล้วตั้ง **เวลา** 02 : 00 | `0 2 * * *` |
| ทุก 30 นาที | **ทุกไม่กี่นาที** แล้วตั้ง **ทุก ๆ** 30 **นาที** | `*/30 * * * *` |
| ทุกวันจันทร์ เวลา 08:30 | **ทุกสัปดาห์** ติ๊กวัน **จ** แล้วตั้งเวลา 08 : 30 | `30 8 * * 1` |
| วันที่ 1 ของทุกเดือน เวลา 06:00 | **ทุกเดือน** ตั้ง **วันที่** 1 แล้วตั้งเวลา 06 : 00 | `0 6 1 * *` |

รหัสกำหนดเวลามี 5 ส่วนเรียงกัน คือ นาที ชั่วโมง วันที่ เดือน และวันในสัปดาห์ เครื่องหมาย `*` แปลว่า "ทุก" คุณไม่จำเป็นต้องพิมพ์เอง เลือกจาก **รูปแบบ** ก็พอ ถ้าเลือก **กำหนดเอง** จะได้ช่องพิมพ์ทีละส่วน ซึ่งเชื่อมกับช่อง **Cron expression** อยู่ตลอด

**การรัน**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **จำนวนครั้งที่ลองใหม่สูงสุด** | ถ้ารอบหนึ่งล้มเหลว ให้ลองใหม่ได้กี่ครั้ง | ค่าเริ่มต้น 0 (ไม่ลองใหม่) |
| **ระยะเวลาหมดเวลา (วินาที)** | ถ้างานทำนานเกินนี้ ระบบจะหยุดรอบนั้น | ค่าเริ่มต้น 300 วินาที (5 นาที) |

**การตั้งค่าตามประเภทงาน**

| ประเภทงาน | ช่อง | ความหมาย |
| --- | --- | --- |
| **รายงาน** | **เทมเพลตรายงาน** | รายงานที่จะออก |
| | **หน่วยธุรกิจ** (จำเป็น) | โรงแรมที่จะออกรายงาน ต้องเลือกอย่างน้อยหนึ่งแห่ง ไม่งั้นการรันจะล้มเหลว |
| | **รูปแบบไฟล์** | pdf, excel, csv หรือ json | <!-- plain-ok -->
| | **ตัวกรอง** | เงื่อนไขของรายงาน เป็นคู่ **คีย์** กับ **ค่า** กด **เพิ่มตัวกรอง** เพื่อเพิ่มแถว ใช้ตามที่ทีมรายงานกำหนด |
| | **ผู้ใช้ที่รับรายงาน** | ผู้ใช้ในระบบที่จะได้รับรายงาน |
| | **วิธีการส่ง** | **ไฟล์** (แนบไฟล์รายงาน) หรือ **ลิงก์ดูรายงาน** |
| | **แจ้งเตือนในเว็บแอป**, **แจ้งเตือนทางอีเมล** | ช่องทางแจ้งผู้รับ ถ้าติ๊กอีเมล จะมีช่อง **แหล่งอีเมล** (**ภายใน** หรือ **ภายนอก**) ให้เลือก |
| **การแจ้งเตือน** | **หัวข้อ**, **ข้อความ** | เนื้อหาการแจ้งเตือน |
| | **ประเภท**, **หมวดหมู่** | ป้ายจัดกลุ่มการแจ้งเตือน พิมพ์ตามที่ทีมระบบกำหนด |
| | **ผู้ใช้ที่รับการแจ้งเตือน** (จำเป็น) | ต้องเลือกอย่างน้อยหนึ่งคน ไม่งั้นการรันจะล้มเหลว |
| **ล้างข้อมูล** | **การกระทำ**, **ประเภท** | สิ่งที่จะล้าง พิมพ์ตามที่ทีมระบบกำหนด ถ้าไม่แน่ใจให้ถามทีมระบบก่อน |
| | **เก่ากว่า** | ล้างข้อมูลที่เก่ากว่าระยะนี้ เช่น `30d` (30 วัน), `90d`, `1y` (1 ปี) |
| **รีเฟรชแดชบอร์ด** | **หน่วยธุรกิจ** | โรงแรมที่จะอัปเดตตัวเลขบนแดชบอร์ด เว้นว่างไว้เพื่อรวมทุกแห่ง |
| | **ระดับ** | ชุดของแดชบอร์ดที่จะอัปเดต **ทุกระดับ** หรือเลือกระดับเดียว |
| **สรุปยอดกิจกรรม** | **จำนวนวันย้อนหลัง** | สรุปยอดกิจกรรมของกี่วันที่ผ่านมาในแต่ละรอบ |
| **เก็บรักษากิจกรรม** | **จำนวนวันที่เก็บข้อมูล** | บันทึกกิจกรรมที่เก่ากว่าจำนวนวันนี้จะถูกลบ |
| | **ขนาดชุดข้อมูล** | จำนวนแถวสูงสุดที่ลบในแต่ละชุด ช่วยไม่ให้ระบบทำงานหนักเกินไป |

## งานที่ทำบ่อย

**สร้างงานใหม่**

1. กดปุ่ม **เพิ่มงานตามเวลา**
2. พิมพ์ **ชื่อ** แล้วเลือก **ประเภทงาน**
3. ที่ **รูปแบบ** เลือกความถี่ แล้วตั้งเวลา
4. ตรวจว่าช่อง **Cron expression** มีค่าแล้ว และคำอธิบายใต้ช่องตรงกับที่ต้องการ ถ้าช่องยังว่าง (เห็นเพียงตัวอักษรสีจาง) ให้เปลี่ยนรูปแบบหรือเวลา ระบบจะเติมให้
5. กรอกช่องในส่วน **การตั้งค่าตามประเภทงาน**
6. กดปุ่ม **บันทึกการแก้ไข** ระบบจะแสดงข้อความ **สร้างงานตามเวลาแล้ว** และเปิดหน้าของงานนั้น

**หยุดงานชั่วคราว**

1. ที่หน้ารายการ กดปุ่ม **หยุด** ท้ายแถว
2. ระบบแสดงข้อความ **หยุดงานตามเวลาแล้ว** สถานะเปลี่ยนเป็น **หยุดทำงาน** ทันที
3. เมื่อต้องการให้ทำงานต่อ กดปุ่ม **เริ่ม** ที่แถวเดิม

**สั่งรันหนึ่งรอบเดี๋ยวนี้**

1. กดปุ่ม **รันทันที** ท้ายแถว
2. ระบบแสดงข้อความ **ส่งคำสั่งรันแล้ว — งานกำลังทำงานอยู่เบื้องหลัง** ข้อความนี้ไม่ได้แปลว่างานสำเร็จแล้ว
3. รอสักครู่ แล้วโหลดหน้าใหม่เพื่อดู **รันล่าสุด** และไอคอนข้อผิดพลาด

งานที่สั่งรันแล้วทำต่อที่ระบบเบื้องหลัง การปิดหน้านี้หรือออกจากระบบไม่ได้หยุดงาน

## ข้อควรระวัง

::: warning รันทันทีมีผลจริง
**รันทันที** ทำงานจริงหนึ่งรอบทันทีโดยไม่ถามยืนยัน เช่น ส่งรายงานหรือการแจ้งเตือนถึงผู้รับจริง หรือลบข้อมูลเก่าตามที่ตั้งไว้ กดครั้งเดียวต่อหนึ่งรอบ การกดซ้ำจะสั่งรันซ้ำอีกรอบ
:::

::: warning การลบงาน
การลบงานย้อนกลับไม่ได้ ถ้าต้องการหยุดชั่วคราว ให้กด **หยุด** แทน งานที่โปรแกรมอื่นสร้างให้หน่วยธุรกิจ เมื่อลบที่นี่ กำหนดการของหน่วยธุรกิจนั้นจะหายไปด้วย
:::

::: warning งานล้างข้อมูล
งานประเภท **ล้างข้อมูล** และ **เก็บรักษากิจกรรม** ลบข้อมูลเก่าจริงทุกครั้งที่รัน ข้อมูลที่ถูกลบไปแล้วกู้คืนจากหน้านี้ไม่ได้ ตรวจค่า **เก่ากว่า** หรือ **จำนวนวันที่เก็บข้อมูล** ให้ถูกก่อนบันทึก
:::

- **หยุด** และ **เริ่ม** มีผลทันทีที่กด ไม่ต้องกดบันทึก
- เวลาที่แสดงใต้ช่อง **Cron expression** เป็นเขตเวลาของเครื่องคุณ ตัวจัดเวลาของระบบอาจใช้เขตเวลาอื่น ให้ดูเวลาจริงที่คอลัมน์ **รันครั้งถัดไป** ในหน้ารายการหลังบันทึก
- งานที่เป็นของโปรแกรมอื่น บางครั้งระบบอาจไม่ให้แก้จากหน้านี้ และจะแจ้งว่า "งานนี้เป็นของ ... ไม่สามารถแก้ไขจากที่นี่ได้"
