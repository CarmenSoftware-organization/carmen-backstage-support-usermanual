# Tenant Migrations

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **องค์กร** > **หน่วยธุรกิจ** > **Tenant Migrations** หัวหน้าจอเขียนว่า **Tenant migration**

**Tenant** คือฐานข้อมูลของโรงแรมแต่ละแห่ง แต่ละ **หน่วยธุรกิจ** (Business Unit — โรงแรมหรือสาขาหนึ่งแห่ง) มีฐานข้อมูลของตัวเอง **Migration** คือการอัปเดตโครงสร้างฐานข้อมูลให้ตรงกับระบบรุ่นล่าสุด

เมื่อ Carmen Blue ออกรุ่นใหม่ ฐานข้อมูลของแต่ละโรงแรมอาจต้องเพิ่มช่องหรือตารางใหม่ก่อน โรงแรมจึงจะใช้ฟีเจอร์ใหม่ได้ หน้านี้ใช้ตรวจว่าโรงแรมใด **ตามหลัง** (ยังไม่ได้อัปเดต) แล้วสั่งอัปเดตทีละโรงแรมหรือทุกโรงแรมพร้อมกัน

**ใครใช้หน้านี้:** ปกติเป็นงานของทีมเทคนิค หลังออกรุ่นใหม่ หรือเมื่อโรงแรมแจ้งว่ามีหน้าจอใช้งานไม่ได้หลังอัปเดตระบบ ผู้ดูแลทั่วไปใช้หน้านี้ **ตรวจสถานะ** ได้อย่างปลอดภัย แต่ไม่ควรกดอัปเดตเองถ้าไม่ได้รับมอบหมาย

## สิ่งที่ทำได้ในหน้านี้

- **ดูสรุป:** กล่องด้านบนบอกจำนวน **tenant ที่ตรงกันแล้ว** เทียบกับทั้งหมด เช่น `10 / 12` และแถบสีแยก **ตรงกันแล้ว** **ตามหลัง** และ **ผิดพลาด** ถ้ายังไม่ได้ตรวจ จะแสดง `-`
- **ตรวจทั้งหมด:** ตรวจทุกโรงแรมว่าตามหลังอยู่หรือไม่ ไม่เปลี่ยนแปลงอะไร
- **Deploy ทั้งหมด** (หลังตรวจแล้วจะเปลี่ยนเป็น **Deploy ... ตัวที่ตามหลัง**): อัปเดตทุกโรงแรมที่ตามหลัง ต้องยืนยันก่อน ปุ่มนี้กดได้แม้ยังไม่ได้ตรวจ (เมื่อชี้เมาส์จะมีคำเตือน) และกดไม่ได้เมื่อตรวจแล้วทุกโรงแรมตรงกันแล้ว
- **ส่งออก** ผลการตรวจเป็นไฟล์ CSV ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **ค้นหา** หน่วยธุรกิจ ดู [ค้นหา](/getting-started/common-actions#search)
- **อ่านตาราง:** แต่ละแถวคือโรงแรมหนึ่งแห่ง
  - คอลัมน์ **Schema** บอกชื่อที่เก็บข้อมูลของโรงแรมและฐานข้อมูลที่ใช้ (บรรทัด **pool:**) <!-- plain-ok -->
  - **สถานะ** เป็น **ยังไม่ได้ตรวจ**, **ตรงกันแล้ว**, **... behind** (ตามหลังอยู่กี่รายการ) หรือ **Error** (ตรวจไม่สำเร็จ) สองแบบหลังแสดงเป็นภาษาอังกฤษบนหน้าจอ
  - **ตรวจล่าสุด** บอกเวลาที่ตรวจครั้งล่าสุด
- **ปุ่มท้ายแถว:**
  - **ตรวจ** (ไอคอนลูกศรวน): ตรวจโรงแรมนี้แห่งเดียว ปลอดภัย
  - **สั่งใช้** (ไอคอนเล่น): อัปเดตโรงแรมนี้ มีเฉพาะเมื่อมีรายการค้าง ต้องยืนยันก่อน
  - **ลง dashboard views** (ไอคอนแดชบอร์ด): อัปเดตส่วนที่ใช้แสดงแดชบอร์ดของโรงแรมนี้ ปิดไว้เมื่อตรงกันแล้ว
  - **แก้สถานะ** (ไอคอนประแจ): มีเฉพาะแถวที่สถานะเป็น **Error** ใช้แก้อัปเดตที่ค้างอยู่ สำหรับทีมเทคนิคเท่านั้น
- ถ้าบัญชีของคุณไม่มีสิทธิ์อัปเดต ปุ่มอัปเดตจะกดไม่ได้ เอาเมาส์ชี้ที่ปุ่มเพื่อดูเหตุผล

## อธิบายช่องข้อมูล

หน้านี้ไม่มีฟอร์มสร้างหรือแก้ไข มีเฉพาะกล่อง **แก้ migration ที่ค้างสถานะ** (ปุ่ม **แก้สถานะ**) ซึ่งเป็นงานของทีมเทคนิค

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ชื่อ migration** (จำเป็น) | ชื่อของอัปเดตที่ค้างอยู่ | ทีมเทคนิคเป็นผู้ให้ชื่อ |
| **ทำเครื่องหมายเป็น** (จำเป็น) | บันทึกว่าอัปเดตนั้น **รันแล้ว** หรือ **ย้อนกลับแล้ว** | ระบบไม่ได้รันอัปเดตจริง แค่บันทึกสถานะ |

## งานที่ทำบ่อย

**ตรวจว่าโรงแรมใดยังไม่ได้อัปเดต (ปลอดภัย)**

1. เปิดหน้า **Tenant Migrations**
2. กดปุ่ม **ตรวจทั้งหมด** ปุ่มจะขึ้นว่า **กำลังตรวจ...**
3. รอจนเสร็จ แล้วดูกล่องสรุปและคอลัมน์ **สถานะ**
4. ถ้าทุกแถวเป็น **ตรงกันแล้ว** ไม่ต้องทำอะไรต่อ
5. ถ้ามีแถว **... behind** หรือ **Error** ให้กด **ส่งออก** แล้วส่งไฟล์ให้ทีมเทคนิค

**อัปเดตโรงแรมแห่งเดียว (เมื่อได้รับมอบหมาย)**

1. กดปุ่ม **ตรวจ** ที่แถวของโรงแรม
2. ถ้ามีรายการค้าง ปุ่ม **สั่งใช้** จะขึ้นมา กดปุ่มนั้น
3. กล่อง **สั่งใช้ tenant migration** จะบอกจำนวนรายการ ชื่อ และรหัสของโรงแรม ตรวจให้ตรงกับโรงแรมที่ต้องการ
4. กด **สั่งใช้ migration**
5. รอจนสถานะเป็น **ตรงกันแล้ว**

**อัปเดตทุกโรงแรมที่ตามหลัง (เมื่อได้รับมอบหมาย)**

1. กด **ตรวจทั้งหมด** ก่อนเสมอ เพื่อดูว่าจะไปแตะโรงแรมใดบ้าง
2. กดปุ่ม **Deploy ... ตัวที่ตามหลัง**
3. กล่อง **Deploy migration ไปทุก BU** จะถามยืนยัน อ่านจำนวนโรงแรมให้ดี
4. กด **Deploy ทั้งหมด** ระหว่างทำงาน หน้าจอจะแสดงความคืบหน้า อย่าปิดหน้านี้ ถ้าเผลอปิดไป ระบบไม่ได้หยุดอัปเดตโรงแรมที่กำลังทำอยู่ ยังทำต่อจนเสร็จ หน้าจอแค่หยุดแสดงความคืบหน้า แต่โรงแรมที่ยังไม่ถึงคิวจะไม่ถูกอัปเดต อย่ากด **Deploy ทั้งหมด** ซ้ำทันที ให้รอสักครู่ เปิดหน้านี้ใหม่ แล้วกด **ตรวจทั้งหมด** เพื่อดูว่าโรงแรมใดยังตามหลังอยู่ และแจ้งทีมเทคนิค
5. เมื่อเสร็จ ระบบจะแสดงข้อความ **Deploy เสร็จแล้ว** ตรวจว่าไม่มีแถว **Error**

## ข้อควรระวัง

::: warning การอัปเดตโครงสร้างฐานข้อมูลย้อนกลับไม่ได้
ปุ่ม **สั่งใช้** และ **Deploy ทั้งหมด** เปลี่ยนโครงสร้างฐานข้อมูลของโรงแรมจริง และ **ย้อนกลับไม่ได้** ถ้าเกิดปัญหากลางทาง โรงแรมอาจใช้งานบางหน้าจอไม่ได้จนกว่าทีมเทคนิคจะแก้ กดเฉพาะเมื่อทีมเทคนิคมอบหมาย และควรทำนอกเวลาที่โรงแรมใช้งานหนัก
:::

::: warning Deploy ทั้งหมด มีผลกับทุกโรงแรมพร้อมกัน
ปุ่มนี้อัปเดตทุกโรงแรมที่ตามหลังในครั้งเดียว และกดได้แม้ยังไม่ได้ตรวจ ถ้ายังไม่ได้ **ตรวจทั้งหมด** คุณจะไม่รู้ว่าจะไปแตะโรงแรมใดบ้าง ตรวจก่อนเสมอ เมื่อเริ่มแล้วไม่มีปุ่มหยุดหรือยกเลิก
:::

::: warning แก้สถานะ สำหรับทีมเทคนิคเท่านั้น
กล่อง **แก้ migration ที่ค้างสถานะ** บันทึกว่าอัปเดตรันแล้วหรือย้อนกลับแล้ว โดยไม่ได้รันอัปเดตจริง ถ้าเลือกผิด ระบบจะนับว่าอัปเดตที่ไม่เคยรันได้รันแล้ว และฐานข้อมูลของโรงแรมจะไม่ตรงกับระบบ อย่าใช้ถ้าไม่ได้รับคำแนะนำจากทีมเทคนิค
:::

- ถ้าขึ้นว่า **มี migration ทำงานอยู่แล้ว กรุณาลองใหม่ในอีกสักครู่** ให้รอแล้วกดตรวจใหม่ อย่ากดซ้ำหลายครั้ง
- หน้าของแต่ละหน่วยธุรกิจ แท็บ **เทคนิค** มีกล่อง **Tenant Migrations** ที่ทำงานแบบเดียวกันสำหรับโรงแรมนั้นแห่งเดียว ดู [หน่วยธุรกิจ](/screens/organization/business-units)
