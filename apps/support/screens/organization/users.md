# ผู้ใช้งาน

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **องค์กร** > **ผู้ใช้งาน** หัวหน้าจอเขียนว่า **จัดการผู้ใช้**

หน้านี้เก็บบัญชีของทุกคนที่ใช้ Carmen Blue เช่น พนักงานโรงแรม ใช้สร้างบัญชีใหม่ แก้ชื่อ ปิดบัญชีชั่วคราว ตั้งรหัสผ่านให้ผู้ใช้ และกำหนดว่าผู้ใช้เข้า **หน่วยธุรกิจ** (Business Unit — โรงแรมหรือสาขาหนึ่งแห่ง) ใดได้บ้าง

ผู้ใช้ต้องอยู่ใน **Cluster** (กลุ่มโรงแรมของลูกค้าหนึ่งราย) ก่อน จึงจะได้รับหน่วยธุรกิจของ Cluster นั้น การเพิ่มผู้ใช้เข้า Cluster ทำที่หน้า [Clusters](/screens/organization/clusters)

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ (จัดการผู้ใช้)**

- **ดูภาพรวมผู้ใช้:** จำนวนผู้ใช้ทั้งหมด แยก **ใช้งาน** **ไม่ใช้งาน** และ **เก็บถาวรแล้ว** (ลบไปแล้ว) และรูปย่อของผู้ใช้ที่ **เพิ่มล่าสุด**
- **ค้นหา** ด้วยชื่อหรืออีเมล ดู [ค้นหา](/getting-started/common-actions#search)
- **กรอง** ตามสถานะ **ใช้งาน** / **ไม่ใช้งาน** หรือติ๊ก **แสดงผู้ใช้ที่ถูกลบชั่วคราว** ดู [ตัวกรอง](/getting-started/common-actions#filters)
- **อ่านตาราง:** คอลัมน์ **ผู้ใช้** แสดงชื่อและอีเมล คอลัมน์ **BU** แสดงจำนวนหน่วยธุรกิจของผู้ใช้ในรูปแบบ ใช้งาน / ทั้งหมด เช่น `2 / 2` ถ้าไม่มีจะแสดง `-`
- **ส่งออก** เป็นไฟล์ CSV ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **ดึงจาก Keycloak:** ดึงบัญชีจากระบบเข้าสู่ระบบกลางมาแสดงในรายการ ใช้เมื่อมีบัญชีที่สร้างไว้ในระบบเข้าสู่ระบบกลางแต่ยังไม่ขึ้นในหน้านี้ ถ้าไม่แน่ใจ ให้ถามทีมเทคนิคก่อนกด
- **เพิ่มผู้ใช้:** ปุ่ม **เพิ่มผู้ใช้**
- **เปิดผู้ใช้:** กดชื่อผู้ใช้
- **เมนูของแถว** (ปุ่ม `⋯`): **แก้ไข**, **ประวัติการเปลี่ยนแปลง**, **ลบ** และ **ลบถาวร** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)
- **เลือกหลายแถว:** ติ๊กช่องหน้าแถว แล้วใช้ปุ่ม **ลบ** หรือ **ลบถาวร** กับทุกแถวที่เลือก ช่องติ๊กนี้มีเฉพาะ **ผู้ดูแลระบบสูงสุด** (Super Admin) ดู [เลือกหลายรายการพร้อมกัน](/getting-started/common-actions#bulk-select)

**หน้าของผู้ใช้**

- **ส่วนหัว:** ชื่อ อีเมล ป้ายสถานะ และบรรทัดสรุปว่าเข้าหน่วยธุรกิจกี่แห่งใน Cluster กี่แห่ง (บรรทัดนี้แสดงเป็นภาษาอังกฤษ) ถ้ายังไม่มีจะขึ้นว่า **ยังไม่ได้กำหนดสิทธิ์เข้าถึง**
- **ปุ่มมุมขวาบน:** **ประวัติการเปลี่ยนแปลง**, **เปลี่ยนรหัสผ่าน** และ **แก้ไข**
- **สิทธิ์เข้าถึง:** แสดงแต่ละ Cluster พร้อมบทบาทใน Cluster และหน่วยธุรกิจใต้ Cluster พร้อม **บทบาท BU** และสถานะ กดปุ่ม **เพิ่ม BU** เพื่อให้ผู้ใช้เข้าหน่วยธุรกิจเพิ่ม หรือกดไอคอนถังขยะเพื่อนำหน่วยธุรกิจออก
- **โทเค็น MCP:** รหัสที่ผู้ใช้สร้างไว้เพื่อเชื่อมผู้ช่วย AI เข้ากับบัญชีของตัวเอง แสดงชื่อ วันสร้าง วันหมดอายุ วันใช้ล่าสุด และสถานะ ปุ่ม **เพิกถอนโทเค็น MCP ทั้งหมด** ทำให้ทุกโทเค็นใช้ไม่ได้ทันที

## อธิบายช่องข้อมูล

**ฟอร์มเพิ่มผู้ใช้ และฟอร์มแก้ไขบัญชี**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ชื่อผู้ใช้** (จำเป็น) | ชื่อที่ใช้เข้าสู่ระบบ | ต้องเป็นอีเมล เช่น `somchai@example.com` เปลี่ยนไม่ได้หลังสร้างบัญชี |
| **อีเมล** (จำเป็น) | อีเมลของผู้ใช้ | ใส่อีเมลเดียวกับชื่อผู้ใช้ |
| **ชื่อจริง** (จำเป็น) | ชื่อจริงของผู้ใช้ | `Somchai` |
| **ชื่อกลาง** | ชื่อกลาง ถ้ามี | ไม่บังคับ |
| **นามสกุล** (จำเป็น) | นามสกุลของผู้ใช้ | `Jaidee` |
| **ชื่อแฝง** | ชื่อสั้นที่ใช้แทนชื่อเต็มในที่แคบ | ไม่บังคับ ตัวอักษรหรือตัวเลขไม่เกิน 3 ตัว เช่น `SOM` |
| **ใช้งาน** | เปิดหรือปิดบัญชี | ติ๊กไว้ตามค่าเริ่มต้น ผู้ใช้ที่ปิดอยู่ยังมีสิทธิ์เดิมครบ แต่เข้าสู่ระบบไม่ได้ |

**กล่องเปลี่ยนรหัสผ่าน (ตั้งรหัสผ่านให้ผู้ใช้คนนี้)**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **รหัสผ่านใหม่** (จำเป็น) | รหัสผ่านที่ผู้ใช้จะใช้เข้าระบบ | อย่างน้อย 6 ตัวอักษร ไม่ต้องรู้รหัสผ่านเดิม |
| **ยืนยันรหัสผ่าน** (จำเป็น) | พิมพ์รหัสผ่านใหม่อีกครั้ง | ต้องตรงกับช่องแรกทุกตัว |

**กล่องเพิ่มหน่วยธุรกิจ (ปุ่มเพิ่ม BU)**

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **Cluster** (จำเป็น) | Cluster ของหน่วยธุรกิจ | เลือกได้เฉพาะ Cluster ที่ผู้ใช้อยู่แล้ว |
| **หน่วยธุรกิจ** (จำเป็น) | โรงแรมที่จะให้ผู้ใช้เข้า | ถ้าขึ้นว่า **ไม่มีหน่วยธุรกิจว่างใน cluster นี้** แปลว่าผู้ใช้อยู่ในทุกโรงแรมของ Cluster แล้ว |
| **บทบาท BU** (จำเป็น) | สิ่งที่ผู้ใช้ทำได้ในโรงแรมนี้ | เช่น **Admin** |

## งานที่ทำบ่อย

**สร้างบัญชีใหม่**

1. กดปุ่ม **เพิ่มผู้ใช้**
2. กรอก **ชื่อผู้ใช้** และ **อีเมล** เป็นอีเมลเดียวกัน
3. กรอก **ชื่อจริง** และ **นามสกุล**
4. ปล่อยให้ **ใช้งาน** ติ๊กไว้
5. กดปุ่ม **สร้างผู้ใช้** ระบบจะเปิดหน้าของผู้ใช้คนนั้น
6. ขั้นต่อไปคือตั้งรหัสผ่าน และให้ผู้ใช้เข้า Cluster และหน่วยธุรกิจ ตาม [เพิ่มผู้ใช้](/guides/add-user)

**ปิดบัญชีชั่วคราว**

1. เปิดหน้าของผู้ใช้ แล้วกด **แก้ไข**
2. เอาติ๊กที่ช่อง **ใช้งาน** ออก
3. กดปุ่ม **บันทึกการแก้ไข**

ผู้ใช้จะเข้าระบบไม่ได้ แต่สิทธิ์ทั้งหมดยังอยู่ ติ๊กกลับเมื่อต้องการเปิดอีกครั้ง วิธีนี้ปลอดภัยกว่าการลบ

**ตั้งรหัสผ่านใหม่ให้ผู้ใช้ที่ลืมรหัสผ่าน**

1. เปิดหน้าของผู้ใช้ แล้วกดปุ่ม **เปลี่ยนรหัสผ่าน**
2. พิมพ์ **รหัสผ่านใหม่** และ **ยืนยันรหัสผ่าน**
3. กดปุ่ม **อัปเดตรหัสผ่าน** ระบบจะแสดงข้อความ **เปลี่ยนรหัสผ่านสำเร็จ**
4. แจ้งรหัสผ่านให้ผู้ใช้ทางช่องทางที่ปลอดภัย

**ให้ผู้ใช้เข้าหน่วยธุรกิจ หรือนำออก**

1. เปิดหน้าของผู้ใช้
2. ในกล่อง **สิทธิ์เข้าถึง** กดปุ่ม **เพิ่ม BU**
3. เลือก **Cluster** แล้วเลือก **หน่วยธุรกิจ** และ **บทบาท BU**
4. กดปุ่ม **เพิ่ม** ระบบจะแสดงข้อความ **กำหนดหน่วยธุรกิจสำเร็จ**
5. ถ้าต้องการนำหน่วยธุรกิจออก ให้กดไอคอนถังขยะที่แถวของหน่วยธุรกิจ แล้วยืนยัน

ถ้าไม่มี Cluster ที่ต้องการให้เลือก ให้เพิ่มผู้ใช้เข้า Cluster ก่อนที่หน้า [Clusters](/screens/organization/clusters)

**ลบผู้ใช้**

1. ที่หน้ารายการ กดปุ่ม `⋯` ที่แถวของผู้ใช้ แล้วเลือก **ลบ**
2. กล่อง **ลบผู้ใช้** จะถามยืนยัน กดยืนยัน
3. ผู้ใช้จะหายจากตาราง แต่ยังดูได้เมื่อติ๊ก **แสดงผู้ใช้ที่ถูกลบชั่วคราว**

**ลบผู้ใช้ถาวร**

1. กดปุ่ม `⋯` ที่แถวของผู้ใช้ แล้วเลือก **ลบถาวร**
2. กล่อง **ลบผู้ใช้ถาวร** จะเปิดขึ้น
3. พิมพ์ชื่อผู้ใช้ของคนนั้นให้ตรงทุกตัวในช่อง **พิมพ์ชื่อผู้ใช้เพื่อยืนยัน**
4. กดปุ่ม **ลบถาวร**

**ลบหลายคนพร้อมกัน (เฉพาะผู้ดูแลระบบสูงสุด)**

1. ติ๊กช่องหน้าแถวของผู้ใช้ที่ต้องการ แถบด้านบนจะขึ้นว่า **เลือกแล้ว ... รายการ**
2. กด **ลบ** เพื่อลบแบบดูย้อนหลังได้ หรือ **ลบถาวร**
3. ถ้าเลือก **ลบถาวร** กล่องจะแสดงรหัส 6 ตัวอักษร พิมพ์รหัสนั้นในช่อง **กรอกรหัส 6 ตัวอักษร** แล้วกด **ลบถาวร**
4. ระบบจะแจ้งว่าลบสำเร็จกี่รายการ และไม่สำเร็จกี่รายการ

## ข้อควรระวัง

::: warning ลบถาวรย้อนกลับไม่ได้
**ลบถาวร** ลบผู้ใช้และข้อมูลที่เกี่ยวข้องทั้งหมดออกจากระบบ **ย้อนกลับไม่ได้** ถ้าต้องการแค่หยุดไม่ให้คนนั้นเข้าระบบ ให้ปิดบัญชีด้วยช่อง **ใช้งาน** แทน
:::

::: warning การลบแบบปกติก็ไม่มีปุ่มกู้คืนบนหน้าจอ
กล่องยืนยันการลบทีละคนบอกว่า **การกระทำนี้ย้อนกลับไม่ได้** ส่วนกล่องลบหลายคนบอกว่ากู้คืนได้ภายหลัง แต่หน้าจอนี้ไม่มีปุ่มกู้คืน ถ้าลบผิดคน ให้แจ้งทีมเทคนิค
:::

::: warning เพิกถอนโทเค็น MCP ทั้งหมด
ปุ่มนี้ทำให้โทเค็นทุกใบของผู้ใช้ใช้ไม่ได้ทันที และ **ย้อนกลับไม่ได้** ผู้ช่วย AI ที่ผู้ใช้เชื่อมไว้จะหยุดทำงาน ใช้เมื่อผู้ใช้พ้นสภาพ หรือสงสัยว่าโทเค็นรั่วไหล
:::

- **ชื่อผู้ใช้** เปลี่ยนไม่ได้หลังสร้างบัญชี ถ้าพิมพ์อีเมลผิด ต้องสร้างบัญชีใหม่แล้วลบบัญชีที่ผิด
- การนำหน่วยธุรกิจออกจากผู้ใช้ ทำให้ผู้ใช้เข้าโรงแรมนั้นไม่ได้ทันที
- อย่าส่งชื่อผู้ใช้และรหัสผ่านรวมกันในอีเมลฉบับเดียว
