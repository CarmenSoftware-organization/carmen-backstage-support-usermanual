# กลุ่มฟอร์ม

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **เนื้อหา** > **กลุ่มฟอร์ม**

เอกสารแต่ละชนิดของโรงแรม เช่น ใบขอซื้อ (PR) ใบสั่งซื้อ (PO) หรือใบรับสินค้า (GRN) มีแบบพิมพ์ได้หลายแบบ เช่น แนวตั้งและแนวนอน แต่ละแบบคือ **เทมเพลตรายงาน** (แม่แบบของเอกสาร) ประเภท **ฟอร์ม** หน้านี้จัดเทมเพลตฟอร์มเป็นกลุ่มตามรหัสเอกสาร และใช้เลือกว่าแบบใดเป็น **ค่าเริ่มต้น** (แบบที่ใช้เป็นหลักของเอกสารนั้น) แต่ละกลุ่มมีค่าเริ่มต้นได้แบบเดียว

ตัวเนื้อหาของเทมเพลตแก้ที่หน้า [เทมเพลตรายงาน](/screens/content/report-templates)

## สิ่งที่ทำได้ในหน้านี้

- **ค้นหา** ด้วยรหัสกลุ่มหรือชื่อเทมเพลต ดู [ค้นหา](/getting-started/common-actions#search)
- ติ๊ก **เฉพาะที่ใช้งาน** เพื่อซ่อนเทมเพลตที่ปิดใช้งานอยู่
- **อ่านการ์ด:** หนึ่งการ์ดต่อหนึ่งรหัสเอกสาร หัวการ์ดบอกรหัสและจำนวนเทมเพลต แต่ละแถวมีปุ่มกลม (ค่าเริ่มต้น) ชื่อ เวลาที่แก้ล่าสุด ป้าย **ใช้งาน** / **ไม่ใช้งาน** และป้าย **มาตรฐาน** / **กำหนดเอง**
- **ตั้งค่าเริ่มต้น:** กดปุ่มกลมหน้าชื่อเทมเพลต
- **เปิดหรือปิดใช้งาน:** ปุ่ม `⋯` ท้ายแถว > **เปิดใช้งาน** หรือ **ปิดใช้งาน** บันทึกทันที
- **แก้เทมเพลต:** ปุ่ม **แก้ไข** ในแถว พาไปที่หน้าของเทมเพลตนั้น
- **เพิ่มเทมเพลตในกลุ่ม:** ปุ่ม **เพิ่ม** บนการ์ด หรือปุ่ม **สร้างเทมเพลตฟอร์ม** ด้านบน พาไปที่ฟอร์มเทมเพลตรายงานใหม่ โดยเลือกประเภท **ฟอร์ม** (และรหัสกลุ่ม ถ้ากดจากการ์ด) ไว้ให้

## อธิบายช่องข้อมูล

หน้านี้ไม่มีฟอร์มของตัวเอง ช่องของเทมเพลตอธิบายไว้ที่ [เทมเพลตรายงาน](/screens/content/report-templates)

| สิ่งที่เห็นบนการ์ด | ความหมาย |
| --- | --- |
| ปุ่มกลมที่เลือกอยู่ | เทมเพลตนี้เป็นค่าเริ่มต้นของกลุ่ม |
| ปุ่มกลมสีจาง กดไม่ได้ | เทมเพลตนี้ปิดใช้งานอยู่ ต้องเปิดใช้งานก่อนจึงจะตั้งเป็นค่าเริ่มต้นได้ |
| **ยังไม่ได้ตั้งค่าเริ่มต้น — เลือกหนึ่งรายการ** | กลุ่มนี้ยังไม่มีค่าเริ่มต้น |
| **ปิดใช้งาน (ค่าเริ่มต้น)** กดไม่ได้ | ปิดเทมเพลตที่เป็นค่าเริ่มต้นไม่ได้ ให้ตั้งแบบอื่นเป็นค่าเริ่มต้นก่อน |

## งานที่ทำบ่อย

**เปลี่ยนแบบเริ่มต้นของเอกสาร**

1. หาการ์ดของรหัสเอกสาร เช่น **PO**
2. กดปุ่มกลมหน้าชื่อเทมเพลตที่ต้องการ
3. กล่อง **ตั้งเทมเพลตฟอร์มเริ่มต้น** จะบอกว่าแบบใหม่จะแทนที่แบบใด
4. กด **ตั้งเป็นค่าเริ่มต้น** ระบบจะแสดงข้อความยืนยัน

**ปิดเทมเพลตที่ไม่ใช้แล้ว**

1. ถ้าเทมเพลตนั้นเป็นค่าเริ่มต้นอยู่ ให้ตั้งแบบอื่นเป็นค่าเริ่มต้นก่อน
2. กดปุ่ม `⋯` ท้ายแถว
3. กด **ปิดใช้งาน** ระบบจะแสดงข้อความ **ปิดใช้งาน "..." แล้ว**

## ข้อควรระวัง

- การเปลี่ยนค่าเริ่มต้น และการเปิดหรือปิดใช้งาน มีผลทันทีที่กด ไม่มีปุ่มบันทึกแยก
- หน้านี้ไม่มีปุ่มลบ การลบเทมเพลตทำที่หน้า [เทมเพลตรายงาน](/screens/content/report-templates) และย้อนกลับไม่ได้

- [เทมเพลตรายงาน](/screens/content/report-templates)
