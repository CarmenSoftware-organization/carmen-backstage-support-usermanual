# ข่าวสาร

## ตำแหน่งในเมนูและหน้าจอนี้ใช้ทำอะไร

เมนูด้านซ้าย กลุ่ม **เนื้อหา** > **ข่าวสาร** หน้าจะขึ้นชื่อ **จัดการข่าว**

**ข่าวสาร** (News — บทความหรือข่าวที่ผู้ใช้ของโรงแรมเปิดอ่านเองได้) ต่างจาก [ประกาศ](/screens/content/broadcasts) ซึ่งเป็นการแจ้งเตือนที่ส่งตรงถึงผู้ใช้ ข่าวแต่ละชิ้นมี 3 สถานะ:

- **ร่าง:** ยังเขียนอยู่ ผู้อ่านยังมองไม่เห็น
- **เผยแพร่แล้ว:** ผู้อ่านในหน่วยธุรกิจที่เป็นเป้าหมายมองเห็น
- **เก็บถาวรแล้ว:** ซ่อนจากผู้อ่าน แต่ยังเก็บไว้ในระบบ

## สิ่งที่ทำได้ในหน้านี้

**หน้ารายการ**

- **ดูภาพรวม:** กล่องด้านบนแสดงข่าว **ล่าสุด** ที่เผยแพร่ และจำนวนข่าวที่เป็น **ร่าง** **เผยแพร่แล้ว** และ **เก็บถาวรแล้ว**
- **ค้นหา** ข่าว ดู [ค้นหา](/getting-started/common-actions#search)
- **กรอง** ตามสถานะและแท็ก ดู [ตัวกรอง](/getting-started/common-actions#filters)
- **ส่งออก** เป็นไฟล์ CSV ดู [ส่งออกเป็นไฟล์ CSV](/getting-started/common-actions#export)
- **เพิ่มข่าว:** ปุ่ม **เพิ่มข่าว**
- **อ่านตาราง:** **หัวข้อ** **สถานะ** **เป้าหมาย** (**ทั้งระบบ** หรือจำนวนหน่วยธุรกิจ) **แท็ก** **เผยแพร่เมื่อ** และ **แก้ไขเมื่อ**
- **เมนูของแถว** (ปุ่ม `⋯`): **แก้ไข**, **ประวัติการเปลี่ยนแปลง** และ **ลบ** ดู [เมนูของแต่ละแถว](/getting-started/common-actions#row-actions)
- **ทำกับหลายข่าวพร้อมกัน:** ติ๊กแถว แล้วกด **เผยแพร่รายการที่เลือก**, **เก็บถาวรรายการที่เลือก** หรือ **ลบรายการที่เลือก** ดู [เลือกหลายรายการพร้อมกัน](/getting-started/common-actions#bulk-select)

**หน้าของข่าว**

- ข่าวที่มีอยู่แล้วเปิดในโหมดดู กดปุ่ม **แก้ไข** เพื่อแก้ ดู [โหมดดูและโหมดแก้ไข](/getting-started/common-actions#view-edit)
- ส่วนบน: **ภาพหน้าปก** และ **พาดหัวข่าว** พร้อมป้ายบอกสถานะและใครมองเห็น
- กล่อง **บทความ:** เนื้อหา แหล่งที่มา และแท็ก
- กล่อง **เผยแพร่:** สถานะ เป้าหมาย และเวลาเผยแพร่
- กล่อง **ประวัติ** (ข่าวที่สร้างแล้ว): ใครสร้างและใครแก้ล่าสุด

## อธิบายช่องข้อมูล

| ช่อง | ความหมาย | ตัวอย่าง / หมายเหตุ |
| --- | --- | --- |
| **ภาพหน้าปก** | รูปประกอบข่าว | ลากรูปมาวาง หรือกด **เรียกดู** รับ JPEG, PNG, WEBP, GIF ขนาดไม่เกิน 5 MB รูปจะอัปโหลดตอนกดบันทึก เลือกรูปใหม่เพื่อเปลี่ยน |
| **พาดหัวข่าว** (จำเป็น) | หัวข้อของข่าว | เช่น "ปิดปรับปรุงระบบคืนวันเสาร์" |
| **เนื้อหา (Markdown)** | ตัวข่าว | เขียนแบบ Markdown (ใช้เครื่องหมายง่าย ๆ เช่น `**ข้อความ**` เพื่อทำตัวหนา) กดแท็บ **ตัวอย่าง** เพื่อดูหน้าตาจริง |
| **URL แหล่งที่มา** | ลิงก์ไปยังต้นทางของข่าว | ไม่บังคับ ต้องเป็นลิงก์เว็บที่ถูกต้อง |
| **แท็ก** | คำสำคัญสำหรับจัดกลุ่มและกรองข่าว | พิมพ์แล้วกด Enter ทีละคำ ระบบแนะนำแท็กที่เคยใช้ |
| **สถานะ** | ขั้นของข่าว | **ร่าง**, **เผยแพร่แล้ว** หรือ **เก็บถาวรแล้ว** |
| **มองเห็นได้ทุกหน่วยธุรกิจ** | ให้ทุกโรงแรมเห็น | ถ้าเอาติ๊กออก ต้องเลือกหน่วยธุรกิจอย่างน้อยหนึ่งแห่ง |
| **เผยแพร่เมื่อ** | เวลาที่ข่าวเผยแพร่ | ระบบใส่ให้เองเมื่อสถานะเปลี่ยนเป็น **เผยแพร่แล้ว** แก้เองไม่ได้ |

## งานที่ทำบ่อย

**เขียนและเผยแพร่ข่าว**

1. กดปุ่ม **เพิ่มข่าว**
2. ใส่ **ภาพหน้าปก** (ถ้ามี) แล้วพิมพ์ **พาดหัวข่าว**
3. เขียน **เนื้อหา (Markdown)** แล้วกดแท็บ **ตัวอย่าง** เพื่อตรวจ
4. ใส่ **แท็ก** และ **URL แหล่งที่มา** ถ้ามี
5. ในกล่อง **เผยแพร่** เลือกผู้อ่าน: ติ๊ก **มองเห็นได้ทุกหน่วยธุรกิจ** หรือเอาติ๊กออกแล้วเลือกหน่วยธุรกิจ
6. ถ้ายังไม่พร้อม ให้คง **สถานะ** เป็น **ร่าง** ถ้าพร้อม ให้เลือก **เผยแพร่แล้ว**
7. กดปุ่ม **สร้างข่าว**

**เผยแพร่หรือเก็บถาวรหลายข่าวพร้อมกัน**

1. ติ๊กข่าวที่ต้องการในตาราง
2. กด **เผยแพร่รายการที่เลือก** หรือ **เก็บถาวรรายการที่เลือก**
3. กล่องยืนยันแสดงรายชื่อข่าวที่เลือก และรหัส 6 ตัวอักษร พิมพ์รหัสนั้นในช่อง
4. กดปุ่มยืนยัน ระบบจะบอกว่าสำเร็จกี่รายการ และไม่สำเร็จกี่รายการ

ข่าวที่เก็บถาวรแล้ว นำกลับมาได้โดยเปิดแต่ละข่าวแล้วเปลี่ยน **สถานะ**

## ข้อควรระวัง

::: warning การลบข่าวย้อนกลับไม่ได้
ทั้งการลบทีละข่าวและ **ลบรายการที่เลือก** ย้อนกลับไม่ได้ และหน้าจอนี้ไม่มีปุ่มกู้คืน ถ้าแค่ต้องการซ่อนข่าวจากผู้อ่าน ให้ใช้ **เก็บถาวร** แทน
:::

- การทำกับหลายข่าวพร้อมกันต้องพิมพ์รหัสยืนยันทุกครั้ง รหัสเปลี่ยนใหม่ทุกครั้งที่เปิดกล่อง
- ข่าวที่ **เผยแพร่แล้ว** ผู้อ่านเห็นทันทีหลังบันทึก ตรวจเป้าหมายให้ถูกก่อนเผยแพร่
